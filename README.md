# maghzaccount-pro — نظام ERP محاسبي متكامل

> **نظام ERP احترافي للمنشآت الصغيرة والمتوسطة في العالم العربي** — محاسبة مزدوجة، مخازن، مبيعات، مشتريات، تصنيع، موارد بشرية، CRM، نقاط بيع، ووكيل ذكي — بالعربية والإنجليزية، على سطح المكتب (Electron) والمتصفح.

**الإصدار:** `v0.25.3` · **الترخيص:** خاص (Private) · **اللغة الافتراضية:** العربية (RTL)

---

## لماذا maghzaccount-pro؟

| المبدأ | التطبيق |
|---|---|
| **الدفتر مصدر الحقيقة** | كل رصيد يُشتق من القيود (`SUM(journal_entries)`) — لا أرصدة متراكمة تنحرف |
| **القيد المزدوج دائماً** | كل عملية (فاتورة، سند، راتب، إنتاج) تولّد قيداً متوازناً ذرياً |
| **تعدد المستأجرين** | عزل كامل بـ `company_id` + فحوصات دفاعية في كل استعلام |
| **يعمل بلا خادم** | PGlite (PostgreSQL حقيقي بتقنية WASM) في المتصفح، وPostgreSQL عبر Electron لسطح المكتب |
| **الوكيل لا يخترع** | كل كتابة بموافقة بشرية، وحارس deterministic يمنع ادعاءات النجاح الكاذبة |

## البنية التقنية

- **الواجهة:** React + TypeScript + Tailwind (وضع داكن/فاتح، RTL، خط Cairo)
- **قاعدة البيانات:** طبقة واحدة — PostgreSQL + Drizzle ORM
  - **سطح المكتب:** PostgreSQL عبر Electron IPC
  - **المتصفح:** PGlite محلي (IndexedDB)، مع خيار **عامل خلفية (Worker)** من الإعدادات يمنع تجميد الواجهة أثناء الاستعلامات الثقيلة
- **الحالة:** Zustand · **الترجمة:** عربي/إنجليزي بمفاتيح متوازنة · **الأيقونات:** Lucide

## التشغيل السريع

```bash
# التبعيات
npm install

# قاعدة التطوير (PostgreSQL محلي)
npm run db:reset:force

# الويب
npm run dev

# سطح المكتب
npm run electron:dev
```

| الأمر | الوظيفة |
|---|---|
| `npm run dev` / `npm run build` | تطوير / بناء الويب |
| `npm run electron:dev` / `npm run electron:build` | تطوير / بناء سطح المكتب |
| `npm run preflight` | الفحص الكامل: lint + tsc + tests |
| `npm test` / `npm run test:e2e` | اختبارات الوحدات / اختبارات المتصفح |
| `npm run db:reset:force` | إعادة بناء القاعدة من الصفر + بيانات تجريبية |
| `npm run db:check` | كشف الانحراف بين Drizzle schema وSQL |
