# الفترات الضريبية والإقرار — دليل الاستخدام

> فصل ضريبة المدخلات عن المخرجات، فترات بثلاث حالات، وإقرار VAT محسوب من أرجل القيود المرحّلة — لا من رؤوس الفواتير.

## نظرة عامة

الوحدة الضريبية تفصل جهتين: **ضريبة المخرجات** (على مبيعاتك — دائنة `21301`) و**ضريبة المدخلات** (على مشترياتك — مدينة `21302` تحت نفس المجموعة 213). الفترات الضريبية (`tax_periods`) تقسّم السنة إلى نوافذ إقرار، وكل نافذة تمر بثلاث حالات. تجد الإعداد في: **القائمة الجانبية ← الإعدادات ← الضريبة** (صفحة VAT وتتضمن لوحة الإقرار `VatReturnPanel`)، وبطاقة الولاية الضريبية في **بيانات الشركة** (`TaxJurisdictionCard`).

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض الإعدادات الضريبية والإقرار | `settings.view` |
| تعديل الولاية/النسبة/الفترات وتقديم الإقرار | `settings.edit` |
| الترحيل داخل فترة مفتوحة | صلاحية ترحيل الوحدة المصدر (`sales.post` / `accounting.post` ...) |

## الحسابان المنفصلان

| الحساب | الطبيعة | يتأثر بـ |
|---|---|---|
| ضريبة المخرجات `21301` | التزام (دائن) | فواتير المبيعات المرحّلة (+)، مرتجعات المبيعات المرحّلة (−) |
| ضريبة المدخلات `21302` | contra-liability (مدين تحت 213) | فواتير المشتريات المرحّلة (+)، مرتجعات المشتريات المرحّلة (−) |

> **لماذا الفصل؟** حساب واحد يخلط ما تجبيه للدولة بما تسترده منها. الفصل يجعل الإقرار قراءة مباشرة: مخرجات الفترة ناقص مدخلاتها.

## الدول المدعومة (`tax.country_code` هو المصدر الوحيد للنسبة)

| الدولة | الكود | النسبة | ملاحظة |
|---|---|---|---|
| السعودية | `SA` | 15% | |
| الإمارات | `AE` | 5% | |
| مصر | `EG` | 14% | |
| اليمن | `YE` | 0% | نسبة صفرية صحيحة — ليست غياباً |

- تُضبط الدولة من بطاقة الولاية في بيانات الشركة — النسبة تُقرأ من ملف الدولة، **لا تُفترض 15% أبداً**.
- غياب الدولة = سؤال المستخدم عن دولته قبل أي تسجيل ضريبي، لا افتراض صامت.

## الفترات الضريبية — دورة الحياة

| الحالة | المعنى | ماذا يمكن فعله |
|---|---|---|
| **مفتوحة** (open) | تستقبل الترحيلات | ترحيل عادي + إعداد الإقرار |
| **مغلقة** (closed) | انتهت مهلة التعديل | لا ترحيل جديد بتاريخ داخلها — التصحيح بفترة مفتوحة |
| **مُقدَّمة** (filed) | قُدِّم إقرارها للدولة | نهائية — مرجع تاريخي فقط |

**القفل عند الترحيل لا الإدخال:** المسودات حرة بأي تاريخ؛ لحظة الترحيل تفحص `assertPeriodOpen` في 8 مسارات (قيود، سندات، فواتير ومردودات المبيعات والمشتريات، رواتب، POS) وترفض تاريخ الفترة المغلقة/المقدمة برسالة تذكر الفترة.

## سير عمل خطوة بخطوة — مثال رقمي (إقرار شهر)

فترة يونيو 2026 (`SA` — 15%): مبيعات مرحّلة 1,000,000 + ضريبتها 150,000، مرتجع مبيعات 100,000 + ضريبته 15,000، مشتريات مرحّلة 600,000 + ضريبتها 90,000، مرتجع مشتريات 60,000 + ضريبته 9,000.

1. القائمة الجانبية ← الإعدادات ← الضريبة ← لوحة **الإقرار**.
2. اختر الفترة (يونيو 2026) — تُحسب البنود **من أرجل القيود المرحّلة** داخل الفترة:

| البند | الحساب | المبلغ (ر.ي) |
|---|---|---:|
| مخرجات الفترة | `SUM(credit)` على `21301` | 150,000 |
| مرتجعات المخرجات | `SUM(debit)` على `21301` | 15,000 |
| **صافي المخرجات** | | **135,000** |
| مدخلات الفترة | `SUM(debit)` على `21302` | 90,000 |
| مرتجعات المدخلات | `SUM(credit)` على `21302` | 9,000 |
| **صافي المدخلات** | | **81,000** |
| **الضريبة المستحقة** | صافي المخرجات − صافي المدخلات | **54,000** |

3. راجع البنود سطراً سطراً (كل بند مربوط بقيوده للتدقيق)، ثم **«إغلاق الفترة»** فـ**«تقديم»** — تصبح `filed` وترفض أي ترحيل جديد داخل يونيو.

> **لماذا من الأرجل لا الرؤوس؟** حقل `vat_amount` في رأس الفاتورة يكذب عند المردودات اللاحقة والخصومات والتعديلات. الأرجل المرحّلة هي الحقيقة المدققة الوحيدة.

## قواعد مهمة — ملخص سريع

| القاعدة | التفصيل |
|---|---|
| الإقرار من الأرجل حصراً | `SUM(je.credit) − SUM(je.debit)` على حسابي الضريبة للفترة — لا قراءة من رؤوس الفواتير |
| `YE` صفرية لا استثناء | المحرك يعاملها كدولة بنسبة 0% — لا فروع `if country` متناثرة |
| الترحيل القديم بفترة جديدة | مسودة قديمة تُرحَّل اليوم تفحص فترة **اليوم** لا فترة الإنشاء |
| الإغلاق قبل التقديم | لا تقديم لفترة مفتوحة — أغلق أولاً ثم قدّم |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «الفترة الضريبية مغلقة/مقدمة» | تاريخ الترحيل داخل فترة `closed/filed` | رحّل بتاريخ في فترة مفتوحة، أو أعد فتح الفترة بصلاحية مخولة |
| إقرار يخالف توقعك من الفواتير | فواتير مسودة غير مرحّلة، أو مردودات لاحقة | قارن ببنود الأرجل سطراً سطراً — المسودات لا تدخل الإقرار |
| نسبة غير متوقعة على فاتورة | الدولة المضبوطة ليست ما تظن | راجع بطاقة الولاية `tax.country_code` في بيانات الشركة |

## نصائح

- أغلق كل فترة فور تقديم إقرارها — الفترة المفتوحة المتروكة دعوة لخطأ بتاريخ قديم.
- قبل الإغلاق اطبع مسودة الإقرار وقارن صافي المخرجات بإجمالي ضريبة فواتير المبيعات المرحّلة للفترة.
- غيّرت دولتك؟ حدّث الولاية **قبل** أي فاتورة جديدة — الفواتير المرحّلة لا يعاد تسعيرها بأثر رجعي.
