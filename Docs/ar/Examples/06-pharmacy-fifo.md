# مثال 06 — صيدلية الشفاء (FIFO ومردود وعجز وسداد)

> طبقتا شراء بسعرين، بيعان يأكلان الأقدم، مرتجع بالتكلفة المجمدة، عجز جرد، وسداد مورد مربوط. المخزون الختامي 25 وحدة × 1,200 = 30,000 يطابق الطبقات.

## 12. قائمة المقارنة واكتشاف الأخطاء

1. (الطبقات) 25 × 1,200 = 30,000 يطابق `11301` — أي فرق يعني استهلاكاً من طبقة خاطئة.
2. (الموردون) 70,000 = 220,000 − 150,000 — السداد بلا ربط يبقيه 220,000 مع اختلاف التوزيع على الفواتير.
3. تكلفة المرتجع بسعر الطبقة (1,200) لا بسعر الشراء الأول (1,000).
4. العجز `52901` مصروف لا تخفيض مبيعات — خلطهما يضخّم المجمل ويخفي الفاقد.
5. خطأ شائع: البيع الثاني بتكلفة المتوسط (≈1,048) بدل طبقة FIFO (1,200) — يكسر المطابقة.
