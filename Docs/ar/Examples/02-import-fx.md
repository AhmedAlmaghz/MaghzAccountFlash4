## 11. قائمة المقارنة واكتشاف الأخطاء

1. (الموردون) 5,100,000 = 15,000,000 − 9,000,000 − 1,500,000 + 600,000 — نسيان التقييم ينقص 600,000.
2. (المخزون) 4,500,000 بعد المرتجع — إدخال المرتجع سنداً بلا أثر مخزني يبقيه 6,000,000.
3. اتجاه الفرق: استلام أكبر مما قُيِّد = مكسب دائن؛ استلام أقل = خسارة مدينة.
4. (التدفق) رصيد الصندوقين معاً 8,000,000 — احتساب الرئيسي وحده (6,000,000) يخفي التحويل.
5. خطأ شائع: التطبيق بسعر الدفع بدل سعر الفاتورة — يحرّف المستحق ويخفي الفرق.
