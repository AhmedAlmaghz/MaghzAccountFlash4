3. (السلف) 30,000 أصل متداول — تسجيلها مصروفاً يضخّم المصروفات ويخفي الحق.
4. (العملاء) 70,000 فقط — أي رقم أكبر يعني تحصيلاً أو مرتجعاً ناقصاً.
