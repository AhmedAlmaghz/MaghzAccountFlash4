# مرتجعات الشراء — دليل الاستخدام

> رد بضاعة إلى المورد: يخرج المخزون وينقص رصيد المورد ويصدر قيد مرتجع المشتريات — ذرياً عند الترحيل.

## نظرة عامة

مرتجع الشراء (Purchase Return) يوثّق رد بضاعة مشتراة إلى المورد: بضاعة تالفة أو مخالفة للمواصفات أو فائضة عن الحاجة. تصل إليه من: **القائمة الجانبية ← المشتريات ← المرتجعات** (`/purchases/returns`).

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض القائمة والتفاصيل | `purchases.view` |
| إنشاء/تعديل مرتجع | `purchases.create` / `purchases.edit` |
| حذف مسودة | `purchases.delete` |
| ترحيل مرتجع | `purchases.post` |

## القائمة

جدول يعرض: رقم المرتجع، المورد، **فاتورة الشراء المرتبطة** (إن وُجدت)، التاريخ، الإجمالي، **السبب**، الحالة، وأزرار الإجراءات.

- **بحث** برقم المرتجع واسم المورد + **فلتر الحالة** + **فلتر المورد** + **ترقيم صفحات** من الخادم.
- **تصدير Excel/PDF** للنتائج المعروضة.

## شاشة المرتجع الجديد

- **الوصول:** القائمة ← المشتريات ← المرتجعات ← زر **«مرتجع جديد»**
- **الغرض:** توثيق رد بضاعة إلى مورد

### الحقول

| الحقل | الوصف | إلزامي |
|---|---|---|
| **رقم المرتجع** | يُولَّد تلقائياً ببادئة `PR-` من تسلسل المستندات | تلقائي |
| **المورد** | الجهة المُراد رد البضاعة إليها | نعم |
| **فاتورة الشراء** | **ارتباط اختياري** بفاتورة شراء — عند اختيارها تُحمَّل بنودها للمساعدة | اختياري |
| **التاريخ** | تاريخ رد البضاعة | نعم |
| **البنود** | المنتج، الوحدة بمعاملها، الكمية المرتجعة، سعر الوحدة | نعم |
| **السبب** | تلف، مخالفة مواصفات، فائض… يظهر في القيد والقائمة | يُستحسن |

ملاحظة عن الاختلاف مع مرتجع المبيعات: الارتباط بفاتورة الشراء **اختياري** هنا (لا إلزام)، لأن بعض الردود تحدث لاحقاً أو باتفاق عام مع المورد — لكن الربط بالفاتورة يبني كشف حساب أدق.

## دورة حياة المستند

| الحالة | المعنى | ماذا يمكن فعله فيها |
|---|---|---|
| **مسودة** (Draft) | لم تؤثر في شيء | تعديل، حذف، **ترحيل** |
| **مُرحّلة** (Posted) | خرج المخزون ونقص رصيد المورد وصدر القيد | قراءة وطباعة فقط |
| **ملغاة** (Cancelled) | أُلغيت قبل الترحيل | قراءة فقط |

**التعديل والحذف للمسودة فقط** — المُرحَّل سجل محاسبي ثابت.

## آثار الترحيل (ذري)

زر **«ترحيل»** ينفّذ **معاملة واحدة** تنجح كلها أو يتراجع كل شيء:

| الأثر | التفصيل |
|---|---|
| **قيد مرتجع المشتريات** | مدين **ذمم دائنة (المورد)** بالإجمالي / دائن **مرتجعات المشتريات** — عكس اتجاه الفاتورة |
| **خروج مخزون** | حركات بنوع `out` بمرجع رقم المرتجع + **نقص الكمية** بالوحدة الأساسية |
| **نقص رصيد المورد** | رصيد المورد ينقص بإجمالي المرتجع — يقل ما عليك له |
| **الحالة** | تُقلب إلى **مُرحّل** داخل المعاملة نفسها |

بعد الترحيل: سند صرف لاحق يُسوّى على المستحق المتبقي (فواتير المرتجع المُرحّلة تُحسم من رصيد المورد عبر الكشف وأعمار الذمم).

## سير عمل خطوة بخطوة — مثال رقمي

ردت 2 كرتونة عصير تالفة إلى مخازن الخير من فاتورة `PINV-00030`:

1. القائمة ← المشتريات ← المرتجعات ← **«مرتجع جديد»**.
2. الرقم يظهر تلقائياً: `PR-00004`.
3. المورد: «مخازن الخير للتوزيع». **فاتورة الشراء:** اختر `PINV-00030` — تُحمَّل بنودها (كرتونات بسعر شراء 6,000).
4. الكمية المرتجعة: `2` كرتونة. السبب: «تلف تبريد — 2 كرتونة من دفعة 2026-09-12».
5. الإجمالي = `12,000`. **حفظ** → مسودة `PR-00004` (لا شيء تغير بعد).
6. اتفقت مع المورد على الرد ثم اضغط **«ترحيل»** — الأثر الذري:

| الأثر | التفصيل |
|---|---|
| المخزون | خروج `2 × 12 = 24` قطعة أساسية، حركة `out` بمرجع `PR-00004` |
| رصيد المورد | 635,240 − 12,000 = **623,240** ر.ي |

قيد اليومية الناتج:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---:|---:|
| ذمم دائنة — مخازن الخير | 12,000 | |
| مرتجعات المشتريات | | 12,000 |

7. افتح كشف حساب المورد: تجد سطر المرتجع مديناً ينقص الرصيد المتجدد، وتبويب أعمار الذمم محدّث بالمستحق الجديد.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| اتجاه معاكس للشراء | قيد عكسي + مخزون يخرج + رصيد مورد ينقص |
| الارتباط بالفاتورة اختياري | لكن الربط يعطي كشفاً وأعمار ذمم أدق |
| الخروج بالوحدة الأساسية | كرتونة مرتجعة = 12 قطعة أساسية تخرج من المخزون |
| المُرحَّل ثابت | التصحيح بمرتجع جديد معاكس أو قرار إداري |
| السبب موثّق | السبب يظهر في القيد والقائمة — اجعله واضحاً وقابلاً للمراجعة |
| الترحيل ذري | القيد + المخزون + الرصيد تنجح معاً أو يتراجع كل شيء |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «Return not found or not in draft status» | ترحيل مرتجع مُرحّل سابقاً | راجع حالته من القائمة |
| «Cannot modify lines of a posted return.» | تعديل بنود مرتجع مُرحّل | أنشئ مرتجعاً معاكساً |
| «Cannot delete posted return…» | حذف مرتجع غير مسودة | المسودات فقط تُحذف |
| الرصيد لم ينقص بعد الحفظ | المرتجع مسودة | رحّله |
| المخزون خرج من مستودع غير المتوقع | الترحيل يعمل على المستودع الافتراضي | انقل الأثر بتحويل مخزون، أو اعتمد هذا المستودع أساسياً |
| المرتجع أكبر من رصيد المورد | رددت أكثر مما اشتريت فعلياً | راجع الكميات — الرصيد قد يصبح دائناً بمعنى سالب (دفع قبلاً) |

## نصائح

- اربط المرتجع **بفاتورة الشراء** كلما أمكن — كشف المورد يبقى متسقاً مع فواتيره.
- وثّق السبب بدقة مع الدفعة والتاريخ — يحميك في نزاع المورد بعد أسابيع.
- ردّ البضاعة قبل ترحيل المرتجع؟ اتركه مسودة حتى يخرج فعلاً — المخزون يخصم لحظة الترحيل.
- راجع فلتر «مسودة» أسبوعياً — مرتجع منسي يعني مخزوناً زائداً ورصيد مورد أعلى من الحقيقة.
- طابق مرتجعاتك مع إشعارات دائن المورد شهرياً — الفارق يُكتشف مبكراً لا في نهاية السنة.
