# الموردون — دليل الاستخدام

> سجل الموردين الكامل: بيانات، رصيد افتتاحي دائن يُرحَّل مرة واحدة، وبطاقة مورد بتبويبَي كشف حساب وأعمار الذمم الدائنة.

## نظرة عامة

المورد هو الطرف الذي تشتري منه، وذممه **دائنة** (Accounts Payable): ما عليك له من مستحقات. تصل إلى الشاشة من: **القائمة الجانبية ← المشتريات ← الموردون** (`/purchases/suppliers`).

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض القائمة والبطاقة والكشوف | `purchases.view` |
| إضافة/تعديل مورد | `purchases.create` / `purchases.edit` |
| حذف مورد | `purchases.delete` — يُحظر مع وجود فواتير أو مرتجعات |

## قائمة الموردين

جدول يعرض: الكود، الاسم، الهاتف، **الرصيد** (دائن = ما عليك له)، حالة التفعيل، وأزرار الإجراءات.

- **بحث** بالاسم والهاتف والكود + **فلتر التفعيل** + **ترقيم صفحات** من الخادم.
- **تصدير** القائمة المعروضة.
- **إضافة مورد جديد** محمية بصلاحية `purchases.create`.

## شاشة المورد الجديد

- **الوصول:** القائمة ← المشتريات ← الموردون ← زر **«مورد جديد»**
- **الغرض:** فتح ملف مورد

### الحقول

| الحقل | الوصف | إلزامي |
|---|---|---|
| **الكود** | يُولَّد تلقائياً من تسلسل المستندات | تلقائي |
| **الاسم** | اسم المورد أو المؤسسة | نعم |
| **الهاتف / البريد** | بيانات التواصل | اختياري |
| **العنوان** | يظهر في مستندات المشتريات | اختياري |
| **الرقم الضريبي** | لتقارير ضريبة المدخلات | اختياري |
| **مفعّل** | المورد غير المفعّل يختفي من قوائم الفواتير الجديدة | نعم |

### الرصيد الافتتاحي الدائن

| الحقل | الوصف |
|---|---|
| **الرصيد الافتتاحي** | المبلغ **الدائن** (ما عليك للمورد) قبل بدء استخدام النظام |
| **تاريخ الافتتاح** | يرتّب سطر الافتتاحي في كشف الحساب وأعمار الذمم |

**كيف يُرحَّل:** عند الحفظ يُنشأ **قيد يومية** مرة واحدة: مدين «حساب حقوق الملكية الافتتاحية» / دائن «ذمم دائنة (الموردون)» × المبلغ. ثم **يُقفل** — لا يُرحَّل الافتتاحي ثانيةً حتى لو عدّلت بيانات المورد.

## بطاقة المورد — التبويبات

### 1) التفاصيل

كل بيانات البطاقة + ملخص الرصيد — نموذج مشابه لبطاقة العميل لكن الأثر **دائن**.

### 2) كشف الحساب

**دفتر حساب كامل** للتعاملات مع المورد برصيد متجدد:

| نوع السطر | مدين | دائن |
|---|---|---|
| **رصيد افتتاحي** | | المبلغ الدائن الافتتاحي |
| **فاتورة شراء** (مُرحّلة) | | إجمالي الفاتورة — يزيد ما عليك |
| **سند صرف** (مُرحّل) | مبلغ السداد — ينقص ما عليك | |
| **مرتجع مشتريات** (مُرحّل) | إجمالي المرتجع — ينقص ما عليك | |

- **معادلة الرصيد المعروض:** `الرصيد = فواتير الشراء − سندات الصرف − مرتجعات الشراء المُرحّلة` (+ الافتتاحي).
- الرصيد الموجب = **ذمم دائنة** (عليك للمورد).
- **قابل للطباعة** — كشف رسمي بترويسة الشركة لإرساله للمورد.

### 3) أعمار الذمم الدائنة

تقسيم المستحق للمورد على **فئات 0-30 / 31-60 / 61-90 / 90+ يوماً** حسب تاريخ الاستحقاق — أساس تخطيط السداد وأولويات الدفع.

## سداد الموردين

السداد لا يتم من شاشة المورد، بل عبر **سندات الصرف** من وحدة **المحاسبة**: أنشئ سند صرف للمورد يربط بالفواتير المُرحّلة المسددة — السند يُرحَّل بقيد (مدين ذمم دائنة / دائن الصندوق أو البنك)، **ينقص رصيد المورد**، ويقلب حالة الفواتير المسددة إلى **مدفوعة جزئياً أو مدفوعة**.

## سير عمل خطوة بخطوة — مثال رقمي

فتح مورد جديد مع رصيد افتتاحي:

1. القائمة ← المشتريات ← الموردون ← **«مورد جديد»**.
2. الكود يظهر تلقائياً. الاسم: «مخازن الخير للتوزيع». الهاتف: `712345678`.
3. الرصيد الافتتاحي: `500,000` ر.ي (عليك له)، تاريخ الافتتاح: `2026-09-01`.
4. **حفظ** — يُرحَّل القيد الافتتاحي مرة واحدة:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---:|---:|
| حقوق الملكية الافتتاحية | 500,000 | |
| ذمم دائنة (الموردون) | | 500,000 |

5. افتح البطاقة ← تبويب **كشف الحساب**: أول سطر «رصيد افتتاحي — دائن 500,000 — الرصيد المتجدد 500,000».
6. بعدها استلمت فاتورة شراء `PINV-00030` بمبلغ 900,000 ورحّلتها: سطر دائن → الرصيد **1,400,000**.
7. صرفت 600,000 بسند صرف مربوط بالفاتورة: سطر مدين → الرصيد **800,000**، وحالة `PINV-00030` تقلب **مدفوعة جزئياً** — وينعكس التقادم في تبويب أعمار الذمم.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| الافتتاحي دائن ومرة واحدة | يُرحَّل لحظة الإنشاء فقط ثم يقفل الحقل |
| الكشف يعرض المرحّل فقط | المسودات لا تدخل الكشف ولا الرصيد |
| السداد عبر سندات الصرف | لا حقل «دفع» في شاشة المورد — كل السداد من المحاسبة |
| الفاتورة الملغاة مستبعدة | لا تدخل الرصيد ولا الكشف |
| الحذف محمي | مورد له فواتير لا يُحذف — عطّله بدلاً من حذفه |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «Cannot delete supplier with existing…» | للمورد فواتير أو مرتجعات | عطّل المورد بدل الحذف |
| حقل الرصيد الافتتاحي مقفل | الافتتاحي رُحِّل عند الإنشاء | التصحيح بقيود يومية من وحدة المحاسبة |
| الرصيد لا يعكس فاتورة جديدة | الفاتورة ما زالت مسودة | رحّل الفاتورة لتدخل الرصيد والكشف |
| الفاتورة لم تقلب «مدفوعة» بعد الصرف | سند الصرف لم يُرحَّل أو لم يربط بالفواتير | رحّل السند وتأكد من ربط الفواتير المسددة |
| المورد لا يظهر في قائمة الفاتورة | غير مفعّل | فعّله من بطاقته |

## نصائح

- راجع تبويب **أعمار الذمم الدائنة** قبل أي دفعة — ادفع الأقدم أولاً للحفاظ على ثقة المورد.
- اطبع كشف الحساب وأرسله مع كل دفعة كبيرة — يمنع معظم الخلافات مع الموردين.
- املأ **الرقم الضريبي** للمورد — تقارير ضريبة المدخلات تحتاجه للمطابقة.
- استخدم فلتر التفعيل لإخفاء الموردين المتوقفين دون فقدان تاريخهم المحاسبي.
- لا تنشئ مورداً جديداً لكل فاتورة متفرقة من نفس الجهة — التوحيد يجعل الكشف والأعمار مفيدة.
