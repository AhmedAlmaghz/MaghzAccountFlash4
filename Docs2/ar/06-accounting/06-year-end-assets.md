# الإقفال السنوي والأصول الثابتة والعكس — دليل الاستخدام

> إغلاق السنة بقيد `CLS-YYYY`، سجل الأصول الثابتة برسملة إجبارية وإهلاك شهري، وتصحيح المُرحَّل بالعكس الحقيقي — بلا تعديل للماضي.

## نظرة عامة

ثلاث أدوات تحمي سلامة الدفاتر عبر الزمن: **الإقفال السنوي** يختم السنة ويمنع الترحيل فيها، **سجل الأصول** يرسمل المشتريات الرأسمالية ويهلكها شهرياً، و**العكس** يصحح الأخطاء المرحّلة دون مساس بالأصل. تجدها في: **القائمة الجانبية ← المحاسبة ← الإقفال السنوي** (`/accounting/year-end`) و**المحاسبة ← الأصول الثابتة** (`/accounting/fixed-assets`) وزر **«عكس»** على القيود والفواتير والسندات المرحّلة.

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض الإقفال والأصول والعكس | `accounting.view` |
| إنشاء أصل / تشغيل الإهلاك الشهري | `accounting.create` |
| إقفال السنة (`CLS-YYYY`) | `accounting.post` |
| عكس قيد/فاتورة/سند مُرحّل | `accounting.post` (نفس صلاحية الترحيل) |

## الإقفال السنوي

### الشاشة

- **الوصول:** القائمة الجانبية ← المحاسبة ← الإقفال السنوي.
- **الغرض:** معاينة نتيجة السنة (إيرادات ومصروفات وصافي)، ثم إقفالها بقيد نظامي واحد.
- **الحقول:** السنة المالية (تُشتق حدودها من بداية السنة المالية `fiscal_year_start` في إعدادات الشركة).
- **الأزرار:** «معاينة» (`previewFiscalClose`) ثم «إقفال السنة» (`closeFiscalYear`).

### دورة حياة السنة

| الحالة | المعنى | ماذا يمكن فعله |
|---|---|---|
| **مفتوحة** (open) | الترحيل مسموح بتواريخ داخلها | ترحيل عادي + معاينة الإقفال |
| **مغلقة** (closed) | مختومة بقيد `CLS-YYYY` | لا ترحيل جديد بتاريخ داخلها إطلاقاً — التصحيح في السنة المفتوحة |

### سير عمل خطوة بخطوة — مثال رقمي

سنة 2026: إيرادات 12,000,000 ر.ي ومصروفات 9,500,000 — الصافي **2,500,000** ربح:

1. افتح الإقفال السنوي واختر السنة `2026` واضغط **«معاينة»** — يعرض النظام:
   - إجمالي الإيرادات (حركة الحسابات من نوع إيراد).
   - إجمالي المصروفات.
   - الصافي المتوقع ترحيله للأرباح المحتجزة.
2. اضغط **«إقفال السنة»** — يُرحَّل قيد واحد مرجعه `CLS-2026`:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---|---:|
| الإيرادات (إقفال) | 12,000,000 | |
| المصروفات (إقفال) | | 9,500,000 |
| الأرباح المحتجزة (الصافي) | | 2,500,000 |

3. تُقلب حالة السنة إلى **مغلقة** (`accounting_periods.status='closed'`) — أي ترحيل لاحق بتاريخ داخل 2026 **يُرفض برسالة صريحة**.
4. الحراس: لا إقفال لسنة لم تنتهِ بعد، ولا إقفال سنة وتحتها سنة مفتوحة أقدم، ولا إقفال مكرر (المرجع `CLS-2026` موجود ← رفض «السنة مقفلة مسبقاً»).

## الأصول الثابتة

### الشاشة

- **الوصول:** القائمة الجانبية ← المحاسبة ← الأصول الثابتة.
- **الغرض:** سجل كل أصل (الاسم، الكود `FA-`، الفئة، تاريخ الشراء، التكلفة، القيمة المتبقية، العمر بالأشهر، الطريقة: ثابت/متناقص).
- **الحالة:** `active` (عامل) ← `disposed` (مستبعد) — نهائية.

### سير عمل خطوة بخطوة — مثال رقمي

شراء سيارة توصيل **6,000,000** ر.ي نقداً، عمر 60 شهراً، طريقة القسط الثابت:

1. اضغط **«أصل جديد»** واختر التمويل: **خزينة** (الصندوق) — **الرسملة جزء من الإنشاء نفسه** (ليست خطوة لاحقة):

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---|---:|
| الأصول الثابتة بالتكلفة `12101` | 6,000,000 | |
| الصندوق (الخزينة المختارة) | | 6,000,000 |

2. شهرياً اضغط **«تشغيل الإهلاك»** — القسط = 6,000,000 ÷ 60 = **100,000**:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---|---:|
| مصروف الإهلاك | 100,000 | |
| مجمع الإهلاك `12102` (contra بطبيعة دائنة) | | 100,000 |

3. التشغيل **idempotent**: نفس الشهر مرتين لا يكرر القيد (مرجع `DEP-YYYYMM` موجود ← تخطٍّ آمن).
4. الاستبعاد (بيع السيارة بـ 1,000,000 بعد إهلاك متراكم 2,000,000):

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---|---:|
| مجمع الإهلاك `12102` | 2,000,000 | |
| الصندوق (المتحصل) | 1,000,000 | |
| خسائر استبعاد أصول | 3,000,000 | |
| الأصول بالتكلفة `12101` | | 6,000,000 |

### قواعد الأصول

| القاعدة | التفصيل |
|---|---|
| التكلفة وتاريخ الشراء مقفلان بعد أول إهلاك | التعديل بعده ممنوع — التصحيح بقيد تسوية |
| حذف الأصل النظيف فقط | أصل بلا أي إهلاك مرحّل فقط يُحذف |
| لا إهلاك للمستقبل | التشغيل يرفض الشهور اللاحقة لتاريخ اليوم |

## العكس الحقيقي (Reversal)

| الأصل المُرحَّل | ماذا يفعل العكس | الأثر |
|---|---|---|
| **قيد يدوي** | مرآة `REV-`<المرجع> تعكس المدين↔الدائن | الأصل يبقى مُرحّلاً؛ التقارير (مجموع مرجّح) تصفّر الأثر |
| **فاتورة مبيعات/مشتريات** | مرتجع حقيقي **للباقي فقط** (المفوتر − المرتجع سابقاً لكل صنف) عبر الإنشاء والترحيل الحقيقيين | العكس المزدوج **مستحيل رياضياً** — الباقي الصفري يُرفض |
| **سند قبض/صرف** | مرآة **الأرجل الفعلية** للقيد الأصلي (لا تقدير مُعاد) + قلب حالة السند إلى `reversed` | لا عكس ثانٍ — الحارس يرفض `REV-` موجوداً |

### مثال رقمي — عكس سند صرف

سند صرف مرحّل 500,000 (مصروف إيجار مدين / صندوق دائن). العكس يولّد:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---|---:|
| الصندوق | 500,000 | |
| مصروف الإيجار | | 500,000 |

ويُقلب السند إلى `reversed` مع مرجع `REV-` الخاص به — محاولة عكس ثانية تُرفض.

## قواعد مهمة — ملخص سريع

| القاعدة | التفصيل |
|---|---|
| السنة المقفلة أرشيف | أي تصحيح يخصها يُسجَّل في السنة المفتوحة بقيد تسوية مع إشارة مرجعية |
| الرسملة جزء من إنشاء الأصل | سجل بلا قيد = أصول ناقصة ونفقات رأسمالية مخفية — نفس المعاملة الذرية دائماً |
| الإهلاك المتناقص لا يكسر المتبقي | الطريقة المتناقصة (DDB) تتوقف عند القيمة المتبقية ولا تتجاوزها |
| عكس الفاتورة = الباقي فقط | `المتبقي = المفوتر − المرتجع` لكل صنف — رفض الصفر يمنع التضخيم |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «السنة مقفلة مسبقاً» / `CLS-2026` موجود | إقفال مكرر | لا شيء — السنة مختومة فعلاً |
| «لا يمكن الإقفال — سنة لاحقة مقفلة» | كسر الترتيب الزمني | افتح السنوات بالترتيب الصحيح أولاً |
| «عُكس مسبقاً» | مرجع `REV-` موجود | راجع القيد العكسي الموجود |
| «الفاتورة مُعكوسة بالكامل أو مُرتجعة» | الباقي صفر لكل الأصناف | لا عكس جديد — البنود كلها مُغطاة |
| «العكس للمرحّل فقط» | محاولة عكس مسودة | رحّل أولاً أو احذف المسودة |

## نصائح

- اقفل السنة فور اعتماد القوائم — كل يوم تأخير نافذة خطأ بتاريخ قديم.
- سمِّ أصولك بأكواد `FA-` متسلسلة واربط كل أصل بصورته وفواتيره في المرفقات.
- قبل الاستبعاد اطبع بطاقة الأصل (التكلفة − المجمع = الصافي) وقارنها بسعر البيع لتوقع الربح/الخسارة.
