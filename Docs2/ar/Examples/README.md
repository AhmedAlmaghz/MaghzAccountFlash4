# أمثلة تدريبية محلولة — دليل الاستخدام

> 10 أمثلة كاملة لشركات متنوعة: كل مثال ببطاقة شركة ورصيد افتتاحي وعمليات، ثم **الحل الكامل** (القيود، الميزان، الدخل، المركز المالي، التدفق النقدي) وقائمة مقارنة لاكتشاف الأخطاء.

## كيف تستخدم هذه الأمثلة؟

1. أنشئ شركة جديدة في النظام بنفس بطاقة المثال (العملة، الولاية الضريبية، طريقة التقييم).
2. أدخل الرصيد الافتتاحي ثم العمليات **مسودات** ورحّلها واحدة واحدة.
3. استخرج من النظام: ميزان المراجعة، قائمة الدخل، المركز المالي، التدفق النقدي (وكشف الأعمار حيث ينطبق).
4. قارن سطراً بسطر مع «الحل الصحيح» في الملف — أي فرق يعني خطأ إدخال أو ترحيل، وقائمة المقارنة ترشدك لمكانه.

> جميع الأرقام **موثقة حسابياً آلياً**: كل قيد متوازن، ومعادلة الميزانية صفرية في كل مثال.

## منهجية كل مثال (دورة نظام كاملة)

كل مثال يغطي بنفس الترتيب: **(1)** بيانات أساسية (صناديق وخزائن، عملاء وموردون، موظفون، منتجات ووحدات وباركود، مخازن، وقائمة مواد أو عميل محتمل حيث يناسب النشاط) ← **(2)** رصيد افتتاحي ← **(3)** عمليات مؤرخة بمسار الشاشة (فواتير مبيعات ومشتريات، سندات مربوطة، مرتجعات، رواتب ومسيرات، سلف وعهد وتسوياتها، ورديات POS، أصول وإهلاك) ← **(4)** قيود مرحّلة ← **(5)** القوائم الختامية ← **(6)** قيد الإقفال `CLS` وميزان ما بعد الإقفال ← **(7)** قائمة مقارنة بشاشات النظام.

## خريطة تغطية العناصر

| العنصر | أين يظهر |
|---|---|
| صناديق وخزائن مربوطة بحسابات | كل الأمثلة (جدول الصناديق) + تحويل بين صندوقين (02) |
| عملاء وموردون بأرصدة وتسويات | كل الأمثلة + عميل من محتمل (03، 05، 10) |
| موظفون وسلف وعهد | 01، 03، 05، 07، 09، 10 |
| منتجات ووحدات وباركود ومخازن | 01، 02، 03، 04، 06، 07، 08، 10 |
| قائمة مواد وأوامر تشغيل | 04 |
| فواتير مبيعات ومشتريات (نقدي وآجل) | كل الأمثلة |
| سندات مربوطة بالفواتير | 01، 02، 03، 04، 05، 06، 07، 08، 09، 10 |
| مرتجعات مبيعات ومشتريات | 01، 02، 03، 04، 06، 10 |
| رواتب ومسيرات ومخصصات | 05، 09 (+ رواتب مباشرة في البقية) |
| أصول ثابتة وإهلاك | 01، 08 |
| ورديات POS وفروق تلقائية | 07 |
| إقفال ختامي `CLS` | كل الأمثلة |
| خدمات بلا مخزون | 05، 08، 09 |
