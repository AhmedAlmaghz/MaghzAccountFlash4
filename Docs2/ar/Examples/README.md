# أمثلة تدريبية محلولة — دليل الاستخدام

> 10 أمثلة كاملة لشركات متنوعة: كل مثال ببطاقة شركة ورصيد افتتاحي وعمليات، ثم **الحل الكامل** (القيود، الميزان، الدخل، المركز المالي، التدفق النقدي) وقائمة مقارنة لاكتشاف الأخطاء.

## كيف تستخدم هذه الأمثلة؟

1. أنشئ شركة جديدة في النظام بنفس بطاقة المثال (العملة، الولاية الضريبية، طريقة التقييم).
2. أدخل الرصيد الافتتاحي ثم العمليات **مسودات** ورحّلها واحدة واحدة.
3. استخرج من النظام: ميزان المراجعة، قائمة الدخل، المركز المالي، التدفق النقدي (وكشف الأعمار حيث ينطبق).
4. قارن سطراً بسطر مع «الحل الصحيح» في الملف — أي فرق يعني خطأ إدخال أو ترحيل، وقائمة المقارنة ترشدك لمكانه.

> جميع الأرقام **موثقة حسابياً آلياً**: كل قيد متوازن، ومعادلة الميزانية صفرية في كل مثال.
