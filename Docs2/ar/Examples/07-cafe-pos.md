# مثال 07 — كافيه الديوان POS (ورديات وفرق صندوق)

> ورديتان: مبيعات نقدية وآجلة، إغلاق بعجز يُرحَّل تلقائياً (`POS-DIFF`)، وإغلاق مطابق بلا قيد. الآجل لا يدخل الدرج أبداً.

## بطاقة الشركة

| البند | القيمة |
|---|---|
| الاسم | كافيه الديوان |
| العملة الأساسية | YER |
| الولاية الضريبية | `YE` |

## الرصيد الافتتاحي

| الحساب | مدين | دائن |
|---|---|---:|
| الصندوق `11101` (عهدة الدرج 500,000) | 500,000 | |
| رأس المال `31101` | | 500,000 |

## العمليات

| # | العملية | المبلغ (ر.ي) |
|---|---|---:|
| 1 | شراء بضاعة (بن) نقداً | 300,000 |
| 2 | الوردية 1: مبيعات نقدية 250,000 (التكلفة 100,000) | 250,000 |
| 3 | الوردية 1: بيع آجل لعميل مسجل 60,000 (التكلفة 24,000) | 60,000 |
| 4 | إغلاق الوردية 1: المتوقع 250,000، المعدود 248,000 ← عجز 2,000 | 2,000 |
| 5 | الوردية 2: مبيعات نقدية 180,000 (التكلفة 72,000)، والجرد مطابق | 180,000 |
| 6 | مواد تغليف نقداً | 20,000 |

## التدفق النقدي

| البند | المبلغ (ر.ي) |
|---|---:|
| رصيد أول المدة | 500,000 |
| مقبوضات (250,000 + 180,000) | 430,000 |

| **رصيد آخر المدة** | **608,000** |

## قائمة المقارنة واكتشاف الأخطاء

1. المتوقع في الدرج = الافتتاح + النقدية فقط (الآجل 60,000 خارج الحسبة) — إدخاله يضخّم المتوقع ويقلب العجز فائضاً.
2. الوردية 2 المطابقة **بلا قيد فرق** — ظهور `POS-DIFF` لها يعني إغلاقاً مكرراً (القيد idempotent).
3. رصيد العميل 60,000: بيعه كاش خطأً يصفّر الذمم ويضخّم النقدية.
4. خطأ شائع: تسجيل العجز مصروفاً يدوياً **ثم** الإغلاق التلقائي — ازدواج 4,000. الطريقة واحدة فقط.
