# اختصارات لوحة المفاتيح

> مرجع كامل للاختصارات المتاحة في النظام — مصممة لعمل سريع بالكيبورد دون الفأرة، خصوصاً في نقاط البيع.

## ملخص سريع

| الاختصار | السياق | الوظيفة |
|---|---|---|
| `Ctrl + K` | كل الصفحات | فتح/إغلاق لوحة الأوامر (Command Palette) |
| `Ctrl + Shift + K` | كل الصفحات | فتح/إغلاق الدردشة العائمة للوكيل الذكي «مغزى» |
| `F2` | شاشة نقاط البيع | التركيز على حقل البحث/الباركود وتحديد نصه |
| `F9` | شاشة نقاط البيع | فتح شاشة الدفع (إتمام البيع) |
| `F10` | شاشة نقاط البيع | تعليق السلة الحالية (Hold) كمسودة باسم يحمل الوقت |
| `Enter` | حقول البحث | تنفيذ البحث/إضافة الصنف المحدد |
| `↑` / `↓` | لوحة الأوامر | التنقل بين النتائج |
| `Enter` | لوحة الأوامر | فتح الصفحة/الخيار المحدد |
| `Escape` | نوافذ وقوائم | إغلاق النافذة/القائمة/الدردشة المفتوحة |

## نقاط البيع (شاشة الكاشير)

نقاط البيع هي أكثر شاشة غنية بالاختصارات، لأنها مصممة لعمل الكاشير بيد واحدة على الكيبورد:

| الاختصار | الوظيفة | التفاصيل |
|---|---|---|
| `F2` | **التركيز على البحث** | ينقلك فوراً لحقل البحث/الباركود ويحدد النص السابق — اكتب الباركود أو اسم المنتج مباشرة |
| `F9` | **الدفع** | يفتح شاشة الدفع لإتمام البيع (نقدي/آجل/مختلط) |
| `F10` | **تعليق السلة** | يعلّق السلة الحالية كمسودة باسم تلقائي مثل «سلة 14:32» — مفيد عند انتظار عميل وبدء خدمة غيره، وتُستعاد من قائمة السلات المعلقة |
| `Enter` (في حقل البحث) | **مسح الباركود** | يضيف الصنف المطابق للسلة مباشرة — جهاز الباركود يعمل كأنه يكتب ويسبق بـ Enter |

سيناريو كاشير كامل دون فأرة:

1. `F2` ← امسح الباركود (أو اكتب الاسم واضغط Enter) — كرر لكل الأصناف.
2. `F9` ← أدخل المبلغ المستلم واعتمد الدفع.
3. بعد الطباعة: `F2` من جديد للعميل التالي. وعند الازدحام استخدم `F10` لتعليق سلات العملاء المنتظرين.

## لوحة الأوامر (Command Palette)

أسرع طريقة للوصول لأي صفحة في النظام:

| المفتاح | الوظيفة |
|---|---|
| `Ctrl + K` (أو `Cmd + K` على Mac) | فتح اللوحة من أي صفحة — وضغطها مجدداً يغلقها |
| `↑` / `↓` | التنقل بين الصفحات المقترحة (نتائج مرتبة حسب النص المكتوب) |
| `Enter` | فتح الصفحة المحددة |
| `Escape` | إغلاق اللوحة |

اكتب مثلاً «فواتير» وستُقترح صفحات الفواتير ذات الصلة — اللوحة تحتوي كل صفحات النظام المنسوبة لمجموعاتها، وهي أيضاً طريقة ممتازة لاكتشاف صفحات لم تعرف بوجودها.

## الوكيل الذكي «مغزى»

| المفتاح | الوظيفة |
|---|---|
| `Ctrl + Shift + K` | فتح/إغلاق الدردشة العائمة فوق الصفحة الحالية |
| `Escape` | إغلاق الدردشة العائمة (إلا إذا كان المؤشر داخل حقل الكتابة — حتى لا تفقد مسودتك) |
| `Enter` (في حقل الدردشة) | إرسال الرسالة |

> انتبه للفرق: `Ctrl + K` للوحة الأوامر، بينما الدردشة العائمة تحتاج إضافة `Shift` — القصد فصل الأداتين حتى لا تنفجرا معاً.

## النوافذ المنبثقة والقوائم

| المفتاح | الوظيفة |
|---|---|
| `Escape` | إغلاق أي نافذة منبثقة (Modal) مفتوحة — نافذة واحدة فقط، الأعمق أولاً |
| `Escape` | إغلاق قوائم الإجراءات المنسدلة (مثل قائمة أزرار الطباعة/التصدير) |
| `Escape` | إغلاق اللوحة العائمة أو لوحة الأوامر أيهما مفتوح |

## قواعد التعارض والحماية

- اختصارات POS (`F2`/`F9`/`F10`) تعمل فقط داخل شاشة الكاشير — لا تؤثر خارجها.
- `Ctrl + K` و`Ctrl + Shift + K` منفصلان عمداً: ضغط أحدهما لا يفتح الأداة الثانية، فلا تتراكم الطبقات فوق بعضها.
- لوحة الأوامر والدردشة العائمة لا يُفتحان معاً أبداً — ضغط الاختصار الثاني يُدار بمنطق التبديل المفرد.
- داخل حقول النصوص متعددة الأسطر (مثل الدردشة) تحترم الاختصارات الكتابة أولاً: `Enter` يرسل، بينما `Escape` لا يمسح ما كتبته.

## ملاحظات عامة

- الاختصارات عاملة في وضعي الويب وسطح المكتب على حد سواء، ومكتوبة بصيغة Windows/Linux (`Ctrl`) — على Mac استخدم `Cmd` بدل `Ctrl`.
- اختصارات `F9`/`F10` قد تتعارض مع وظائف نظام التشغيل على بعض اللابتوبات (مثل ضبط الإضاءة أو الصوت) — فعّل «Fn Lock» أو استخدم أزرار الشاشة المكافئة.
- جميع الاختصارات تعمل بالكيبورد العربي والإنجليزي على السواء، لأنها مفاتيح وظيفية لا حروف.

## أسئلة سريعة

| سؤال | جواب |
|---|---|
| ضغطت `Ctrl + K` ولم تفتح الدردشة؟ | هذا سلوك صحيح — `Ctrl + K` للوحة الأوامر؛ الدردشة بـ `Ctrl + Shift + K` |
| فُقد التركيز في شاشة الكاشير بعد نافذة منبثقة؟ | اضغط `Escape` لإغلاقها ثم `F2` للعودة لحقل البحث |
| `F10` علّق سلة والآن لا أراها؟ | افتح قائمة السلات المعلقة في شاشة الكاشير واستعدها — لا تُحذف تلقائياً |
| هل توجد اختصارات لإدخال الباركود؟ | لا حاجة لاختصار خاص: الماسح الضوئي يكتب في حقل البحث وينهي بـ `Enter` تلقائياً |

## نصائح

- احفظ ثلاثة فقط لتظل سريعاً: `Ctrl + K` للتنقل، `F2`/`F9` في الكاشير، `Ctrl + Shift + K` لسؤال «مغزى».
- درّب الكاشير الجديد على مسار «مسح ← F9 ← اعتماد» قبل أول وردية مستقلة.
- اجعل `Ctrl + K` عادتك الأولى: أسرع من التنقل بالقوائم ويعرّفك على كل صفحات النظام.
