# مركز التقارير — دليل الاستخدام

> بوابة موحدة لكل تقارير النظام: شبكة بطاقات تنقلك مباشرة إلى أي تقرير، مع حماية بالصلاحيات وتصدير موحد.

## نظرة عامة

مركز التقارير (Reports Hub) في المسار `/reports` يعرض **12 تقريراً** في شبكة بطاقات ملونة (3 بطاقات بالصف). كل بطاقة تحمل: أيقونة، اسم التقرير، وصفاً من سطرين، ورابط «فتح التقرير ←» مع شارة تُظهر عدد التقارير المتاحة في الترويسة.

## الوصول والصلاحيات

- الصلاحية المطلوبة: `reports.view` لعرض المركز.
- من لا يملك `reports.view` يرى رسالة صريحة «لا تملك صلاحية لعرض هذه الصفحة» بدل شبكة البطاقات.
- **منشئ التقارير المخصص** مخفي تماماً من الشبكة لمن لا يملك `reports.custom`.
- تصدير أي تقرير يتطلب `reports.export` (الأزرار معطلة بدونها).
- البطاقة «نظرة مالية» لا تفتح تقريراً مستقلاً بل تنقلك إلى قائمة المركز المالي في المحاسبة (`/accounting/balance`).
- أزرار التصدير داخل كل تقرير تعمل بنفس الصلاحية `reports.export` — راجع ملف مصفوفة الصلاحيات.

## تفاصيل الفلاتر لكل تقرير

| التقرير | الفلاتر المتاحة |
|---|---|
| تحليل المبيعات | فترة (من/إلى)، عميل محدد، منتج محدد |
| تحليل المخزون | حالة الصنف: الكل / جيد / منخفض / نافد |
| تنبيه النقص | المستودع |
| حركة المخزون | المنتج، الفترة |
| تقييم المخزون | المستودع/الفترة حسب ما يظهر في شريط الفلاتر |
| كشف حساب عميل | فترة (من/إلى) — تُعرض فقط الفواتير ذات رصيد مستحق وغير ملغاة |
| كشف حساب مورد | فترة (من/إلى) |
| تحليل الأرباح | الفترة (من/إلى) |
| تحويل العملاء المحتملين | فترة (من/إلى) مع زر مسح الفلاتر |
| خط أنابيب الفرص | يعرض توزيعاً شاملاً بلا فلاتر تاريخ |
| منشئ التقارير المخصص | اختيار الجدول + الأعمدة + الترقيم (انظر القسم أدناه) |

> الزر «إعادة التصفية» يعيد كل الفلاتر لوضعها الافتراضي في كل التقريرات.

## وصف سريع لكل تقرير (متى تستخدمه)

| التقرير | متى تستخدمه |
|---|---|
| تحليل المبيعات | مراجعة أداء البيع: من يشتري أكثر، وأي المنتجات تبيع |
| تحليل المخزون | لمحة شاملة عن صحة المخزون: ما هو جيد ومنخفض ونافد |
| تنبيه النقص | **يومياً**: ما الذي سينفد قريباً ويحتاج أمر شراء عاجل |
| حركة المخزون | تتبع مصدر أي حركة صرف أو استلام وتوقيتها |
| تقييم المخزون | معرفة قيمة ما في المستودعات بالتكلفة — مدخل ميزانيات ونهاية الفترات |
| كشف حساب عميل | متابعة التحصيل: من يستحق مني كم ومتى أصبح المستحق قديماً |
| كشف حساب مورد | جدولة السداد للموردين حسب عمر المستحق |
| تحليل الأرباح | أي المنتجات تربح فعلياً بعد تكلفة الشراء |
| تحويل العملاء المحتملين | قياس كفاءة فريق المبيعات في تحويل الاتصالات لفرص |
| خط أنابيب الفرص | رؤية الصفقات الجارية وموقعه من مراحل البيع |
| منشئ التقارير المخصص | تقرير مخصص لا يغطيه التقرير الجاهز |

## التصدير والطباعة (عام)

كل تقرير في النظام (وليس المركز فقط) يتبع نفس منظومة التصدير الموحدة:

| الزر | الناتج | ملاحظات |
|---|---|---|
| **تصدير Excel** | ملف `.xlsx` بجدول التقرير | المكتبة تُحمَّل ديناميكياً عند أول ضغطة فقط (لا تُثقل النظام عند الإقلاع) |
| **تصدير PDF** | ملف PDF منسق | يُولَّد عبر مكتبة `jspdf` المحمَّلة ديناميكياً، مع دعم اتجاه RTL |
| **تصدير HTML** | ملف HTML للمشاركة | يحفظ جدول التقرير بصيغة تفتح في أي متصفح |

قواعد مشتركة:

- الملف يحمل ترويسة موحدة: **اسم المنشأة النشطة + اسم التقرير + تاريخ الإنشاء** (هوية التقارير `useReportBranding`).
- اسم الملف مشتق من التقرير والتاريخ، مثال: `SalesAnalysis_2026-09-12`.
- أزرار التصدير تظهر معطلة لمن لا يملك `reports.export`.
- للطباعة الورقية: صدّر PDF ثم اطبعه، أو اطبع ملف HTML من المتصفح.
- التصدير يلتقط ما يعود من الفلاتر الحالية — صدّر بعد ضبط الفلاتر لا قبلها.

## منشئ التقارير المخصص (Custom Report Builder)

أداة تتيح لمالك الحساب بناء تقرير مبسط من جداول البيانات الأساسية دون تدخل تقني:

1. **اختر الجدول** من القوائم المتاحة: فواتير المبيعات، فواتير المشتريات، المنتجات، العملاء، الموردون.
2. **اختر الأعمدة** التي تريد ظهورها — لكل جدول مجموعة أعمدة معرفة مسبقاً.
3. **استعرض النتائج** في جدول مع ترقيم صفحات وأزرار تنقل.
4. **صدّر** الناتج بنفس أزرار التصدير الموحدة (Excel / PDF / HTML).

الأعمدة المتاحة لكل جدول (مختارات):

| الجدول | أمثلة أعمدة |
|---|---|
| فواتير المبيعات | رقم الفاتورة، العميل، التاريخ، الإجمالي، الحالة |
| فواتير المشتريات | رقم الفاتورة، المورد، التاريخ، الإجمالي، الحالة |
| المنتجات | الاسم، رمز SKU، سعر التكلفة، سعر البيع، نشط/موقوف |
| العملاء | الرمز، الاسم، الهاتف، الرصيد |
| الموردون | الرمز، الاسم، الهاتف، الرصيد |

ملاحظات:

- التقرير يلتزم عزل المنشأة تلقائياً — ترى بيانات شركتك فقط مهما كان دورك.
- الأعمدة محددة مسبقاً لكل جدول (لا استعلامات حرة)؛ هذا يضمن ألا يعرض الباني بيانات خارج صلاحياتك.
- مخفي تماماً عن بطاقات المركز لمن لا يملك `reports.custom`.

## أخطاء شائعة وحلولها

| الرسالة/الحالة | السبب | الحل |
|---|---|---|
| «لا تملك صلاحية لعرض هذه الصفحة» في المركز | لا يملك دورك `reports.view` | اطلب منح الصلاحية من الإعدادات ← الأدوار |
| بطاقة منشئ التقارير المخصص غير ظاهرة | لا يملك دورك `reports.custom` | اطلب منح صلاحية التقارير المخصصة |
| أزرار التصدير معطلة | لا يملك دورك `reports.export` | اطلب منح صلاحية التصدير |
| تصدير PDF لا يفتح ملفاً | المتصفح حجب النافذة المنبثقة | اسمح بالنوافذ المنبثقة للموقع ثم أعد التصدير |
| كشف حساب عميل فارغ رغم وجود فواتير | الكشف يعرض فقط الفواتير ذات رصيد غير مسدد وغير ملغاة | تحقق من تسجيل دفعات الفواتير أو من حالة الفاتورة |
| تقرير أعمار الذمم يظهر رصيداً لا تتوقعه | الحساب يعتمد تاريخ الاستحقاق والفرق بين الإجمالي والمدفوع | راجع تواريخ الاستحقاق في الفواتير |
| تنقلك «نظرة مالية» خارج المركز | هذا مقصود — البطاقة تفتح قائمة المركز المالي في المحاسبة | استخدم القائمة الجانبية ← المحاسبة ← المركز المالي |

## نصائح

- ثبّت روتيناً أسبوعياً: تنبيه النقص يوم السبت، كشف حساب عميل يوم الأحد، تحليل الأرباح نهاية الشهر.
- استخدم أعمار الذمم في كشف حساب العميل لتقرير أي العملاء يستحق المتابعة الهاتفية فوراً (فئة 90+ أولوية).
- صدّر كشوف الحسابات PDF وأرسلها للعملاء كمتابعة رسمية شهرية.
- عند الحاجة لتقرير لا يوجد ضمن الـ 12، جرّب منشئ التقارير المخصص قبل طلب تطوير جديد.
- اربط تقارير المركز بصفحة التقارير في القائمة الجانبية — كل بطاقة لها مسار مباشر يمكن حفظه في المتصفح.
