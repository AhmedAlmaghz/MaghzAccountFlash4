# المخازن — دليل الاستخدام

> إدارة كاملة لدورة البضاعة: المنتجات والوحدات، المستودعات، الأرصدة، الحركات، التحويلات، وتسويات الجرد.

## نظرة عامة

وحدة المخازن هي قلب الجرد المستمر (Perpetual Inventory) في النظام: كل فاتورة مبيعات تُرحَّل تُخرج البضاعة، وكل فاتورة شراء تُرحَّل تُدخلها، وكل تسوية جرد تصحح الفروقات — كل ذلك تلقائياً وبقيد محاسبي مصاحب.

تصل إلى الوحدة من: **القائمة الجانبية ← المخازن** (`/inventory`). صفحة المركز تعرض بطاقات التنقل مع عدادات حية.

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض المنتجات والمستودعات والأرصدة والحركات | `inventory.view` |
| إضافة/تعديل منتج أو مستودع أو تحويل أو تسوية | `inventory.create` / `inventory.edit` |
| حذف | `inventory.delete` |
| ترحيل تسوية جرد | `inventory.edit` (مع اعتماد مسبق) |

- كل البيانات معزولة حسب الشركة (`company_id`) — لا ترى إلا بيانات شركتك النشطة.
- دور `viewer` يعرض فقط بلا أزرار إضافة أو تعديل.

## صفحة مركز المخازن

عند فتح `/inventory` تجد بطاقات تنقل رئيسية، كل بطاقة تعرض عداداً حياً:

| البطاقة | المسار | العداد الحي | الوصف |
|---|---|---|---|
| **المنتجات** | `/inventory/products` | إجمالي المنتجات | إدارة المنتجات والتصنيفات والأسعار |
| **المستودعات** | `/inventory/warehouses` | عدد المستودعات | المستودعات وربطها بالفروع |
| **المخزون** | `/inventory/stock` | عدد أسطر الأرصدة | أرصدة المخزون والتحويلات بين المستودعات |
| **الحركات** | `/inventory/transactions` | إجمالي الكميات المتحركة | حركات وارد/صادر/تسوية/تحويل |
| **التسويات** | `/inventory/adjustments` | — | تسويات الجرد والفروقات |
| **تنبيه النقص** | `/reports/low-stock-alert` | عدد الأصناف الناقصة | تقرير أصناف تحت الحد الأدنى |

## التقارير المرتبطة

من **القائمة الجانبية ← مركز التقارير** تجد تقارير المخازن:

| التقرير | الغرض |
|---|---|
| **تنبيه النقص (Low Stock Alert)** | الأصناف التي وصل رصيدها إلى الحد الأدنى أو نقطة إعادة الطلب |
| **حركة المخزون (Item Ledger)** | كشف تفصيلي لحركات صنف واحد خلال فترة |
| **تقييم المخزون (Stock Valuation)** | قيمة المخزون بالكلفة: الكمية × سعر الكلفة |

## بنية الوحدة

```
المخازن
├── المنتجات          ← بطاقة المنتج + الوحدات المتعددة + الرصيد الافتتاحي
├── المستودعات        ← تعريف المستودعات + عرض مخزون كل مستودع
├── المخزون           ← الأرصدة + تبويب التحويلات (TRF-)
├── حركات المخزون     ← سجل كل الحركات (in / out / adjustment / transfer)
└── تسويات المخزون    ← الجرد ودورة الاعتماد والترحيل (ADJ-)
```

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| المخزون بالوحدة الأساسية | كل الأرصدة والحركات تُخزَّن **بالوحدة الأساسية (Base Unit)** — المستندات تثبّت معامل التحويل لحظة الإنشاء |
| الترحيل يحرّك المخزون | لا شيء يتغير في الأرصدة حتى **ترحيل** المستند — المسودات لا تؤثر |
| قيد مصاحب لكل حركة | الترحيل يولّد **قيد اليومية** تلقائياً (مخزون / تكلفة / فرق جرد) |
| الأرصدة لا تقبل التحرير اليدوي | الرصيد يتغير فقط عبر مستند: فاتورة، مرتجع، تحويل، تسوية، أو حركة يدوية بسيطة |
| معزولة لكل مستودع | الرصيد يُتتبَّع لكل (منتج × مستودع) على حدة |

## أخطاء شائعة وحلولها

| الرسالة/الملاحظة | السبب | الحل |
|---|---|---|
| الرصيد لا يتغير بعد حفظ فاتورة | الفاتورة ما زالت **مسودة** | رحّل الفاتورة ليتحرك المخزون ويصدر القيد |
| ظهرت الكمية بالوحدة الأساسية رغم البيع بالكرتونة | المخزون دائماً بالوحدة الأساسية | طبيعي — 2 كرتونة تُخصم 24 وحدة أساسية |
| لا يمكن حذف وحدة المنتج الوحيدة | كل منتج يجب أن يحتفظ بوحدة أساسية واحدة على الأقل | أضف وحدة أخرى أولاً ثم احذف |
| زر «إكمال» التحويل معطل | التحويل مكتمل أو ليس مسودة | أنشئ تحويلاً جديداً |
| لا يمكن ترحيل تسوية | الفرق صفر أو لم يُعتمد | اعتمدها أولاً؛ الفرق الصفري لا يُرحَّل أصلاً |

## نصائح

- ابدأ بتعريف **المستودعات** ثم **الوحدات** (الإعدادات) ثم **المنتجات** — الترتيب يوفر عليك إعادة العمل.
- أدخل **الرصيد الافتتاحي** لكل منتج مرة واحدة عند إنشائه؛ لا يمكن إدخاله لاحقاً من نفس النافذة.
- راجع بطاقة **تنبيه النقص** يومياً — العداد الحي يكشف ما يحتاج طلب شراء فوراً.
- استخدم **التحويلات** لنقل البضاعة بين المستودعات بدل التسويات — التحويل يتتبع الطرفين.
- اجعل **التسوية** آخر حل فقط: للجرد الفعلي وأخطاء العدّ، لا لتصحيح أخطاء المستندات.
