# المستودعات والمخزون — دليل الاستخدام

> تعريف المستودعات وربطها بالفروع، قراءة الأرصدة لحظياً، ونقل البضاعة بين المستودعات بتحويلات مُتتبَّعة.

## نظرة عامة

هذه الشاشة تجمع ثلاث شاشات مترابطة: **المستودعات** (تعريف المواقع)، **المخزون** (الأرصدة لكل منتج × مستودع)، و**التحويلات** (نقل البضاعة مع سجل كامل). تصل إليها من: **القائمة الجانبية ← المخازن ← المستودعات** أو **← المخزون**.

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض المستودعات والأرصدة والتحويلات | `inventory.view` |
| إضافة/تعديل مستودع أو تحويل | `inventory.create` / `inventory.edit` |
| حذف مستودع أو مسودة تحويل | `inventory.delete` |
| إكمال تحويل (تحريك المخزون) | `inventory.edit` |

## شاشة المستودعات

- **الوصول:** القائمة ← المخازن ← المستودعات (`/inventory/warehouses`)
- **الغرض:** تعريف مواقع التخزين وربطها بالفروع

### حقول المستودع

| الحقل | الوصف | إلزامي |
|---|---|---|
| **الاسم** | اسم المستودع المعروض في كل القوائم | نعم |
| **الكود** | رمز مختصر (مثل `WH-MAIN`) | اختياري |
| **الفرع** | ربط المستودع بفرع من فروع الشركة | اختياري |
| **مفعّل** | المستودع غير المفعّل يختفي من قوائم الاختيار الجديدة | نعم |

### الأزرار والإجراءات

- **«عرض المخزون»** لكل مستودع: نافذة تعرض كل الأصناف في هذا المستودع تحديداً (المنتج، الكمية، الوحدة، الكلفة) مع قيمة المخزون الإجمالية.
- تعديل / حذف — الحذف يُحظر إن وُجدت به أرصدة أو حركات.
- **KPIs أعلى الشاشة:** إجمالي المستودعات، المفعّل منها، عدد الفروع المرتبطة، قيمة المخزون الكلية.

## شاشة المخزون (الأرصدة)

- **الوصول:** القائمة ← المخازن ← المخزون (`/inventory/stock`)
- **الغرض:** قراءة الأرصدة الحية لكل (منتج × مستودع)

### ماذا تعرض

| العمود | الوصف |
|---|---|
| المنتج | الاسم والكود |
| المستودع | موقع الرصيد |
| الكمية | بالوحدة الأساسية |
| الوحدة | اسم الوحدة الأساسية |
| الكلفة | سعر كلفة المنتج × الكمية = قيمة السطر |
| تنبيه | أيقونة تحذير إذا نزل الرصيد تحت **الحد الأدنى** (`min_stock_alert`) |

### الفلاتر وKPIs

- **بحث** باسم المنتج أو كوده، **فلتر مستودع**، و**فلتر «إظهار الناقص فقط»** الذي يعرض الأصناف تحت الحد الأدنى.
- **KPIs:** عدد أسطر الأرصدة، إجمالي الكميات، **عدد الأصناف الناقصة** (بشارة «يحتاج طلب»)، قيمة المخزون.
- **تصدير Excel/PDF** للأرصدة المعروضة.

## تبويب التحويلات

نقل بضاعة من مستودع إلى آخر دون بيع أو شراء.

### إنشاء تحويل

- **الوصول:** شاشة المخزون ← تبويب **«التحويلات»** ← زر **«تحويل جديد»**
- **الغرض:** توثيق نقل البضاعة وتنفيذه فعلياً

| الحقل | الوصف | إلزامي |
|---|---|---|
| **رقم التحويل** | بترقيم تلقائي ببادئة `TRF-` من تسلسل المستندات (يمكن تعطيل التوليد) | تلقائي |
| **المنتج** | اختر المنتج | نعم |
| **الوحدة** | وحدة الكمية المنقولة — يُحوَّل داخلياً للوحدة الأساسية | نعم |
| **من مستودع** | مصدر الخروج | نعم |
| **إلى مستودع** | وجهة الدخول — **المستودع نفسه محجوب** من القائمة | نعم |
| **الكمية** | الكمية المنقولة | نعم |
| **المرجع / ملاحظات** | توثيق اختياري | اختياري |

### دورة حياة التحويل

| الحالة | المعنى | ماذا يمكن فعله |
|---|---|---|
| **مسودة / معلق** | موثّق فقط — **لم يتحرك مخزون بعد** | تعديل، حذف، **إكمال** |
| **مكتمل** | نُفِّذ فعلياً: حركتا صادر/وارد + تحديث الأرصدة | قراءة فقط |
| **ملغى** | أُلغي قبل التنفيذ | قراءة فقط |

### زر «إكمال» — التنفيذ الذري

عند الضغط على **«إكمال»** ينفّذ النظام معاملة واحدة (Transaction) فيها:

1. **فحص الكفاية** على مستوى قاعدة البيانات: إذا تجاوز أي سطر رصيد المصدر، يفشل كل شيء — لا يتحرك جزء ولا يبقى التحويل نصف منفذ.
2. إنشاء **حركة صادر** من المستودع المصدر و**حركة وارد** للمستودع الوجهة (نوع الحركة `transfer`).
3. خصم الكمية من رصيد المصدر وإضافتها لرصيد الوجهة (يُنشأ صف رصيد للوجهة إن لم يوجد).
4. قلب الحالة إلى **مكتمل**.

- **حذف المسودات فقط** — التحويل المكتمل سجل محاسبي ثابت لا يُحذف.

## شاشة حركات المخزون

- **الوصول:** القائمة ← المخازن ← الحركات (`/inventory/transactions`)
- **الغرض:** سجل قراءة-غالباً لكل ما تحرك في المخزون

### ماذا تعرض

| العمود | الوصف |
|---|---|
| التاريخ | تاريخ/وقت الحركة |
| النوع | شارة ملونة: `in` (وارد أخضر) / `out` (صادر أحمر) / `adjustment` (تسوية كهرماني) / `transfer` (تحويل أزرق) |
| المنتج | الاسم والكود |
| المستودع | موقع الحركة |
| الكمية | بالوحدة الأساسية |
| المستند المرجعي | رقم الفاتورة/التحويل/التسوية المولّدة للحركة |

### الفلاتر وKPIs

- **فلتر النوع** (وارد/صادر/تسوية/تحويل)، **التاريخ**، **المنتج**، **المستودع**، وبحث نصي في المرجع.
- **KPIs:** عدد الحركات لكل نوع (وارد، صادر، تسوية، تحويل) + الإجمالي.
- **تصدير Excel/PDF** للنتائج المعروضة.

### الإدخال اليدوي للحركات البسيطة

زر **«حركة جديدة»** يفتح نموذجاً مبسطاً للتسويات الصغيرة والواردات الخارجية:

| الحقل | الوصف |
|---|---|
| النوع | وارد (`in`) أو صادر (`out`) أو تحويل أو تسوية |
| المنتج والمستودع والكمية | أساس الحركة |
| المرجع والملاحظات | توثيق حر |

- الحركة الواردة **تزيد** الرصيد، والصادرة **تنقصه** — تُنفَّذ ذرياً مع إنشاء صف الرصيد إن لم يوجد.
- حركات النوع `transfer` المسجلة يدوياً تسجل السطر فقط دون تحريك الأرصدة — استخدم تبويب التحويلات للنقل الفعلي.

## سير عمل خطوة بخطوة — مثال رقمي

نقل 5 كراتين (معامل 12) من «المستودع الرئيسي» إلى «مستودع الفرع»:

1. شاشة المخزون ← تبويب **التحويلات** ← **«تحويل جديد»**.
2. رقم التحويل يظهر تلقائياً: `TRF-00007`.
3. المنتج: «عصير برتقال». الوحدة: **كرتونة**. الكمية: `5`.
4. من مستودع: **المستودع الرئيسي** (رصيده 240 قطعة). إلى مستودع: **مستودع الفرع**.
5. **حفظ** — التحويل مسودة؛ لا شيء تغير في الأرصدة بعد.
6. راجع السطر ثم اضغط **«إكمال»**.
7. النتيجة فورية:

| المستودع | قبل (قطعة أساسية) | بعد (قطعة أساسية) |
|---|---:|---:|
| المستودع الرئيسي | 240 | 240 − 60 = **180** |
| مستودع الفرع | 0 | **60** |

8. تظهر حركتان في سجل الحركات: «تحويل صادر» من الرئيسي و«تحويل وارد» للفرع، بمرجع `TRF-00007`.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| المستودع نفسه محجوب | لا يمكن اختيار نفس المستودع في «من» و«إلى» |
| الكفاية تُفحص عند التنفيذ | فحص ذري داخل المعاملة — لا أرصدة سالبة ولا تنفيذ ناقص |
| المسودة لا تحرّك شيئاً | الأرصدة تتغير فقط لحظة «إكمال» |
| الحركات سجل محاسبي | حركة الفواتير والمستندات تُولَّد تلقائياً — لا تدخلها يدوياً مكررة |
| كل الحركات بالوحدة الأساسية | اختيار الكرتونة يحوَّل داخلياً (5 × 12 = 60) |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «Transfer not found or not in draft status» | ضغطت «إكمال» على تحويل مكتمل | التحويل منفذ فعلاً — راجع سجل الحركات |
| فشل الإكمال بسبب نقص الرصيد | رصيد المصدر أقل من الكمية (منافسة تحويلات متزامنة) | قلّل الكمية أو أدرج استلاماً أولاً |
| «يجب إضافة منتج واحد على الأقل» | حفظ تحويل بلا بنود | أضف منتجاً وكمية |
| المستودع غير ظاهر في قائمة «إلى» | هو نفسه المستودع المصدر | اختر مستودعاً مختلفاً |
| حركة تحويل يدوية لم تغيّر الأرصدة | نوع `transfer` يدوي يسجل السجل فقط | استخدم تبويب التحويلات ثم «إكمال» |

## نصائح

- أنشئ مستودعاً لكل فرع فعلي — تقارير الأرصدة والفروقات تُبنى عليه.
- استخدم زر «عرض المخزون» على بطاقة المستودع كجرد سريع قبل الجلسة الفعلية.
- اجعل سجل الحركات عادة مراجعة يومية: فلتر «صادر» مع تاريخ اليوم يكشف كل ما خرج.
- لا تمرّر بضاعة بين المستودعات «شفاها» — التحويل الموثق يحميك من فروقات جرد وهمية.
- صدّر الأرصدة أسبوعياً إلى Excel لأرشفة خارجية سريعة.
