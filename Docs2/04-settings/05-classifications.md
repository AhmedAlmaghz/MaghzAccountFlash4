# التصنيفات — دليل الاستخدام

> أنواع المنتجات وتصنيفاتها ووحدات القياس وصناديق النقد ومراكز التكلفة: الطبقة التنظيمية التي تبني عليها المخزون والنقد.

## نظرة عامة

تجمع هذه المجموعة من صفحات الإعدادات كل أدوات التصنيف والتنظيم: نوع المنتج (تصنيف رئيسي واحد)، وتصنيفاته (وسوم متعددة هرمية)، ووحدات قياسه، إضافة إلى صناديق النقد ومراكز التكلفة. كلها تُسجَّل لكل شركة على حدة ويُسجَّل أي تغيير فيها في سجل التدقيق (Audit Log).

- **الموقع:** القائمة الجانبية ← الإعدادات ← (أنواع المنتجات | تصنيفات المنتجات | وحدات القياس | صناديق النقد | مراكز التكلفة)
- **الصلاحيات:** العرض `settings.view`، الإضافة `settings.create`، التعديل `settings.edit`، الحذف `settings.delete`

## العلاقة بين النوع والتصنيف (اقرأها أولاً)

| الأداة | طبيعتها | مثال |
|---|---|---|
| **نوع المنتج** | تصنيف رئيسي **واحد** لكل منتج — يحدد سلوكه في الوحدات | «سلع تامة» (يظهر في المبيعات والمشتريات والمخزون) مقابل «مادة خام» (يظهر في التصنيع) |
| **تصنيفات المنتجات** | وسوم **متعددة** لكل منتج، مرتبة في شجرة هرمية | المنتج «عصير برتقال» يحمل: أغذية ← مشروبات، وأيضاً «عروض رمضان» |

القاعدة: **النوع = تصنيف رئيسي واحد يحدد السلوك، التصنيفات = وسوم متعددة للتجميع والفلترة.**

## 1. أنواع المنتجات

- **الوصول:** القائمة الجانبية ← الإعدادات ← أنواع المنتجات (`/settings/product-types`)
- **الغرض:** CRUD بسيط لأنواع المنتجات التي تحدد أين يظهر كل منتج.

### الحقول

| الحقل | الوصف | إلزامي/اختياري |
|---|---|---|
| الاسم العربي | اسم النوع | إلزامي |
| الاسم الإنجليزي | اسم النوع بالإنجليزية | اختياري |
| الكود | رمز قصير | اختياري |
| يظهر في المبيعات / المشتريات / المخزون / التصنيع | مفاتيح تتحكم بظهور المنتجات من هذا النوع في كل وحدة | اختياري |
| تتبع مخزون | هل تخضع منتجات هذا النوع لتتبع الكميات | اختياري |
| له قائمة مواد (BOM) | هل يُسمح بتعريف قائمة مواد لمنتجات هذا النوع | اختياري |
| مفعّل | حالة النوع | اختياري |

الإضافة والتعديل عبر نافذة منبثقة، والحذف عبر مربع تأكيد صريح.

## 2. تصنيفات المنتجات

- **الوصول:** القائمة الجانبية ← الإعدادات ← تصنيفات المنتجات (`/settings/product-categories`)
- **الغرض:** شجرة هرمية من الوسوم تُربط بالمنتجات **بعلاقة متعدد-لكثير**: المنتج الواحد قد يحمل عدة تصنيفات، والتصنيف الواحد يجمع عدة منتجات.

### الشاشة والإجراءات

| الإجراء | الوصف |
|---|---|
| **تصنيف جديد** | نافذة باسم التصنيف + **التصنيف الأب** (اختياري) — اختيار أب يجعله فرعاً تحت ذلك الأب |
| **تعديل** | تغيير الاسم أو نقل التصنيف إلى أب آخر |
| **حذف** | مربع تأكيد؛ الحذف **متداخل**: إضافة/حذف أي عقدة يعيد بناء الشجرة المعروضة فوراً |
| **توسيع/طي** | أزرار السهم بجانب كل عقدة لها أبناء، مع عدّاد «عدد التصنيفات الفرعية» |

### كيف تربط التصنيفات بالمنتجات

الربط يتم من صفحة المنتجات (المخازن): عند إنشاء أو تعديل منتج تختار له عدة تصنيفات من الشجرة. ثم تُستخدم التصنيفات كفلاتر في قائمة المنتجات والتقارير.

**مثال شجرة:**

```
أغذية
├── مشروبات
│   └── عصائر
└── معلبات
مواد بناء
└── أدوات صحية
```

## 3. وحدات القياس

- **الوصول:** القائمة الجانبية ← الإعدادات ← وحدات القياس (`/settings/units`)
- **الغرض:** تعريف وحدات شراء وبيع المنتجات (قطعة، كرتونة، كيلو...).

| الحقل | الوصف | إلزامي/اختياري |
|---|---|---|
| الاسم العربي | اسم الوحدة | إلزامي |
| الاسم الإنجليزي | اسم الوحدة بالإنجليزية | اختياري |
| الكود | رمز قصير | اختياري |
| معامل التحويل (Conversion Factor) | كم وحدة أساسية تساوي هذه الوحدة | افتراضي 1 |

**مثال:** وحدة «كرتونة» بمعامل تحويل 12 تعني أن كرتونة واحدة = 12 من الوحدة الأساسية (قطعة). المخزون يُخزَّن دائماً بالوحدة الأساسية — راجع دليل المخازن.

## 4. صناديق النقد

- **الوصول:** القائمة الجانبية ← الإعدادات ← صناديق النقد (`/settings/cash-boxes`)
- **الغرض:** تعريف **الدرج النقدي (Cash Box)** المرتبط بحساب GL في شجرة الحسابات. كل حركة نقدية تمر عبر صندوق: مبيعات نقاط البيع، الفواتير النقدية، سندات القبض والصرف، صرف الرواتب، ومستحقات نهاية الخدمة.

### الحقول

| الحقل | الوصف | إلزامي/اختياري |
|---|---|---|
| الاسم | اسم الصندوق (مثل: «صندوق الفرع الرئيسي») | إلزامي |
| الكود | رمز قصير يظهر بخط أحادي المسافة | اختياري |
| الرصيد الافتتاحي | الرصيد النقدي عند بدء استخدام الصندوق | افتراضي 0 |
| الحساب المحاسبي | حساب GL المرتبط بالصندوق (عادة حساب «النقد بالصندوق») | اختياري — يُنصح به |
| الفرع | الفرع الذي يقع فيه الصندوق | اختياري |
| المسؤول | المستخدم المسؤول عن الصندوق | اختياري |
| مفعّل | يظهر في قوائم اختيار الصندوق | افتراضي مفعّل |

> الجدول يعرض الرصيد الحالي لكل صندوق بجانب اسمه. الحذف يتم بتأكيد صريح.

## 5. مراكز التكلفة

- **الوصول:** القائمة الجانبية ← الإعدادات ← مراكز التكلفة (`/settings/cost-centers`)
- **الغرض:** توزيع المصروفات والإيرادات على مراكز مسؤولية (أقسام، مشاريع، أنشطة).

| الحقل | الوصف | إلزامي/اختياري |
|---|---|---|
| الاسم العربي | اسم المركز | إلزامي |
| الاسم الإنجليزي | الاسم بالإنجليزية | اختياري |
| الكود | رمز قصير | اختياري |
| النوع | نوع المركز (قسم department أو غيره) | افتراضي: قسم |
| الميزانية | الميزانية المخططة للمركز — تُعرض بجانبه مع مقارنة المصروف | افتراضي 0 |

**مثال:** أنشئ مراكز «المبيعات»، «الصيانة»، «مشروع التوسعة» بميزانياتها، ثم وزّع المصروفات عليها لتقارير ربحية كل مركز.

## سير عمل خطوة بخطوة

1. **أنواع المنتجات:** القائمة الجانبية ← الإعدادات ← أنواع المنتجات ← «نوع جديد» ← أدخل «سلع تامة» وفعّل المبيعات/المشتريات/المخزون ← حفظ.
2. **التصنيفات:** الإعدادات ← تصنيفات المنتجات ← أنشئ «أغذية» (بلا أب) ثم «مشروبات» (الأب: أغذية) ← حفظ.
3. **الوحدات:** الإعدادات ← وحدات القياس ← أضف «قطعة» (معامل 1) و«كرتونة» (معامل 12).
4. **صناديق النقد:** الإعدادات ← صناديق النقد ← «صندوق جديد» ← الاسم + الحساب المحاسبي + الفرع ← حفظ.
5. **مراكز التكلفة:** الإعدادات ← مراكز التكلفة ← أضف مراكزك بميزانياتها.
6. اربط كل ذلك عند إدخال المنتجات (نوع + تصنيفات + وحدات) وعند تشغيل نقاط البيع (الصندوق).

## قواعد مهمة

- النوع والتصنيف مختلفتان وظيفياً: لا تحوّل التصنيفات إلى أنواع لتقسيم المخزون — النوع هو من يحدد السلوك (تتبع مخزون، BOM، الوحدة الظاهرة).
- الصندوق النقدي مرتبط بحساب GL: أي عجز أو زيادة في الوردية ينعكس على هذا الحساب — راجع دليل نقاط البيع (تقرير Z).
- لا تحذف تصنيفاً مستخدماً في منتجات كثيرة قبل نقل منتجاته لتصنيف بديل.
- كل إجراء في الصفحات الخمس يُسجَّل في سجل التدقيق باسم المستخدم والوقت.

## أخطاء شائعة وحلولها

| الرسالة/السلوك | السبب | الحل |
|---|---|---|
| «الاسم مطلوب» | تركت الاسم العربي فارغاً | أدخل الاسم واحفظ |
| التصنيف لا يظهر كفرع | لم تختر «التصنيف الأب» عند إنشائه | عدّله واختر الأب المطلوب |
| لا أجد صندوقاً في شاشة POS | الصندوق غير مفعّل أو مرتبط بفرع آخر | فعّل الصندوق أو اربطه بالفرع الصحيح |
| فشل الحذف | السجل مستخدم (منتجات مرتبطة بالتصنيف/النوع أو حركات على الصندوق) | انقل الاستخدامات أولاً أو اترك السجل |
| ميزانية المركز لا تظهر في التقرير | لم تُدخل قيمة الميزانية | عدّل المركز وأدخل الميزانية |

## نصائح

- لا تفرط في التفريع بالتصنيفات: شجرة بعمق 2-3 مستويات تكفي لأي فلترة عملية.
- أعطِ كل صندوق نقدي مسؤولاً محدداً — يوضح المسؤولية عند تسوية فروق الورديات.
- راجع الميزانية مقابل المصروف الفعلي لكل مركز تكلفة شهرياً في مركز التقارير.
