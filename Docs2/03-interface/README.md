# الواجهة العامة — دليل الاستخدام

> جولة في هيكل الشاشة: الشريط الجانبي، الهيدر، قائمة المستخدم، الثيمات، واتجاه الكتابة.

## نظرة عامة

بعد تسجيل الدخول تظهر الواجهة الرئيسية بتصميم من اليمين إلى اليسار (RTL) وتتكوّن من:

| الجزء | الموقع | الغرض |
|---|---|---|
| الشريط الجانبي | يمين الشاشة (في الوضع العربي) | التنقل بين الوحدات الـ 13 |
| الهيدر | أعلى الشاشة | الشركة النشطة، البحث الشامل، الرئيسية، المساعد، قائمة المستخدم |
| منطقة المحتوى | المنتصف | الصفحة الحالية |
| شريط التبويبات السفلي | أسفل الشاشة (الجوال فقط) | وصول سريع لأول 4 وحدات + «المزيد» |

## الشريط الجانبي

الشريط الجانبي هو خريطة النظام. الوحدات مجمعة منطقياً:

| المجموعة | الوحدات |
|---|---|
| الرئيسية | لوحة التحكم، المساعد الذكي «مغزى» |
| التشغيل | المبيعات، نقاط البيع، المشتريات، المخازن، التصنيع |
| الإدارة | المحاسبة، الموظفين، علاقات العملاء |
| التحليل | التقارير (مركز التقارير) |
| النظام | الإعدادات |

- كل قسم له صفحة رئيسية — اضغط على اسم القسم للدخول إليها، أو اضغط سهم الطي بجانبه لفتح قائمة صفحاته الفرعية.
- عند تصغير الشريط تظهر الأيقونات فقط، مع تلميح باسم القسم عند التمرير.

### الإخفاء حسب الصلاحيات — ولماذا ليس حماية كافية وحدها

الوحدات التي لا يملك دورك صلاحية الوصول إليها **تُخفى من الشريط الجانبي** تلقائياً. مثلاً مندوب المبيعات (`sales_rep`) لا يرى الإعدادات أو المحاسبة، بينما المدير (`admin`) يرى كل شيء.

> **تنبيه مهم:** إخفاء القائمة وسيلة تنظيمية لتجربة استخدام أنظف، وليست الحماية الفعلية. الحماية الحقيقية أن **كل مسار في النظام محمي بشكل مستقل** — حتى لو كتب أحد المستخدمين رابط صفحة غير مسموح له مباشرة في شريط العنوان، تُرفض الصفحة ولا تُعرض بياناتها. القاعدة: الصلاحية تُفحص على كل مسار، والإخفاء مجرد انعكاس مرئي لها.

### التمرير والتصغير

| الإجراء | كيف؟ | النتيجة |
|---|---|---|
| تصغير/توسيع الشريط | زر السهم أسفل الشريط الجانبي | يتبدل بين العرض الكامل (الأسماء والأيقونات) والوضع المصغر (الأيقونات فقط) — يُحفظ اختيارك |
| التمرير بين الأقسام | عجلة الفأرة داخل الشريط | كل الأقسام قابلة للتمرير عمودياً |
| الجوال/الشاشة الصغيرة | زر القائمة في الهيدر | الشريط يظهر كدرج منزلق مع طبقة تعتيم، ويُغلق بالضغط خارجاً أو زر Escape |

## الهيدر

شريط أعلى الشاشة يبقى ثابتاً في كل الصفحات:

| العنصر | الموقع | الوظيفة |
|---|---|---|
| الشركة النشطة | أعلى اليمين (شعار + اسم) | تعرض المنشأة التي تعمل على بياناتها حالياً — كل ما تنشئه يُسجَّل على هذه الشركة |
| البحث الشامل | أعلى الوسط (أو أيقونة العدسة) | بحث في الصفحات والعملاء والموردين والمنتجات والفواتير — يُفتح أيضاً بـ `Ctrl+K` |
| زر الرئيسية | أيقونة البيت | عودة فورية إلى لوحة التحكم |
| المساعد الذكي | أيقونة الروبوت | يظهر فقط لمن يملك صلاحية `ai.use` — يفتح صفحة الوكيل الذكي «مغزى» |
| قائمة المستخدم | أعلى اليسار (صورة المستخدم + سهم) | كل خيارات الحساب والمظهر — التفصيل أدناه |

## قائمة المستخدم

اضغط على صورة المستخدم في الهيدر لفتح القائمة:

| الخيار | الوظيفة |
|---|---|
| **بطاقة الهوية** | صورة المستخدم، الاسم، البريد، وشارة الدور (`admin` مثلاً) |
| **اللغة** | تبديل فوري بين **العربية** و**الإنجليزية** — تتغير الواجهة واتجاهها في الحال |
| **المظهر** | تبديل بين **الوضع الفاتح** والوضع الداكن |
| **كل الثيمات** | رابط سريع إلى صفحة المظهر والثيمات (انظر أدناه) |
| **الملف الشخصي** | تعديل الاسم الكامل والهاتف والصورة الشخصية |
| **تغيير كلمة المرور** | يتطلب إدخال كلمة المرور الحالية — التفاصيل في `02-getting-started/03-login.md` |
| **الإعدادات** | رابط إلى صفحة الإعدادات الرئيسية |
| **تسجيل الخروج** | إنهاء الجلسة والعودة لشاشة الدخول |

## صفحة الثيمات (المظهر والثيمات)

- **الوصول:** القائمة الجانبية ← الإعدادات ← المظهر والثيمات (أو قائمة المستخدم ← كل الثيمات)

هنا تتحكم بالهوية البصرية للنظام:

| الميزة | التفصيل |
|---|---|
| **ثيمات الهوية** | ثيمات جاهزة من النظام بالوضعين الفاتح والداكن (الزمردي والذهبي) — تفعّلها بضغطة واحدة |
| **ثيماتي الخاصة** | أنشئ ثيماً مخصصاً بألوان شركتك، وعدّله أو احذفه |
| **المعاينة الحية** | قبل الحفظ ترى شكلاً حقيقياً للقائمة والهيدر والأزرار بالألوان المختارة |

### إنشاء ثيم مخصص

1. اضغط **«ثيم جديد»**.
2. أدخل اسم الثيم **بالعربية والإنجليزية** (كلاهما إلزامي).
3. اختر **الوضع**: فاتح أو داكن.
4. حدد الألوان — كل حقل يقبل صيغة hex فقط (`#RRGGBB`):

| اللون | ماذا يتحكم فيه؟ |
|---|---|
| اللون الأساسي (زمردي) | الأزرار الرئيسية والروابط النشطة وعناصر التمييز |
| لون التمييز (ذهبي) | الشارات واللمسات الثانوية |
| الخلفية | خلفية النافذة العامة |
| السطح (البطاقات) | خلفية البطاقات والجداول |
| خلفية القائمة الرئيسية | خلفية الشريط الجانبي |
| خلفية الهيدر | خلفية الشريط العلوي |
| لون الروابط (افتراضي) | نص عناصر القائمة غير النشطة |
| لون الروابط (نشط) | نص وأيقونة القسم الذي أنت فيه |
| لون الأيقونات (افتراضي) | أيقونات القائمة غير النشطة |

5. اختر **الخط**: القاهرة (Cairo)، إنتر (Inter)، بليكس (Plex)، أو خط النظام.
6. عاين ثم احفظ — يُفعَّل الثيم فوراً ويمكنك العودة لثيم الهوية في أي وقت. حذف ثيم مفعّل يعيدك تلقائياً لثيم الهوية الافتراضي.

## اتجاه الكتابة (RTL)

النظام عربي أولاً:

- الواجهة الافتراضية **من اليمين إلى اليسار (RTL)**: الشريط الجانبي يميناً، الهيدر معكوس، والنماذج تُقرأ طبيعياً بالعربية.
- عند التبديل للإنجليزية من قائمة المستخدم ينقلب الاتجاه كلياً إلى LTR — الجداول والحقول والأيقونات تتبدل مواقعها تلقائياً.
- الحقول التقنية (كلمة المرور، الأكواد، أرقام المستندات مثل `INV-0001`) تُعرض دائماً باتجاه لاتيني داخل الواجهة العربية لضمان القراءة الصحيحة.

## خريطة المسارات السريعة

المسار الكامل لأكثر الصفحات استخداماً (اتبع نفس النمط لكل وحدة):

| الصفحة | المسار الكامل |
|---|---|
| لوحة التحكم | القائمة الجانبية ← لوحة التحكم |
| فاتورة مبيعات جديدة | القائمة الجانبية ← المبيعات ← فواتير المبيعات ← زر «فاتورة جديدة» |
| شاشة الكاشير | القائمة الجانبية ← نقاط البيع ← شاشة الكاشير |
| قيد يومية جديد | القائمة الجانبية ← المحاسبة ← القيود اليومية ← زر «قيد جديد» |
| كشف حساب عميل | القائمة الجانبية ← التقارير ← كشف حساب عميل |
| إضافة مستخدم | القائمة الجانبية ← الإعدادات ← المستخدمون |
| النسخ الاحتياطي | القائمة الجانبية ← الإعدادات ← النسخ الاحتياطي |
| إعادة تهيئة المعالج | القائمة الجانبية ← الإعدادات ← إعادة التهيئة |

## نصائح

- احفظ `Ctrl+K` في ذاكرتك — البحث الشامل أسرع طريق لأي صفحة أو سجل دون تجول في القوائم.
- اضبط ثيماً بألوان شركتك وشارك الشعور بالهوية مع فريقك — التبديل بين الفاتح والداكن يعمل مع أي ثيم.
- اسم الشركة في الهيدر تذكير دائم: إن كنت تدير أكثر من منشأة تأكد دائماً أن الشركة النشطة هي الصحيحة قبل أي فاتورة.
- على الجوال استخدم شريط التبويبات السفلي ثم «المزيد» للوصول لباقي الوحدات — نفس الصلاحيات تنطبق هناك.
