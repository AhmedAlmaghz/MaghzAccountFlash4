# دليل المستخدم الشامل — MaghzAccountPro

> الدليل الرسمي الكامل لنظام **MaghzAccountPro** (الإصدار v0.15.18): نظام ERP محاسبي متكامل للمنشآت الصغيرة والمتوسطة، بواجهة عربية أولاً، محاسبة مزدوجة متوافقة مع IFRS، ضريبة قيمة مضافة مرنة، عملات متعددة، ووكيل ذكي «مغزى».

### مسارات قراءة حسب الدور

| الدور | المسار المقترح |
|---|---|
| **المدير / المالك** | المقدمة ← الإعدادات ← المستخدمون والأدوار ← لوحة التحكم ← التقارير المالية |
| **المحاسب** | المحاسبة (الأربعة) ← المبيعات والمشتريات ← العملات المتعددة ← سجل التدقيق |
| **الكاشير** | تسجيل الدخول ← شاشة الكاشير ← الورديات ← إعدادات POS |
| **أمين المخزن** | المنتجات ← المستودعات والمخزون ← التحويلات ← التسويات |
| **مندوب المبيعات** | العملاء ← الفواتير ← عروض الأسعار ← المرتجعات ← CRM |
| **مسؤول الموارد البشرية** | إعدادات HR ← الموظفون والحضور ← الرواتب ونهاية الخدمة |
| **مسؤول المبيعات (CRM)** | العملاء المحتملون ← الفرص ← المهام والأنشطة |

## قواعد ذهبية يجب أن يعرفها كل مستخدم

1. **المسودة قبل الترحيل:** كل مستند مالي (فاتورة، سند، قيد، تسوية) يبدأ **مسودة** قابلة للتعديل والحذف، وبعد **الترحيل** يصبح غير قابل للتعديل ويُنشئ قيده المحاسبي — التصحيح يتم بمستند عكسي أو بقيود جديدة.
2. **التوثيق المزدوج:** كل عملية مرحّلة لها قيد متوازن (المدين = الدائن)، والتقارير المالية تعرض **القيود المرحّلة فقط**.
3. **التأثير على المخزون تلقائي:** ترحيل فاتورة بيع يخفض المخزون، وترحيل فاتورة شراء يرفعه، والمرتجعات والتسويات تعكس ذلك — المخزون دائماً بالوحدة الأساسية.
4. **إخفاء القائمة ليس حماية:** كل صفحة محمية بصلاحياتها على مستوى الرابط، وما لا يملكه المستخدم لا يصل إليه حتى بمعرفة العنوان.
5. **كل شيء مسجَّل:** الحركات الحساسة (دخول، تعديل إعدادات، ترحيل، حذف) تُسجَّل في سجل التدقيق مع القيم القديمة والجديدة.
6. **المساعد «مغزى» لا ينفذ شيئاً بدون موافقتك:** كل عملية كتابة يقترحها تظهر كبطاقة تأكيد بملخص عربي واضح — لا تنفَّذ إلا بعد موافقتك الصريحة.
