# معالج الإعداد الأول — دليل الاستخدام

> تهيئة النظام من 5 خطوات: الترحيب، قاعدة البيانات، بيانات الشركة، البيانات الأولية، ثم الإنجاز.

## نظرة عامة

يظهر معالج الإعداد تلقائياً عند أول تشغيل للنظام، أو عند إعادة تشغيله من الإعدادات. يأخذك خلال 5 خطوات قصيرة لإعداد قاعدة البيانات ومنشأتك وبيانات البداية، وفي نهايته تكون جاهزاً لتسجيل الدخول كمدير. شريط التقدم أعلى الشاشة يوضح موقعك دائماً ويمكنك الرجوع بخطوة للخلف في أي وقت قبل الإنهاء.

## الخطوة 1: الترحيب

شاشة ترحيب تعرض أبرز قدرات النظام (PostgreSQL، تعدد العملات، البيانات الافتراضية الجاهزة) وزر **«ابدأ»** للمتابعة.

### خيار «مسح جميع البيانات والبدء من جديد»

في أسفل شاشة الترحيب يوجد خيار حذف شامل للبيانات — استخدمه فقط إذا كانت لديك تهيئة سابقة تريد التخلص منها نهائياً:

1. اضغط **«مسح جميع البيانات والبدء من جديد»**.
2. سيظهر تحذير أصفر: «سيتم حذف جميع بيانات قاعدة البيانات. هذا الإجراء لا يمكن التراجع عنه».
3. أدخل **اسم مستخدم المدير** و**كلمة مرور المدير** للتحقق من هويتك.
4. فعّل مربع التأكيد: «أتفهم أن هذا الإجراء سيمسح جميع البيانات بشكل نهائي».
5. اضغط **«نعم، امسح جميع البيانات»**.

| العنصر | إلزامي؟ | ملاحظة |
|---|---|---|
| اسم مستخدم المدير | نعم | مثال: `admin` |
| كلمة مرور المدير | نعم | تُتحقق منها النظام قبل التنفيذ |
| مربع التأكيد | نعم | زر المسح يبقى معطلاً حتى تفعّله |

> **تحذير:** الحذف نهائي ويشمل كل بيانات القاعدة (فواتير، عملاء، منتجات، قيود). إذا كانت لديك بيانات مهمة خذ نسخة احتياطية أولاً من الإعدادات ← النسخ الاحتياطي.

## الخطوة 2: قاعدة البيانات

تختار هنا أين تُحفظ بياناتك — بطاقتان للاختيار:

| الخيار | متى تختاره؟ |
|---|---|
| **PGlite محلي (PostgreSQL WASM)** | جهاز واحد بدون تثبيت خادم — البيانات تُحفظ محلياً على جهازك |
| **PostgreSQL خادم** | عدة مستخدمين يشاركون بياناتهم عبر خادم مركزي على الشبكة |

عند اختيار PostgreSQL الخارجي أدخل: **الخادم (Host)**، **المنفذ (Port)**، **اسم قاعدة البيانات**، **اسم المستخدم**، **كلمة المرور**.

اضغط زر **«اختبار الاتصال»** في كلا الحالتين:

- نجاح: تظهر رسالة خضراء باسم القاعدة المتصل بها (ورقم إصدار الخادم في وضع PostgreSQL).
- فشل: تظهر رسالة حمراء بالسبب — صحح البيانات وأعد المحاولة قبل المتابعة.

> راجع `01-installation.md` للمقارنة الكاملة بين الخيارين وحلول أخطاء الاتصال.

## الخطوة 3: بيانات الشركة

أدخل هوية منشأتك — هذه البيانات تظهر على الفواتير والتقارير.

| الحقل | الوصف | إلزامي/اختياري |
|---|---|---|
| اسم الشركة | الاسم العربي — يظهر في الهيدر والفواتير | إلزامي |
| الاسم الإنجليزي | يظهر عند التبديل للواجهة الإنجليزية | اختياري |
| العملة الافتراضية | YER (افتراضي) / SAR / USD / AED / KWD / QAR — هذه **العملة الأساسية** التي تُحسب بها كل التقارير | إلزامي |
| الرقم الضريبي | يظهر على الفواتير عند تطبيق ضريبة القيمة المضافة | اختياري |
| الهاتف | رقم تواصل المنشأة | اختياري |
| العنوان | عنوان المنشأة | اختياري |
| البريد الإلكتروني | بريد المنشأة | اختياري |
| التقويم | ميلادي (Gregorian) أو هجري (Hijri) | إلزامي (افتراضي: ميلادي) |
| المنازل العشرية | 0 / 2 / 3 / 4 خانة عشرية لعرض المبالغ — 2 مناسبة للمعظم، و0 مناسبة للريال اليمني | إلزامي (افتراضي: 2) |
| بداية السنة المالية | اليوم الذي تبدأ منه سنتك المحاسبية (افتراضي: 1 يناير) | اختياري |

> **مهم:** العملة الافتراضية تُحدد **العملة الأساسية** للنظام كله. تغييرها لاحقاً ممكن لكنه يستدعي مراجعة أسعار المنتجات وأسعار الصرف — اخترها بوعي الآن.

## الخطوة 4: البيانات الأولية

تختار ماذا يُجهَّز لك عند البدء، وتحدد كلمة مرور المدير.

### كلمة مرور المدير

حقل **كلمة مرور المدير** أعلى الخطوة — تُستخدم لتسجيل الدخول كمدير النظام بعد التهيئة. أدخل كلمة مرورك بنفسك، أو اترك الحقل لتوليد كلمة مرور قوية تلقائياً (حسب إصدارك).

> **تنبيه مهم:** إذا ولّد النظام كلمة المرور تلقائياً، تُعرض **مرة واحدة فقط** في مربع مميز بلون أصفر بعد إتمام البذر — انسخها واحفظها فوراً. لا يمكن استرجاعها لاحقاً إلا بإعادة التهيئة.

### خيارات البيانات

| الخيار | ماذا يتضمن؟ | لمن؟ |
|---|---|---|
| **بدون بيانات** | شركة فارغة تماماً — تُدخل كل شيء يدوياً | من يريد بناء كل شيء بنفسه |
| **البيانات الافتراضية** (مُوصى به) | شجرة الحسابات الجاهزة، إعدادات VAT، الفروع، المستخدم المدير، العملة | البداية الصحيحة لمعظم المنشآت |
| **البيانات التجريبية (Demo)** | كل ما سبق + عملاء وموردين ومنتجات وفواتير وموظفين ومهام... | التدريب والاستكشاف — **لا تستخدمها في بيئة عمل حقيقية** |

اختر الخيار ثم اضغط **«بذر البيانات والتالي»** (أو «تخطي» إذا اخترت «بدون بيانات»). ستظهر رسالة نجاح خضراء عند اكتمال البذر.

## الخطوة 5: الإنجاز

شاشة ملخص تعرض إعداداتك قبل الدخول:

| البند | ماذا يعرض؟ |
|---|---|
| الشركة | الاسم الذي أدخلته في الخطوة 3 |
| العملة | العملة الافتراضية المختارة |
| قاعدة البيانات | نوع الاتصال |
| البيانات | الخيار المختار (بدون / افتراضية / تجريبية) |

راجع الملخص — إذا احتجت تعديلاً استخدم زر «رجوع» للوصول للخطوة المطلوبة. عند جاهزيتك اضغط **«الدخول إلى النظام»**: يحفظ النظام كل إعداداتك ويعيد تحميل التطبيق لتظهر شاشة **تسجيل الدخول** (راجع `03-login.md`).

## إعادة تشغيل معالج الإعداد

إذا احتجت تغيير اتصال قاعدة البيانات أو إعادة بذر البيانات الافتراضية بعد فترة من الاستخدام:

- **المسار:** القائمة الجانبية ← الإعدادات ← إعادة التهيئة
- **من يُسمح له؟** دور `admin` أو `super_admin` فقط — أي دور آخر يرى شاشة «غير مصرح».

الخطوات:

1. ستظهر بطاقة تحذير أوضح ماذا يحدث فعلاً: **إعادة التهيئة لا تحذف بيانات قاعدة البيانات** — تعيد فقط تشغيل معالج التهيئة لتغيير إعدادات الاتصال أو إعادة بذر البيانات الافتراضية.
2. فعّل مربع التأكيد: «أفهم أن هذا سيُعيد تشغيل معالج التهيئة عند التالي».
3. اضغط **«إعادة التهيئة الآن»** (الزر مرئي فقط لمن يملك صلاحية `settings.delete`).
4. يعيد النظام تحميل الصفحة ويبدأ المعالج من الخطوة الأولى.

> **ملاحظة:** الفرق بين هذا الخيار و«مسح جميع البيانات» في شاشة الترحيب: إعادة التهيئة تعيد المعالج فقط دون حذف بيانات، أما «مسح جميع البيانات» فتحذف كل شيء نهائياً.

## أخطاء شائعة وحلولها

| الرسالة كما تظهر في النظام | السبب | الحل |
|---|---|---|
| «يرجى إدخال كلمة مرور المدير قبل المتابعة» | حقل كلمة المرور فارغ عند اختيار بذر بيانات | أدخل كلمة المرور ثم أعد «بذر البيانات والتالي» |
| «فشل اختبار الاتصال» | بيانات PostgreSQL خاطئة أو الخادم متوقف | راجع Host/Port/المستخدم/كلمة المرور وتأكد من تشغيل الخدمة |
| «غير مصرح — فقط المدراء يمكنهم إعادة تهيئة النظام» | دورك ليس admin/super_admin | اطلب من مدير النظام تنفيذ إعادة التهيئة |
| «لون غير صالح» أو خطأ حفظ في نهاية المعالج | تعارض مؤقت في الاتصال | أعد المحاولة؛ إن تكرر تحقق من اتصال قاعدة البيانات |

## نصائح

- ابدأ بـ «البيانات الافتراضية» — شجرة الحسابات الجاهزة توفّر عليك ساعات من الإعداد اليدوي، ويمكنك تعديلها لاحقاً.
- البيانات التجريبية ممتازة للتدريب، لكن لا تخلطها ببيانات عملك الحقيقية — أنشئ قاعدة منفصلة لتجربتها.
- احفظ كلمة مرور المدير في مكان آمن فور توليدها — النظام لا يعرضها مرة ثانية.
- اسم الشركة وبياناتها قابلة للتعديل لاحقاً من القائمة الجانبية ← الإعدادات ← بيانات الشركة.
