# العملاء — دليل الاستخدام

> سجل العملاء الكامل: بيانات، حد ائتمان، رصيد افتتاحي يُرحَّل مرة واحدة، وبطاقة عميل بثلاثة تبويبات (التفاصيل / كشف الحساب / أعمار الذمم).

## نظرة عامة

العميل هو الطرف الذي تُبنى عليه فواتير المبيعات وذممها المدينة. تصل إلى الشاشة من: **القائمة الجانبية ← المبيعات ← العملاء** (`/sales/customers`).

## الوصول والصلاحيات

| الفعل | الصلاحية |
|---|---|
| عرض القائمة والبطاقة والكشوف | `sales.view` |
| إضافة/تعديل عميل | `sales.create` / `sales.edit` |
| حذف عميل | `sales.delete` — يُحظر مع وجود فواتير أو مرتجعات |

## قائمة العملاء

جدول يعرض: الكود، الاسم، الهاتف، **الرصيد** (ملون: مدين كهرماني / دائن أخضر)، حالة التفعيل، وأزرار الإجراءات.

- **بحث** بالاسم والهاتف والكود + **فلتر التفعيل** + **ترقيم صفحات** من الخادم.
- **KPIs:** إجمالي العملاء، المفعّل، إجمالي الأرصدة (مدين ودائن منفصلين).
- **إضافة عميل جديد** محمية بصلاحية `sales.create`.

## شاشة العميل الجديد

- **الوصول:** القائمة ← المبيعات ← العملاء ← زر **«عميل جديد»**
- **الغرض:** فتح ملف عميل

### الحقول

| الحقل | الوصف | إلزامي |
|---|---|---|
| **الكود** | يُولَّد تلقائياً ببادئة `CUS-` من تسلسل المستندات؛ يمكن كتابته يدوياً | تلقائي |
| **الاسم** | اسم العميل أو المؤسسة | نعم |
| **الهاتف** | رقم التواصل الأساسي | اختياري |
| **البريد الإلكتروني** | للفواتير الإلكترونية والمراسلة | اختياري |
| **العنوان** | يظهر في رأس الفاتورة المطبوعة | اختياري |
| **الرقم الضريبي** | يظهر في الفاتورة الرسمية وتقارير VAT | اختياري |
| **حد الائتمان** | السقف المسموح من الذمم المدينة على هذا العميل | اختياري |
| **مفعّل** | العميل غير المفعّل يختفي من قوائم الفواتير الجديدة | نعم |

### الرصيد الافتتاحي المدين

| الحقل | الوصف |
|---|---|
| **الرصيد الافتتاحي** | المبلغ المدين (ما على العميل لك) قبل بدء استخدام النظام |
| **تاريخ الافتتاح** | يرتّب سطر الافتتاحي في كشف الحساب وأعمار الذمم |

**كيف يُرحَّل:** عند الحفظ يُنشأ **قيد يومية** مرة واحدة: مدين «ذمم مدينة» × المبلغ / دائن «حساب حقوق الملكية الافتتاحية». ثم **يُقفل** — لا يُرحَّل الافتتاحي ثانيةً حتى لو عدّلت بيانات العميل. الرصيد الافتتاحي بلا تاريخ يُعامَل كأقدم دين (فئة 90+ في أعمار الذمم).

## بطاقة العميل — ثلاثة تبويبات

اضغط على أي عميل لفتح البطاقة:

### 1) التفاصيل

كل بيانات البطاقة + ملخص الرصيد وحد الائتمان — نفس نموذج الإضافة في وضع القراءة/التعديل.

### 2) كشف الحساب

**دفتر حساب كامل** بأسطر مرتبة زمنياً مع **رصيد متجدد**:

| نوع السطر | مدين | دائن |
|---|---|---|
| **رصيد افتتاحي** | المبلغ المدين الافتتاحي | (إن كان دائناً) |
| **فاتورة** (غير ملغاة) | إجمالي الفاتورة | |
| **مردود** (مُرحّل) | | إجمالي المرتجع |
| **سند قبض** (مُرحّل) | | مبلغ التحصيل |

- الرصيد المتجدد يُحسب سطراً بعد سطر (المدين يزيد، الدائن ينقص).
- **قابل للطباعة** — زر الطباعة ينتج كشفاً رسمياً بترويسة الشركة لإرساله للعميل.

### 3) أعمار الذمم

تقسيم المستحق المستحق على العميل إلى **فئات 0-30 / 31-60 / 61-90 / 90+ يوماً** حسب تاريخ الاستحقاق، مع عدد الفواتير في كل فئة وإجمالي المستحق. يعتمد على: الفواتير المُرحّلة غير المسددة + الافتتاحي − المدفوعات − المرتجعات.

## معادلة الرصيد المعروض

الرصيد في القائمة والبطاقة يُحسب **من المستندات مباشرة**:

```
الرصيد = الرصيد الافتتاحي
       + Σ فواتير المبيعات المُرحَّلة (باستثناء الملغاة)
       − Σ سندات القبض المُرحّلة
       − Σ مرتجعات المبيعات المُرحّلة
```

- الرصيد الموجب = **ذمم مدينة** (على العميل لك) — يُلوَّن كهرمانياً.
- الرصيد السالب = دائن (دفع قبلاً أو مرتجع بلا فاتورة) — يُلوَّن أخضر.

## سير عمل خطوة بخطوة — مثال رقمي

فتح عميل جديد مع رصيد افتتاحي:

1. القائمة ← المبيعات ← العملاء ← **«عميل جديد»**.
2. الكود يظهر تلقائياً: `CUS-00014`. الاسم: «مؤسسة النور التجارية».
3. الهاتف: `777123456`. الرقم الضريبي: `3001234567`. حد الائتمان: `2,000,000` ر.ي.
4. الرصيد الافتتاحي: `350,000` ر.ي، تاريخ الافتتاح: `2026-09-01`.
5. **حفظ** — يُرحَّل القيد الافتتاحي مرة واحدة:

| الحساب | مدين (ر.ي) | دائن (ر.ي) |
|---|---:|---:|
| ذمم مدينة (العملاء) | 350,000 | |
| حقوق الملكية الافتتاحية | | 350,000 |

6. افتح البطاقة ← تبويب **كشف الحساب**: أول سطر «رصيد افتتاحي — مدين 350,000 — الرصيد المتجدد 350,000».
7. بعدها بعت فاتورة `INV-00052` بمبلغ 120,000 ورحّلتها: سطر جديد مدين 120,000 → الرصيد **470,000**.
8. حصّلت 200,000 بسند قبض: سطر دائن → الرصيد **270,000** — وينعكس في تبويب أعمار الذمم حسب تواريخ الاستحقاق.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| الافتتاحي مرة واحدة | يُرحَّل لحظة الإنشاء فقط ثم يقفل الحقل |
| الكشف يعرض المرحّل فقط | الفواتير والمردودات والسندات المسودات لا تظهر في الكشف |
| الفاتورة الملغاة مستبعدة | لا تدخل الرصيد ولا الكشف |
| حد الائتمان استرشادي | يظهر في البطاقة للمراجعة عند البيع الآجل |
| الحذف محمي | عميل له فواتير لا يُحذف — عطّله بدلاً من حذفه |

## أخطاء شائعة وحلولها

| الرسالة | السبب | الحل |
|---|---|---|
| «Cannot delete customer with existing invoices…» | للعميل فواتير أو عروض أو مرتجعات | عطّل العميل بدل الحذف |
| حقل الرصيد الافتتاحي مقفل | الافتتاحي رُحِّل عند الإنشاء | التصحيح بقيود يومية أو تسوية من وحدة المحاسبة |
| الرصيد لا يشمل فاتورة جديدة | الفاتورة ما زالت مسودة | رحّل الفاتورة لتدخل الرصيد والكشف |
| سطر الافتتاحي في فئة «90+» | افتتاحي بلا تاريخ | طبيعي — الافتتاحي المؤرخ كان سيظهر في فئته |
| العميل لا يظهر في قائمة الفاتورة | العميل غير مفعّل | فعّله من بطاقته |

## نصائح

- املأ **الرقم الضريبي** من أول يوم — الفاتورة الرسمية وتقارير VAT يحتاجانه.
- راجع تبويب **أعمار الذمم** أسبوعياً: ما تجاوز 90 يوماً يحتاج خطة تحصيل فورية.
- اطبع كشف الحساب وأرسله للعميل مع كل تحصيل كبير — يمنع معظم الخلافات.
- استخدم حد الائتمان كسياسة بيع: راجعه قبل أي بيع آجل كبير.
- لا تنشئ عميلاً جديداً لكل فاتورة نقدي — استخدم «العميل النقدي الافتراضي» أو نقاط البيع.
