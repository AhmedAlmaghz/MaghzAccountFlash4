## 1️⃣ فلسفة المحتوى

> **لا نعلن عن البرنامج — نُريه يعمل.**

كل قطعة محتوى = **لقطة حقيقية** للمساعد يفهم العامية، أو حارس يفشل ادعاءً، أو ميزان يتوازن. المصدر الأقوى: **شاشة النظام نفسها** — أجمل إعلان هو الديمو الحي.

### قاعدة 80/20
- **80%** يثبت القيمة (ديمو، قبل/بعد، تعليم) — بلا بيع مباشر
- **20%** دعوة صريحة (CTA): حمّل، جرّب، شارك بالتحدي

## 5️⃣ قوالب الـ Hooks الجاهزة (نسخ، الصق، عدّل)

### للفيديوهات القصيرة (أول 3 ثوانٍ تحسم):
1. «تخيل تكلم دفاترك… وهي ترد عليك»
2. «قُلت للنظام جملة بالعامية — وشاف وش سوّى»
3. «هذا المحاسب الذكي… **رفض** ينفذ أمر غلط. شوف ليش»
4. «من التحميل لأول فاتورة: ٥ دقايق. بساعة حقيقية.»
5. «ال AI اللي يكتب بلا موافقتك؟ **ممنوع عندنا. هندسياً.**»
6. «٦ خطوات بال Excel… صارت جملة وحدة هنا»
7. «جربنا نضحك على الذكاء — النظام فضحنا»
8. «عملاؤك المدينين: كم منهم ناسي؟ (النظام يعرف بالثانية)»

## 7️⃣ قواعد النشر والتفاعل

1. **الرد على كل تعليق خلال ساعتين** (خاصة الأسئلة المحاسبية — فرصة محتوى)
2. **التعليق المتشكك هدية**: كل اعتراض = فيديو رد جديد (راجع إدارة الاعتراضات في خطة التسويق)
3. **إعادة النشر (Repost) لكل من يصور تجربته** — وقود المجتمع
4. **الأرقام بالعربية الهندية في العناوين** أحياناً (١٢٣) — تناسق مع هوية المنتج + لفت نظر
5. **لا نحذف نقداً** — نرد بالدليل والديمو
