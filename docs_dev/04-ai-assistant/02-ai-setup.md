# إعداد الوكيل الذكي

> المسار: `/settings/ai` — الصلاحية: `ai.settings` — الإعدادات **لكل شركة**

---

## قبل البدء

تحتاج **مفتاح API** من مزود ذكاء اصطناعي يدعم واجهة OpenAI المتوافقة. الخيارات المسبقة:

| المزود | الحصول على مفتاح | ملاحظات |
|---|---|---|
| **Gemini** (Google) | aistudio.google.com | ⭐ مجاني بسخاء — الخيار الموصى به للبداية |
| **OpenAI** | platform.openai.com | الأقسم عربياً (مدفوع) |
| **OpenRouter** | openrouter.ai | بوابة موحدة لعشرات الموديلات |
| **Groq** | console.groq.com | سرعة فائقة (مجاني للتجربة) |
| **Ollama** | تثبيت محلي ollama.com | ⭐ مجاني تماماً وبلا إنترنت — يعمل على جهازك |
| **مخصص** | أي مزود متوافق | أدخل عنوان API يدوياً |

---

## خطوات الإعداد

### 1) افتح صفحة الإعداد
الإعدادات ← إعدادات الذكاء الاصطناعي (`/settings/ai`)

### 2) اختر المزود
اختيارك من القائمة يعبئ **عنوان API** تلقائياً:
- Gemini: `generativelanguage.googleapis.com/v1beta/openai/`
- Ollama: `localhost:11434/v1`

### 3) أدخل الموديل
مثال للنص الحر حسب المزود:
- Gemini: `gemini-2.0-flash` (سريع ومجاني) أو `gemini-2.5-pro`
- OpenAI: `gpt-4o` / `gpt-4o-mini`
- OpenRouter: `google/gemini-2.0-flash-001`
- Ollama: `llama3.1` أو `qwen2.5` (جيد للعربية)

> 💡 **توصية عربية**: موديلات Gemini و GPT-4o هي الأقوى بالعربية المحاسبية. Ollama مع `qwen2.5` خيار محلي جيد إن كان الإنترنت مشكلة.

### 4) الصق مفتاح API
- حقل كلمة مرور بعين إظهار/إخفاء
- **الحالة الحالية معروضة**: `****` إن كان هناك مفتاح محفوظ أو مصدره `env`
- المفتاح المحفوظ **لا يُعاد إرساله** عند الحفظ — لا يغادر جهازك بعد التخزين (يخزن في الطبقة الرئيسية مشفراً)

### 5) فعّل الخدمة
مفتاح تشغيل/تعطيل — يعطّل الوكيل كله عند الإيقاف.

### 6) اختبر الاتصال ⭐
زر **«اختبار الاتصال»**:
- ✅ نجاح: يعرض اسم الموديل الذي رد فعلاً
- ❌ فشل: رسالة الخطأ الحقيقية (مفتاح خاطئ؟ موديل غير موجود؟ شبكة؟)

## أفضل الممارسات

| الممارسة | لماذا |
|---|---|
| ابدأ بـ Gemini Flash المجاني | كافٍ تماماً للاستخدام اليومي |
| اختبر قبل التمكين | يكشف فوراً أي خطأ إعداد |
| مفتاح لكل بيئة | افصل مفتاح التجربة عن الإنتاج |
| راقب quota | المفاتيح المجانية لها حدود طلبات/دقيقة |
| Ollama للمؤسسات الحساسة | البيانات لا تخرج من الجهاز إطلاقاً |

---

## تعطيل الوكيل عن مستخدم

الوكيل يظهر لمن يملك صلاحية `ai.use`:
- لمنعه عن دور معين: الأدوار ← عدّل الدور ← أزل `ai.use`
- الصفحة (`/ai`) والودج العائم يخفيان تلقائياً بلا الصلاحية

## استكشاف الأخطاء السريع

| المشكلة | الحل |
|---|---|
| «غير مكوَّن» في لوحة الدردشة | أكمل الإعداد أعلاه — البطاقة ترشدك للصفحة |
| اختبار الاتصال فاشل: 401 | المفتاح خاطئ أو منتهي |
| 404 / model not found | اسم الموديل غير صحيح لهذا المزود |
| مهلة الشبكة | راجع الإنترنت أو عنوان API (خاصية Ollama: تأكد أن الخدمة تعمل) |
| ردود عربية رديئة | جرّب موديلاً أقوى (قائمة [الموديلات](#3-أدخل-الموديل)) |
