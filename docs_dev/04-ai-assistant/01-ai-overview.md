# الوكيل المحاسبي الذكي — نظرة عامة

> مساعد أعمال محاسبي يجري محادثات عربية، يبحث في بياناتك، ينشئ المستندات ويرحّلها — **بموافقتك الصريحة قبل أي كتابة**

---

## ما هو؟

مساعد ذكاء اصطناعي مدمج (249 أداة) يفهم:
- **العربية الفصحى والعامية** — بحث متسامح مع الأخطاء الإملائية (أ/إ/آ، ة/ه، ى/ي + Levenshtein)
- **الأرقام الهندية**: «١٣٢٬٥٠٠» = 132,500
- **فواصل الآلاف وكلمات العملة**: «132,500 ريال»
- **التواريخ الحرة**: «12-8» و «15 أغسطس 2026» و «غداً»
- **أسماء كياناتك**: يحل «شركة الأمل» لما تقصده حتى مع أخطاء إملائية

## ثلاث نقاط دخول

| الواجهة | الوصول | مناسب لـ |
|---|---|---|
| **صفحة الدردشة الكاملة** | `/ai` من القائمة | جلسات عمل طويلة + درج الجلسات المحفوظة |
| **الودج العائم** ⭐ | زر عائم أسفل الشاشة في كل الصفحات (Ctrl+K) | سؤال سريع دون مغادرة صفحتك |
| **رقائق سريعة** | أزرار فوق حقل الإدخال | «فاتورة مبيعات» / «ملخص المبيعات» / «المخزون» / «تقرير» / «انتقال» — نقرة واحدة ترسلها |

## ماذا يستطيع أن يفعل؟

### يبحث (30+ أداة بحث)
> «دور على عميل اسمه ابو محمد»
> «أريني سندات القبض الشهر الماضي»

### يقرأ ويحلل (تقارير فورية)
> «اعطني ملخص مبيعات الشهر»
> «كم صافي ربحنا هذا الربع؟»
> «ما متابعاتي العاجلة اليوم؟» (مهام متأخرة + فرص متجاوزة + عملاء بلا تواصل)

### ينشئ ويرحّل (بموافقتك)
> «سجل فاتورة مبيعات لعميل بقالة النور، خمس كيس رز بسمتي بسعر خمسة آلاف وخمسمئة، نقدي من الصندوق الرئيسي»
→ بطاقة موافقة تعرض عدد الأصناف و**الإجمالي التقديري قبل الضريبة** ← موافقة ← فاتورة مسودة
> «رحّلها» ← ترحيل بقيد كامل

### معالجات مركبة بخطوة واحدة
> «اصنع وترحّل فاتورة شراء من مورد X...» — إنشاء + ترحيل ذرّي
> «جهز رواتب الشهر» — معاينة ← إنشاء ← ترحيل (مع تراجع تلقائي عند أي فشل)
> «حول العميل المحتمل سالم لعميل وافتح له فرصة» — تحويل ذرّي موحد

### يتكلم بصوتك
زر 🎙 في حقل الإدخال — إدخال صوتي عربي (ar-SA) أو إنجليزي حسب لغة الواجهة.

## لماذا هو آمن؟ (ملخص)

| الضمانة | كيف |
|---|---|
| **لا كتابة بلا موافقة** | كل أداة كتابة تتوقف على بطاقة تأكيد كهرمانية (موافقة/رفض) |
| **أدواته = نفس واجهاتك** | لا مسار بيانات منفصل — يستدعي نفس APIs مع نفس حراس العمل |
| **صلاحياتك تنطبق عليه** | لا يرى أداة ولا ينفذ شيئاً خارج صلاحيات دورك |
| **حارس هلوسة** | ادّعى تنفيذاً بلا أداة حقيقية؟ يُحذف رده ويُعاد تشغيله حتى يعترف أو ينفذ |
| **حارس تكرار** | نفس الأداة بنفس المعطيات فشلت مرتين ← يوقف المحاولة الثالثة برسالة صادقة |
| **سجل تدقيق كامل** | كل كتابة تدخل audit_logs باسم الأداة — تتبع كامل لما فعله |

التفاصيل الكاملة في **[دليل الأمان](05-ai-safety.md)**.

## بنية المحادثة

| العنصر | الوصف |
|---|---|
| **رسائلك** | فقاعة زرقاء + زر نسخ |
| **ردود المساعد** | Markdown منسق: عناوين، قوائم، **جداول**، أرقام عريضة |
| **بطاقات الأدوات** | شارة حالة (بانتظار/جارٍ/نجاح/خطأ/مرفوض) + **ملخص عربي للمعاملات** + توسيع لعرض JSON والنتائج |
| **رقائق الاقتراح** | تحت آخر رد: «انتقال للصفحة» 🧭 و«متابعة» ✨ — نقرة تنقلك أو ترسل |
| **مؤشر التفكير** | نقاط نطاطة أثناء المعالجة |
| **إعادة التوليد** | زر على آخر رد |

## الجلسات

- **حفظ تلقائي** في الخلفية (بلا انتظار) + عند إغلاق النافذة
- **درج الجلسات**: مجمعة زمنياً (اليوم/أمس/هذا الأسبوع/أقدم) مع بحث وإعادة تسمية وحذف
- **تصدير**: JSON (تقني) أو Markdown (للقراءة)
