# نظام تعدد العملات

> كل مستند يحمل عملته وسعر صرفه ومعادله بالأساسية — والتقارير تفصل عند التعدد

---

## النموذج المفاهيمي

### العملة الأساسية
- كل شركة لها عملة أساسية (`isDefault`) — **الريال اليمني YER افتراضياً**
- سعرها = **1 دائماً** — كل التقارير الإجمالية تُعرض بها

### دلالة سعر الصرف (القاعدة الحاسمة)
```
rate(USD) = 1500  يعني:  1 دولار = 1500 ريال
```
**سعر الصرف = كم وحدة من الأساسية تساوي 1 من هذه العملة**

### معادلة التحويل
```ts
convertAmount(value, fromRate, toRate) = value * fromRate / toRate
// مثال: 100$ إلى YER = 100 * 1500 / 1 = 150,000
```

---

## الأعمدة الثلاثية في كل مستند

كل مستند مالي (فواتير المبيعات/المشتريات + السندات) يخزن:

| العمود | المحتوى |
|---|---|
| `currencyCode` | عملة المستند (3 حروف ISO — YER افتراضية) |
| `exchangeRate` | سعر الصرف لحظة الإنشاء (`numeric(18,6)`) |
| `baseCurrencyAmount` | **المعادل بالأساسية = amount × rate** (يحسبه الـ API دائماً — لا يثق بقيمة العميل) |

الأسطر تحمل `baseCurrencyLineTotal` بنفس المنطق.

> ⭐ **مصدر حقيقة واحد**: المعادل يُحسب **خدمياً** عند الإنشاء (auto-compute في API layer) — الواجهة تعرضه حياً فقط.

---

## في واجهات الفواتير والسندات

1. **محدد العملة** (CurrencySelect) + حقل **سعر الصرف** جنباً لجنب
2. **قراءة حية «المعادل بالأساسية»** تحت الحقلين — تتحدث مع كل تغيير
3. تغيير العملة **يجلب سعرها تلقائياً** من جدول العملات
4. عند التحرير: تعبأ من قيم المستند المحفوظة

---

## في التقارير (الفصل بالعملة)

عند وجود عملات متعددة في فترة، التقارير تعرض **`CurrencyBreakdown`**:

| المكوّن | المحتوى |
|---|---|
| الجدول | العملة / المبلغ / **المعادل بالأساسية** / شريط نسبة % |
| شارة | «متعدد العملات» |
| الخلاصة | الإجمالي بالأساسية |

متوفر في: تحليل المبيعات (الإيرادات)، تحليل الأرباح (الإيرادات + COGS)، وغيرها.

> **القاعدة**: لا يُجمع مبلغ بعملة مع آخر بعملة مختلفة مباشرة — كل جمع يمر عبر المعادل بالأساسية.

## الأصول المشتركة (`src/core/utils/currencyConverter.ts` + `useCurrencyDisplay`)

| الدالة | الوظيفة |
|---|---|
| `getCurrency(code)` | بحث + fallback |
| `convertAmount(v, from, to)` | عبر الأساسية |
| `convertToBase(v, rate)` / `convertFromBase(v, rate)` | اتجاه واحد |
| `formatWithSymbol(v, currency)` | «ر.ي 1,234.50» أو «USD 1,234.50» |
| `summarizeMultiCurrency(record)` | Record<code, amount> → الأساسية |
| `useCurrencyDisplay()` | hook جاهز للشاشات (currencies + default + format + convert) |

---

## سلوكيات دقيقة

| الحالة | السلوك |
|---|---|
| عملة غير معروفة (rate 0) | fallback للمبلغ الأصلي (لا NaN) |
| rate ≤ 0 في فاتورة | **رفض** (منع قسمة على صفر) |
| NaN/Infinity | تتحول 0 (لا تتسرب للتقارير) |
| `formatWithSymbol` | symbol لو موجود وإلا الكود |
| أرصدة الكشوف | تتبع عملة المستند — عمود شارة العملة في الجداول |

---

## حالات استخدام

| الموقف | الخطوات |
|---|---|
| بعت بالدولار | فاتورة ← العملة: USD ← السعر يتعبأ (1500) ← «المعادل» يعرض بالريال |
| سند بعملة أجنبية | السند ← العملة + السعر ← القيد يسجل المعادل أيضاً |
| عميل دولار وعميل ريال | كل مستند بعملته — تقرير المبيعات سيفصلهما تلقائياً |
| سعر الصرف تغير | عدّل جدول العملات — المستندات **الجديدة** تستخدم السعر الجديد (القديمة تحفظ سعرها التاريخي) |

---

## ملاحظات للدقة المحاسبية

- **سعر الصرف التاريخي محفوظ**: مستند بسعر قديم لا يتأثر بتعديل الجدول لاحقاً (أثر تدقيقي)
- **الترحيل بالأساسية**: القيود اليومية تعتمد المعادل — الميزان دائماً بعملة واحدة
- **YER_CODE ثابت موحد** (`'YER'`) — لا نصوص مبعثرة
