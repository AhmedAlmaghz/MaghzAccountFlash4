# حل المشكلات الشائعة

> أعراض شائعة وأسبابها وحلولها

---

## التشغيل والاتصال

### التطبيق لا يفتح / شاشة خطأ قاعدة البيانات
| العرَض | الحل |
|---|---|
| شاشة «تعذر الاتصال بقاعدة البيانات» | 1) زر «إعادة المحاولة» 2) تحقق من تشغيل PostgreSQL 3) راجع بيانات الاتصال بالإعدادات ← قاعدة البيانات 4) خيار الطوارئ: «استخدام PGlite» (بيانات محلية — لا تفقد بياناتك الخارجية) |
| لأول مرة لا يظهر المعالج | نادر — احذف `localStorage['maghzaccount-onboarding']` من أدوات المتصفح/DevTools ثم أعد التحميل |

### فقدت كلمة مرور admin
- **نسخة سطح المكتب (PG خارجي)**: زر «نسيت كلمة المرور» إن ظهر — أو من مدير آخر
- **لا يوجد مدير آخر + PGlite**: أعد التهيئة (الإعدادات ← إعادة التهيئة ← «مسح جميع البيانات» بمنطقة الخطر) — **خذ نسخة احتياطية أولاً**
- **قاعدة تطوير**: `npm run db:reset` يعيد بناء كل شيء بكلمة مرور جديدة

## الدخول والجلسات

| العرَض | السبب والحل |
|---|---|
| «5 محاولات فاشلة» ثم قفل | حماية brute-force — انتظر 5 دقائق أو سجل بمستخدم آخر |
| خروج تلقائي مفاجئ | انتهاء الخمول (30 دقيقة) أو الحد المطلق (8 ساعات س سطح المكتب) — طبيعي |
| بعد تغيير كلمة مروري طُردت جلساتي الأخرى | مقصود — سياسة أمنية |
| «حسابك موقوف» | مديرك عطّل حسابك — راجع admin |

## المستندات والفواتير

### «لا يمكن حذف/تعديل الفاتورة»
| الرسالة تقريباً | السبب |
|---|---|
| الفاتورة مرحّلة | النظام يحمي المرحّل — صحح بمعالجة لاحقة (سند/مردود) |
| عليها مدفوعات | خصم المدفوعات أولاً (سند عكسي) ثم الحذف |
| تقليل paid_amount مرفوض | الزيادة فقط مسموحة — العكس بسند عكسي |

### سند القبض لا يقبل المبلغ
| الحالة | الحل |
|---|---|
| «المبلغ المطبق يتجاوز المستحق» | أدخل ≤ المستحق المعروض |
| «يتطلب فاتورة» | اختر «على الحساب» أو فاتورة من القائمة |
| الفاتورة لا تظهر في القائمة | حالتها draft أو مدفوعة بالكامل — فقط المرحّلة بباقٍ تظهر |

### «invalid input syntax for type uuid»
حدث تاريخياً — النسخ الحالية تعالجه. إن ظهر: حدّث التطبيق + تأكد أن الحقول المطلوبة غير فارغة (المورد/العميل).

### التاريخ يظهر غريباً أو بصيغة مختلفة
- الصيغة تتبع **الإعدادات ← الشركة ← صيغة التاريخ** (و notة التقويم هجري/ميلادي)
- عدّلها هناك — كل الشاشات تتبع فوراً

## المخازن

| العرَض | الحل |
|---|---|
| «رصيد غير كافٍ» عند بدء أمر تشغيل | تقرير النقص يعرض المادة الناقصة والكمية — اشتر/حوّل ثم أعد |
| الرصيد لا يتطابق مع الجرد | سجّل تسوية (الفرق + السبب) ← اعتماد ← ترحيل — يصحح الرصيد والقيد |
| حركات لا أذكر إنشاءها | كل عملية تولد حركة تلقائياً — عمود **المرجع** يعرض رقم المستند المصدر |
| المخزون يظهر 0 رغم الشراء | الفاتورة **draft** (لم تُرحّل) — الترحيل هو ما يحرك المخزون |

## الموارد البشرية

| العرَض | الحل |
|---|---|
| «رصيد الإجازة لا يكفي» | الرسالة تعرض المتبقي — راجع سياسة الأرصدة أو النوع «بدون راتب» |
| «الفترة لها مسير بالفعل» | يوجد draft/posted لنفس الشهر — راجعه أو ألغه (يحرر الفترة) |

| التأخير لم يحسب | اضبط «سماحية التأخير» في سياسات HR — الاشتقاق يحترمها |
| مسير الرواتب فشل ترحيله | المعالج يحذف المسودة تلقائياً (تراجع) — راجع رسالة الخطأ وأعد |

## قبل الاتصال بالدعم — جهز

1. رقم المستند/الشاشة ورابطها (URL)
2. رسالة الخطأ **حرفياً** (أو لقطة)
3. خطوات إعادة الإنتاج
4. دورك + (إن سُئلت) إصدار النظام (أسفل صفحة الدخول)
5. هل المشكلة تتكرر لمستخدم آخر؟
