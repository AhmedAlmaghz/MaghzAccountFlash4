# مخططات سير العمل (دورات الحياة)

> كل دورة حياة مستند في النظام — الحالات والانتقالات والآثار

---

## المستندات المالية

### فاتورة المبيعات
```
            ┌───────── إلغاء ─────────┐
            ▼                         │
draft ──ترحيل──▶ posted ──سند قبض──▶ partially_paid ──▶ paid
(مسودة)          (مرحّلة)                (مدفوعة جزئياً)   (مدفوعة)
```
| الانتقال | الشروط | الأثر |
|---|---|---|
| ترحيل | — | قيد (نقدي=خزينة/paid • آجل=عميل) + حركة out + رصيد العميل |
| سند قبض | amountApplied ≤ المستحق | paid_amount ↑ + status تلقائي + رصيد ينقص |
| إلغاء | مرحّلة | تسقط من التقارير والحسابات |
| حذف | **draft + بلا مدفوعات فقط** | — |

### فاتورة المشتريات
مرآة: ترحيل (نقدي=خزينة/آجل=مورد) + حركة in + رصيد المورد — السداد بسند صرف.

### عرض السعر
```
draft ──▶ accepted ──تحويل──▶ converted (محمي من الحذف)
   └──▶ rejected
```

### المردودات (بيع/شراء)
```
draft ──ترحيل──▶ posted
```
بيع: حركة **in** + رصيد عميل ينقص | شراء: حركة **out** + رصيد مورد ينقص. المرحّل محمي.

### السندات (قبض/صرف)
```
draft ──ترحيل──▶ posted (لا حذف ولا تغيير ربط بفاتورة)
```
| السند | القيد |
|---|---|
| قبض | مدين خزينة / دائن عميل (+ تخصيص الفاتورة ذرّي) |
| صرف لمورد | مدين مورد / دائن خزينة (+ تخصيص) |
| صرف مصروف | مدين حساب المصروف / دائن خزينة |

### قيد اليومية
```
draft ──ترحيل──▶ posted ──▶ cancelled
```
مرحّل = لا تعديل — التصحيح بقيد عكسي.

## التصنيع — دورة الإنتاج ⭐

```
planned ──بدء──▶ in_progress ──إكمال──▶ completed
   ▲                 │
   │                 └──إلغاء (+إرجاع اختياري)──▶ cancelled
   └────────────── إعادة فتح (تصفير المسار) ──┘
```
| المرحلة | البوابة | الأثر |
|---|---|---|
| **بدء** | توفر كل خامات في كل المستودعات (نقص = فشل بتقرير) | حركات out + **قيد WIP** |
| **إكمال** | كمية منتجة + مستودع التام | استلام in + تسوية الفرق + **قيد تام** + **تثبيت الفعلي في DB** |
| إلغاء من in_progress | خيار إرجاع | حركات in عكسية |
| إعادة فتح | — | تواريخ/WIP/actuals تصفّر — يبدأ نظيفاً |

**سلوك فعلي = مخطط**: عند الإكمال actualQuantity يتعبأ بالمخطط وactualUnitCost بunitCost — عدّل فقط المنحرف (variance-by-exception).

## الموارد البشرية

### الإجازة
```
pending ──▶ approved | rejected
   │          └── cancelled
   └── cancelled
```
الاعتماد: فحص رصيد صارم (المعتمد+المعلق − هذه ≤ رصيد النوع) — رفض بمتبقٍ عربي. unpaid بلا حد.

### مسير الرواتب
```
draft ──ترحيل──▶ posted          (قيد gross-up ذري مع تغيير الحالة)
   │       └──▶ cancelled        (يحرر الفترة لمسير جديد)
   └── حذف (draft فقط — مسار التراجع)
```
فترة (شهر/سنة) واحدة draft/posted — **الخادم يعيد حساب كل سطر** دائماً.

### نهاية الخدمة
```
draft ──اعتماد──▶ approved ──دفع بخزنة──▶ paid
```
| المرحلة | القيد |
|---|---|
| اعتماد | مدين 52501 / دائن 21503 (استحقاق يظهر بالالتزامات) |
| دفع | مدين 21503 / دائن حساب الخزينة |

### الحضور
Upsert بـ UNIQUE(employee_id, date) — نفس اليوم يحدّث لا يكرر. التأخير والOT يشتقان خدمياً من السياسة (اليدوي > 0 يفوز).

## CRM

### العميل المحتمل
```
new ──▶ contacted ──▶ qualified ──▶ converted (إلى Customer + فرصة اختيارية)
                    └──▶ lost
```
حذف Lead له مراجع (فرص/مهام/أنشطة) = **مرفوض** برسالة تفصيلية.

### الفرصة (آلة أمامية صارمة)
```
new ──▶ qualified ──▶ proposal ──▶ negotiation ──▶ won   (probability=100, closeDate)
                                        └────────▶ lost (probability=0, closeDate)
```
- **لا رجوع** — سوحب Kanban غير قانوني = toast يشرح
- **won/lost نهائية** — تختم close_date وتثبت الاحتمالية في نفس الـ UPDATE
- **won ≠ فاتورة** — النظام يسأل عن إنشائها ولا يبادر تلقائياً

### المهمة
```
pending ──▶ completed | cancelled
```
متأخرة = non-completed + non-cancelled بتاريخ قبل اليوم (مقارنة يوم كامل).

## المخزون

### التسوية
```
draft ──اعتماد──▶ approved ──ترحيل──▶ posted
```
الترحيل: حركة adjustment + تحديث الرصيد + قيد (زيادة/نقص بحساب الهالك).

### التحويل
```
pending ──إكمال──▶ completed    (حركتان متقابلتان out + in)
   └── حذف (pending فقط)
```

### حركة المخزون (قراءة)
سجل تدقيقي من العمليات فقط — أنواعها: `in` (شراء/مردود بيع/إكمال إنتاج) و `out` (بيع/مردود شراء/بدء إنتاج) و `transfer` و `adjustment` — **المرجع رقم المستند البشري دائماً**.

## المستخدم والجلسة

```
مجهول ──login──▶ نشط ──30 دقيقة خمول / 8 ساعات مطلقة / خروج──▶ مجهول
```
تغيير كلمة مرور أو تعطيل أو حذف = **بطلان فوري لكل جلسات المستخدم**.

## لوحة تحكم سريعة (كل الدورات في جدول)

| الكيان | الحالات | النهائية | المحمي من |
|---|---|---|---|
| فاتورة بيع/شراء | draft→posted→(paid) | paid / cancelled | حذف المرحّل، تعديل أسطره |
| عرض | draft→accepted→converted | converted | حذف converted |
| مردود | draft→posted | posted | حذف المرحّل |
| سند | draft→posted | posted | حذف/تعديل ربط المرحّل |
| قيد | draft→posted | cancelled | تعديل المرحّل |
| أمر تشغيل | planned→in_progress→completed | completed | إكمال غير مبدوء |
| إجازة | pending→approved/rejected | — | تجاوز الرصيد |
| مسير | draft→posted | — | تكرار الفترة |
| EOS | draft→approved→paid | paid | دفع بلا اعتماد |
| فرصة | new→…→won/lost | won/lost | الرجوع للخلف |
