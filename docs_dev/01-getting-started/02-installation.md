# التثبيت والتهيئة

> متطلبات التشغيل وأوضاع قاعدة البيانات وبدء التطبيق

---

## متطلبات التشغيل

### تطبيق سطح المكتب (Electron)
| المتطلب | الحد الأدنى |
|---|---|
| نظام التشغيل | Windows 10/11 (64-bit) |
| المعالج | 2 cores |
| الذاكرة | 4 GB RAM |
| المساحة | 500 MB |

### قاعدة بيانات PostgreSQL خارجية (اختياري لكن موصى به)
| المتطلب | القيمة |
|---|---|
| الإصدار | PostgreSQL 16 أو أحدث |
| الاتصال | localhost أو خادم شبكة |

> 💡 لا تريد تثبيت PostgreSQL؟ التطبيق يعمل فوراً بـ **PGlite** — قاعدة PostgreSQL كاملة تعمل داخل التطبيق نفسه (WASM) دون أي إعداد.

## أوضاع قاعدة البيانات

يقدم التطبيق وضعين للتخزين، تختارهما في أول تشغيل (ويمكن تغييرهما لاحقاً من إعدادات قاعدة البيانات):

### 1) PGlite — قاعدة محلية بلا إعداد (الافتراضي)
- PostgreSQL حقيقي مضغوط (WebAssembly) يعمل داخل التطبيق
- **صفر إعداد**: يعمل فور الفتح
- مناسب للاستخدام الفردي والتجربة والبيانات الصغيرة
- ⚠️ البيانات محلية على هذا الجهاز فقط

### 2) PostgreSQL خارجي — للاستخدام الجاد
- خادم PostgreSQL كامل (محلي أو على الشبكة)
- يدعم تعدد المستخدمين والنسخ الاحتياطي والأداء العالي
- يتطلب بيانات اتصال: المضيف، المنفذ، اسم القاعدة، المستخدم، كلمة المرور

| الإعداد الافتراضي | القيمة |
|---|---|
| Host | `localhost` |
| Port | `5432` |
| Database | `MaghzAccountFlash35` |
| Username | `maghz` |

## أوامر التشغيل (للمطورين)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل نسخة الويب (تستخدم PGlite)
npm run dev

# تشغيل نسخة سطح المكتب (Electron + PostgreSQL)
npm run electron:dev

# البناء النهائي (تثبيت ويندوز portable)
npm run electron:build

# بناء محلي بدون توقيع
npm run electron:build:local
```

### أوامر قاعدة البيانات
```bash
# إعادة تهيئة القاعدة من الصفر (تحذير: يمسح كل البيانات)
npm run db:reset            # بأسئلة تأكيد تفاعلية
npm run db:reset:force      # مباشرة بلا أسئلة

# فحص انسجام مخطط Drizzle مع ترحيلات SQL
npm run db:check

# مزامنة قاعدة خارجية (متقدم)
npm run db:sync
```

### أوامر الجودة والاختبارات
```bash
npm run lint          # فحص ESLint
npm run test          # 1300+ اختبار وحدة (Vitest)
npm run test:e2e      # اختبارات e2e (Playwright، تحتاج قاعدة تطوير)
npm run preflight     # lint + typecheck + tests دفعة واحدة
```

## أول تشغيل: ماذا يحدث؟

1. **معالج التهيئة** يفتح تلقائياً (5 خطوات موجهة) — يراجع **[دليل معالج التهيئة](03-onboarding.md)**
2. بعد إكمال المعالج: شاشة **تسجيل الدخول** — أدخل بيانات المدير التي أنشأتها
3. تصل إلى **لوحة التحكم** الرئيسية

> ⚠️ **مهم**: في خطوة البيانات الأولية قد يولّد النظام كلمة مرور عشوائية لحساب `admin` — انسخها فوراً من الشاشة الصفراء، ويمكنك تغييرها لاحقاً من صفحة المستخدمين.

## استكشاف سريع للواجهة

بعد الدخول ستجد:

- **الشريط الجانبي الأيمن** (RTL): كل الوحدات مقسمة لمجموعات، يتقلص/يتمدد من زر أسفله
- **الشريط العلوي**: بحث عام (Ctrl+K)، اسم الشركة، بياناتك، تبديل اللغة والثيم الداكن، تسجيل خروج
- **الجوال**: قائمة منسحبة + شريط تبويبات سفلي

كل التفاصيل في **[تسجيل الدخول والواجهة](04-login-interface.md)**
