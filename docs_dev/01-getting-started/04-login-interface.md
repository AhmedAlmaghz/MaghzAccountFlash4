# تسجيل الدخول والواجهة الرئيسية

> الجلسات، الشاشة الرئيسية، التنقل، لوحة الأوامر السريعة

---

## تسجيل الدخول

شاشة بطاقة وسطية بخلفية متدرجة متحركة وشعار النظام.

### الحقول
| الحقل | الوصف |
|---|---|
| **اسم المستخدم** | إلزامي — تركيز تلقائي عند فتح الصفحة |
| **كلمة المرور** | إلزامي — زر عين لعرض/إخفاء |
| **تذكرني** | يحفظ اسم المستخدم لهذا الجهاز ويملؤه تلقائياً في الزيارات القادمة |

بيانات غير صحيحة ← رسالة حمراء بالعربية مع اهتزاز البطاقة: «اسم المستخدم أو كلمة المرور غير صحيحة».

> 🔐 **حماية من التخمين**: بعد 5 محاولات فاشلة خلال 60 ثانية يُقفل الدخول 5 دقائق (لكل اسم مستخدم + لكل نافذة).

---

## سلوك الجلسة

| البند | السلوك |
|---|---|
| **انتهاء الخمول** | 30 دقيقة بلا نشاط ← خروج تلقائي إلى شاشة الدخول |
| **تتبع النشاط** | حركة الفأرة/الكيبورد/اللمس/التمرير تُجدّد المؤقت تلقائياً |
| **حد أقصى للجلسة** (نسخة سطح المكتب) | 8 ساعات مطلقة — بعدها يُطلب دخول جديد حتى مع النشاط |
| **فحص الاستعادة** | عند إعادة تحميل الصفحة يتحقق النظام من بصمة الجلسة ومن أن المستخدم لا يزال نشطاً في القاعدة |
| **قطع الجلسات** | تغيير كلمة المرور أو تعطيل/حذف المستخدم يبطل كل جلساته فوراً |

## الواجهة الرئيسية — نظرة شاملة

### الشريط الجانبي (يمين RTL)
- مقسم إلى **5 مجموعات**: لوحة التحكم، المساعد الذكي، العمليات (مبيعات/مشتريات/مخازن/تصنيع)، الإدارة (حسابات/موظفون/CRM)، التقارير والإعدادات
- **قابل للتقلص** (288px ↔ 72px) من زر أسفله — الوضع المتقلص يعرض أيقونات مع tooltips
- عناصر الآباء تتمدد لتعرض الأبناء بخط رابط عمودي
- العنصر النشط يحمل شريط تدرّج ملوّن
- **مفلتر بصلاحياتك**: ما لا تملك له صلاحية وصول لا يظهر أصلاً

### الشريط العلوي (الرأس)
| العنصر | الوظيفة |
|---|---|
| 🔍 **البحث** | يفتح **لوحة الأوامر** (Ctrl+K) — انظر أدناه |
| 🏢 **اسم الشركة النشطة** | مع أيقونة مبنى |
| 👤 **بطاقة المستخدم** | صورة رمزية (أول حرف) + اسمك + دورك بين قوسين |
| 🌐 **تبديل اللغة** | عربي ⇄ English فوري |
| 🌙 **تبديل الثيم** | داكن / فاتح |
| 🚪 **خروج** | يحرر الجلسة ويبطلها على الخادم |

### الجوال
- زر همبرغر ← قائمة منسدحة RTL (تغلق بـ Esc أو بلمس الخلفية)
- **شريط سفلي**: أول 4 وحدات متاحة لك + زر «المزيد»

## لوحة الأوامر — Ctrl+K

أقوى أداة تنقل في النظام. تبحث متزامنة في:

### 1) الصفحات — كتالوج 84 صفحة
- كل صفحات النظام مع **كلمات مفتاحية عربية وإنجليزية**
- مثال: اكتب «ميزان» ← تجد صفحة ميزان المراجعة
- **مفلترة بصلاحياتك** — لا تظهر لك صفحة محجوبة عنك
- النتائج مجمعة حسب الوحدة مع تظليل أجزاء النص المطابقة بالكهرماني

### 2) البيانات الحية
بحث بفاصل 250ms في 6 مصادر (أول 5 نتائج لكل مصدر):
- **العملاء** (الاسم + الهاتف) ← ينقل لصفحة العملاء
- **الموردون** • **المنتجات** (الاسم + الكود) • **الموظفون** (الاسم + الرقم الوظيفي) • **العملاء المحتملون** • **الفرص**

### التنقل بلوحة المفاتيح
| المفتاح | الفعل |
|---|---|
| `↑` `↓` | تحرك بين النتائج |
| `Enter` | افتح المحدد |
| `Esc` | إغلاق اللوحة |

> 💡 **Ctrl+K يُشارك مع ودج الدردشة الذكية** — يعتمد أيهما يفتح على السياق؛ اضغطه مرة أخرى للتبديل.

## العناصر المشتركة في كل الصفحات

كل صفحات الوحدات مبنية على أنماط موحدة — تعرفها مرة تقرأها في كل مكان:

| العنصر | الشكل |
|---|---|
| **رأس الصفحة** | أيقونة + عنوان + وصف + أزرار الإجراءات (إنشاء/تصدير/طباعة) |
| **شريط الفلاتر** | بحث نصي + قوائم منسدلة (حالة، تصنيف...) + زر مسح |
| **شبكة الإحصاءات** | بطاقات KPI أعلى الجدول (عدد، إجمالي، حالة...) |
| **الجدول الذكي** | صفوف قابلة للنقر + ترقيم صفحات + حالة فراغ بشارة إجراء |
| **الترقيم** | أزرار أول/سابق/تالي/أخير + حجم الصفحة (10/25/50/100) + مؤشر «1–25 من 132» |
| **أزرار الحالة** | `StatusBadge` موحد لكل حالات المستندات بألوان ثابتة |

### الحقول الذكية (SmartSelect)
كل قوائم الاختيار في النظام تبحث نصياً وتعرض معلومات مساعدة:
- **اختيار المنتج** يعرض شارات: السعر، الباركود، الوحدة، (والمخزون في سياقات المخازن/التصنيع)
- **اختيار العميل/المورد** يعرض الرصيد والهاتف
- **اختيار الحساب** يعرض الكود + الاسم مع تسطيح شجرة الحسابات

### حوار تحذير التكرار
عند إنشاء كيان أو مستند يشبه واحداً قائماً:
- **تطابق تام** (بعد تطبيع عربي) ← حوار أحمر يمنع الإنشاء
- **تشابه ≥ 85%** ← حوار كهرماني يسرد المتشابهات بنسبة مئوية وشريط تقدم — خيارك: إلغاء أو «متابعة رغم التشابه»

## اختصارات لوحة المفاتيح

| الاختصار | الفعل |
|---|---|
| `Ctrl+K` | لوحة الأوامر / ودج الذكاء الاصطناعي |
| `Enter` (في الدردشة) | إرسال الرسالة |
| `Shift+Enter` | سطر جديد في الدردشة |
| `Esc` | إغلاق المودال/اللوحة/القائمة المنسدحة |
