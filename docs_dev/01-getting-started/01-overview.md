# نظرة عامة على النظام

> **maghzaccount-pro** — نظام تخطيط موارد المؤسسات (ERP) ومحاسبة مزدوجة القيد متكامل، مصمم للمنشآت الصغيرة والمتوسطة في العالم العربي.

---

## ما هو maghzaccount-pro؟

maghzaccount-pro هو نظام أعمال متكامل يجمع المحاسبة المالية والإدارية في تطبيق واحد عربي أولاً (RTL). يعمل كتطبيق سطح مكتب (Electron) مع قاعدة بيانات PostgreSQL حقيقية، ويغطي الدورة التجارية كاملة من شراء المواد الخام وحتى تحصيل الإيرادات وقياس الربحية.

### الفلسفة التصميمية
- **عربي أولاً**: واجهة RTL كاملة بخط Cairo، تقويم ميلادي/هجري، أرقام عربية
- **محاسبة مزدوجة حقيقية**: كل عملية تجارية تنتج قيداً متوازناً تلقائياً (Double-Entry)
- **مصدر حقيقة واحد**: الأرصدة تُحسب من قيود اليومية دائماً، لا أرقام مخزنة منفصلة
- **عزل الشركات**: كل بيانات مشدودة إلى `company_id` — لا تسرب بيانات بين الشركات
- **وكيل ذكي مدمج**: مساعد محاسبي بـ 249 أداة يتحدث العربية ويطلب موافقتك قبل أي كتابة

## أبرز القدرات

### المحاسبة المالية
- شجرة حسابات جاهزة متوافقة مع IFRS (أصول/التزامات/حقوق ملكية/إيرادات/مصروفات)
- قيود يومية تلقائية لكل عملية (فواتير، سندات، رواتب، تصنيع)
- الرصيد الافتتاحي مدمج في كل الكشوفات وأعمار الديون بلا استثناء
- تقارير مالية: ميزان مراجعة، ميزانية، أرباح وخسائر، تدفق نقدي
- حسابات افتراضية قابلة للتكوين لكل نوع ترحيل (خزينة، مدينين، WIP، إنتاج...)

### المبيعات والمشتريات
- فواتير بخطوط أصناف، خصومات على مستوى السطر والفاتورة، VAT قابلة للضبط
- **فاتورة نقدي** = قيدها على الخزنة مباشرة وتسكين `paid`؛ **آجل** = على حساب العميل
- ربط السندات بالفواتير: سند القبض يخصم من رصيد الفاتورة تلقائياً ويغيّر حالتها (مدفوعة/مدفوعة جزئياً)
- حماية مالية: منع الدفع الزائد، منع حذف/تعديل المرحّل، منع حذف عميل له فواتير
- كشف حساب وأعمار ديون لكل عميل/مورد (شرائح 0-30/31-60/61-90/+90)

### المخازن والتصنيع
- مخزون حقيقي لكل منتج×مستودع مع حد أدنى وتنبيه نواقص
- حركات واردة/صادرة/تحويل/تسوية بمرجع رقم المستند البشري
- **دورة إنتاج كاملة**: أمر التشغيل ← البدء يصرف الخامات فعلياً (ببوابة توفر) ← الإكمال يستلم التام ويسوّي الفروقات ويجمّل التكلفة
- قياس تكلفة WIP محاسبياً (معيار IAS 2)

### الموارد البشرية
- رواتب بمحرك حساب موحد (أساسي + مكونات ثابتة/نسبية + أوفر تايم من الحضور)
- ترحيل مسير الرواتب بقيد ذرية (إجمالي مصروف / صافي مستحق / استقطاعات)
- أرصدة إجازات بفحص صارم قبل الاعتماد
- نهاية خدمة بمرحلتين: استحقاق عند الاعتماد + تسوية عند الدفع من خزنة

### تعدد العملات
- الريال اليمني (YER) عملة أساسية + عملات بأسعار صرف (1 USD = 1500 YER مثلاً)
- كل مستند يحمل عملته وسعر صرفه والمعادل بالأساسية
- التقارير تفصل الإجماليات حسب العملة عند التعدد

### الوكيل الذكي
- بحث ضبابي عربي متسامح مع الإملاء (أ/إ/آ، ة/ه، ى/ي)
- إنشاء فواتير/عملاء/قيود بالعامية أو الفصحى — مع بطاقة موافقة قبل أي كتابة
- يفهم الأرقام الهندية (١٢٣)، تواريخ حرة («12-8»، «15 أغسطس 2026»)، وفواصل الآلاف
- حارس هلوسة: إذا ادّعى تنفيزاً بلا أداة حقيقية يُحذف رده ويُعاد تشغيله
- معالجات مركبة: إنشاء + ترحيل فاتورة بخطوة واحدة، معاينة ثم توليد مسير رواتب

## التقنيات المستخدمة (للمهتمين)

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Tailwind CSS 4 |
| سطح المكتب | Electron 42 |
| قاعدة البيانات | PostgreSQL 16+ (خارجي) أو PGlite (محلية WASM) |
| ORM | Drizzle ORM + ترحيلات SQL idempotent |
| الحالة | Zustand |
| الجداول | TanStack Table |
| المخططات | Recharts |
| التصدير | jsPDF + xlsx (تحميل كسول) |
| الاختبارات | Vitest (1300+ اختبار) + Playwright (83 e2e) |

## منصة التشغيل

| الوضع | الوصف |
|---|---|
| **سطح المكتب** | تطبيق Windows portable عبر Electron — قاعدة PostgreSQL خارجية أو محلية |
| **المتصفح** | نسخة ويب — تعمل بـ PGlite محلياً داخل المتصفح (مناسب للتجربة) |

> 💡 **توصية**: لبيانات إنتاج حقيقية استخدم PostgreSQL خارجياً — PGlite محبوس داخل المتصفح ولا يصلح للاستخدام الجاد متعدد الأجهزة.
