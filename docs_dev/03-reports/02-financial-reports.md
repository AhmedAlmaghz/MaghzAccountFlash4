## تحليل الأرباح

**المسار**: `/reports/profit-analysis` — أقوى تقرير ربحية في النظام.

### الفلاتر
- **من/إلى تاريخ** — الافتراضي يحترم **بداية السنة المالية للشركة**
- **مفتاح مقارنة بالفترة السابقة** — يضيف لكل KPI سطر «الفترة السابقة»

### بطاقات KPI (4)
| البطاقة | المصدر |
|---|---|
| **الإيرادات** | فواتير المبيعات المرحّلة (يفصل بالعملات عند التعدد) |
| **تكلفة المبيعات (COGS)** | تكلفة الأصناف المباعة (من المشتريات/الإنتاج) |
| **المصروفات التشغيلية** | قيود المصروفات (إيجار، رواتب، كهرباء...) |
| **صافي الربح** | إيرادات − COGS − مصروفات |

### المخططات والجداول
| العنصر | ماذا يكشف |
|---|---|
| **مخطط المقارنة** | أعمدة مزدوجة: الفترة الحالية مقابل السابقة للمقاييس الأربعة |
| **توزيع المصروفات** | دائري + جدول: كل بند مصروف بمبلغه ونسبته % |
| **أفضل المنتجات ربحية** | لكل منتج: الإيراد / التكلفة / **الربح** / **الهامش %** (ملون: ≥30% أخضر، ≥15% كهرماني، أقل أحمر) |
| **تفصيل بالعملات** | الإيرادات حسب العملة + COGS حسب العملة (إن وُجدت عملات متعددة) |

### تفسير سريع
```
الهامش الإجمالي = (الإيراد − COGS) ÷ الإيراد
```
هامش منخفض مع إيراد عالي = تبيع كثيراً بربح رقيق — راجع التسعير أو كلفة الشراء.

## التقارير المحاسبية (داخل وحدة الحسابات)

هذه التقارير محسوبة من شجرة الحسابات + القيود:

### ميزان المراجعة
**المسار**: `/accounting/trial`
- كل الحسابات بأرصدة مدين/دائن لفترة
- **اختبار التوازن الأعظم**: مجموع المدين = مجموع الدائن (إن اختلفا ثمة خطأ بيانات — نادر جداً)

### الميزانية العمومية
**المسار**: `/accounting/balance`
- الأصول = الالتزامات + حقوق الملكية في تاريخ مرجعي
- شريط توازن أخضر عند التحقق

### قائمة الأرباح والخسائر
**المسار**: `/accounting/profit`
- البنية القياسية: إيرادات − COGS = ربح إجمالي − مصروفات = صافي
- الفترة الافتراضية من السنة المالية

### التدفق النقدي
**المسار**: `/accounting/cashflow`
- السيولة الحقيقية: التحصيلات والمدفوعات النقدية + مستحقات الموردين
- يجيب: «هل النقد في الجيب يكفي؟» (مختلف عن الربحية!)

### دفتر الأستاذ
**المسار**: `/accounting/ledger`
- كشف تفصيلي لحساب واحد بسطر افتتاحي ورصيد تراكمي — انظر [دليل الحسابات](../02-user-guide/01-accounting.md)

## مقارنة سريعة: أي تقرير مالي لأي غرض؟

| الغرض | التقرير |
|---|---|
| فحص سلامة القيود | ميزان المراجعة |
| صورة ثروة الشركة لغرض/مصرف | الميزانية العمومية |
| هل النشاط مربح؟ | الأرباح والخسائر أو تحليل الأرباح |
| هل النقد يكفي؟ | التدفق النقدي |
| تحقيق ربحية منتج بعينه | تحليل الأرباح ← جدول المنتجات |
| تدقيق حساب بعينه | دفتر الأستاذ |
