# مركز التقارير

> المسار: `/reports` — الصلاحيات: `reports.view` للعرض، `reports.export` للتصدير، `reports.custom` للمنشئ

## خريطة التقارير

| التقرير | المسار | النوع |
|---|---|---|
| **مركز التقارير** (البوابة) | `/reports` | فهرس بطاقات |
| تحليل المبيعات | `/reports/sales-analysis` | مبيعات |
| تحليل المخزون | `/reports/inventory-analysis` | مخازن |
| تنبيه النواقص | `/reports/low-stock-alert` | مخازن |
| حركة المخزون | `/reports/stock-movement` | مخازن |
| تقييم المخزون | `/reports/stock-valuation` | مخازن |
| كشف حساب عميل + أعمار | `/reports/customer-statement` | ذمم |
| كشف حساب مورد + أعمار | `/reports/supplier-statement` | ذمم |
| تحليل الأرباح | `/reports/profit-analysis` | مالية |
| تحويل العملاء المحتملين | `/reports/lead-conversion` | CRM |

> 🔒 **الصلاحيات تحرس كل تقرير**: بلا `reports.view` ترى رسالة واضحة بدل شاشة بيضاء. أزرار التصدير تُقفل بلا `reports.export`.

---

## المركز (البوابة)

`/reports` — 7 بطاقات مجمعة حسب المجال:
- **المبيعات**: تحليل المبيعات، كشف حساب عميل
- **المخازن**: تحليل المخزون، تقييم، حركة، نواقص
- **الموردون**: كشف حساب مورد
- **الأرباح**: تحليل الأرباح
- **CRM**: تحويل، خط الفرص
- **مخصص**: منشئ التقارير

---

## قواعد ذهبية تنطبق على كل التقارير

1. **الرصيد الافتتاحي مدمج دائماً** — كشوف الحسابات وأعمار الديون تبدأ بسطر الافتتاحي؛ الافتتاحي غير المؤرخ يقع في شريحة +90
2. **الفلاتر التاريخية لا تفقد الرصيد** — ما قبل الفترة يُجمع في سطر «رصيد افتتاحي»
3. **الفواتير الملغاة مستثناة** من كل الحسابات
4. **تعدد العملات** — التقارير تفصل حسب العملة عند وجود عملات متعددة في الفترة (جدول العملة/المبلغ/المعادل)
5. **كل الأرقام من قيود اليومية** — لا أرقام مخزنة قديمة

## عناصر مشتركة في شاشات التقارير

| العنصر | الوصف |
|---|---|
| **فلاتر التاريخ** | من/إلى + أزرار جاهزة (آخر 30 / 90 / السنة / الكل) |
| **بطاقات KPI** | ملخصات ملوّنة أعلى كل تقرير |
| **مخططات** | Recharts تفاعلية (أعمدة/دائري/خطي/قمع) |
| **زر مسح الفلاتر** | يعيد كل شيء للوضع الافتراضي |
| **تصدير Excel/PDF** | انظر [دليل التصدير](08-export-print.md) |

---

## دليل سريع: أي تقرير لأي سؤال؟

| السؤال | التقرير |
|---|---|
| كم بعت هذا الشهر ولمن؟ | تحليل المبيعات |
| ما هي أصنافي الراكدة؟ | تحليل المخزون ← تبويب «الراكد» |
| ما قيمة مخزوني الآن؟ | تقييم المخزون |
| ماذا ينقصني فوراً؟ | تنبيه النواقص (+ زر أمر شراء) |
| كم يستحق عليّ كل عميل ومتى؟ | كشف حساب عميل (الأعمار) |
| هل أربح فعلاً؟ | تحليل الأرباح |
| من أين يأتي عملائي الجدد؟ | تحويل المحتملين |
| أين تقف صفقاتي؟ | خط الفرص |
| سؤال لا يغطيه تقرير جاهز؟ | **منشئ التقارير المخصص** |
