## مواصفات التصدير

### Excel (.xlsx)
- **أسماء ملفات ذكية** تتبع التقرير والعرض النشط (`sales-analysis_2026-09.xlsx`)
- تُحترم الأعمدة الظاهرة (تبويب «الراكد» يصدّر بيانات الراكد فقط)
- المكتبة (xlsx) **تحمّل كسولاً** — لا تثقل التطبيق إلا لحظة الضغط

### PDF
- **RTL عربي كامل** بخط Cairo (السليم للعربية)
- رأس: **عنوان التقرير + اسم الشركة**
- كل التقارير المذكورة أعلاه بترقيم صفحات
- المكتبة (jsPDF) تحمّل كسولاً أيضاً

### الطباعة المباشرة
من **صفحات الوحدات** (ليست مركز التقارير):

| المستند | من أين | المواصفات |
|---|---|---|
| **فاتورة مبيعات** | صفحة الفواتير ← تفاصيل ← طباعة | ⭐ تصميم عالمي: رأس متدرج، جدول عناوين ملوّن، ملخص بخصم وضريبة (بشارة النسبة) وإجمالي بارز، **مبلغ بالحروف** |
| عروض الأسعار | صفحة العروض | نفس قالب الفاتورة |
| المردودات | صفحات المردودات | نفس القالب |
| السندات | صفحات السندات | قالب سند رسمي |
| حضور شهر | صفحة الحضور | نموذج شهري RTL |
| كشوف الإجازات | صفحة الإجازات | نموذج رسمي |

### تفاصيل سطر الفاتورة المطبوعة
تحت اسم كل منتج تظهر سلسلة تعريفية:
```
الكود • الباركود • SKU • الوحدة
```
— لمسح سريع عند الاستلام وتفادي أخطاء التجهيز.

## محادثات الوكيل الذكي

من رأس لوحة الدردشة — قائمة تصدير المحادثة:
| الصيغة | الاستخدام |
|---|---|
| **JSON** | أرشفة تقنية كاملة (رسائل + أدوات + معاملاتها) |
| **Markdown** | قراءة ومشاركة بشرية (الجداول تُحفظ جداولاً) |

---

## نصائح عملية

| الموقف | الحل |
|---|---|
| PDF يظهر علامات استفهام بدل العربية | حدّث التطبيق (النسخ الحديثة تدمج Cairo) |
| تريد تحليل Excel متقدم (Pivot) | صدّر Excel الخام واعمل الجدول المحوري في Excel |
| تريد فاتورة بنسختين (أصل + نسخة) | اطبع مرتين أو من إعدادات الطابعة |
| فحص التصدير بلا صلاحية | الأزرار مخفية أصلاً — إن ظهرت فعلاً فالنظام يرفض الخدمة |
