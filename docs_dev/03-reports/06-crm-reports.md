## تقرير تحويل العملاء المحتملين (Lead Conversion)

**المسار**: `/reports/lead-conversion`

### الفلاتر
من/إلى تاريخ + أزرار جاهزة (آخر 30 / 90 / السنة / الكل)

### بطاقات KPI
| المجموعة | البطاقات |
|---|---|
| **قمع التحويل** | إجمالي المحتملين → جديد → متواصل → مؤهل → محول → مفقود |
| **المؤشرات** | **نسبة التحويل الإجمالية** | القيمة التقديرية | **القيمة المحولة** | نسبة التأهيل |

### المخططات الثلاثة
| المخطط | النوع | ماذا يكشف |
|---|---|---|
| **قمع التحويل** | أعمدة قمع عمودية | أين يتسرب القمع (انحدار حاد = مشكلة مرحلة) |
| **توزيع المصادر** | دائري | أي قناة تسويق تجلب فعلاً (إعلان/توصية/معرض...) |
| **الاتجاه الشهري** | أعمدة | إجمالي (رمادي) مقابل محول (أخضر) — نمو فريقك |

### جدول المصادر
لكل مصدر: عدد المحتملين + المحول + **نسبة تحويله** (شريط تقدم ملوّن) — أجب ببيانات على «أين أصرف ميزانية التسويق؟»

## خط الفرص (Opportunity Pipeline)

**المسار**: `/reports/opportunity-pipeline`

### بطاقات KPI (4)
| البطاقة | المعنى |
|---|---|
| إجمالي الفرص | كل الصفقات في الفترة |
| **قيمة الأنباق** | مجموع قيم الفرص المفتوحة |
| **الأنباق المرجحة** ⭐ | Σ(قيمة × احتمالية) — التوقع الواقعي (أدق من الجمع الأعمى) |
| قيمة المكسوب | ما أُغلق بنجاح (won) |

### المخطط والجدولان
- **أعمدة ثنائية المحور** لكل مرحلة مفتوحة: عدد الفرص + قيمتها معاً
- **تفصيل المراحل**: المرحلة، العدد، القيمة، المرجحة، متوسط الاحتمالية %
- **أداء المندوبين**: لكل مسؤول — عدد فرصه، قيمتها، المرجحة

### تفسير عملي
- قيمة عالقة في `proposal` باحتمالية منخفضة = عروض لا تُغلق — راجع التسعير
- **الأنباق المرجحة** هي رقمك الأصدق للتوقعات: فرصة 100 ألف باحتمال 90% تساوي 90 ألفاً متوقعة، وفرصة 100 ألف باحتمال 10% تساوي 10 آلاف فقط

## أدوات الوكيل المرتبطة

| الأداة | ماذا تعطيك (بالصوت أو النص) |
|---|---|
| `crm.lead_conversion` | نفس تقرير التحويل كنص منسق |
| `crm.opportunity_pipeline` | نفس تقرير الخط |
| `crm.sales_funnel` | القمع مجمّعاً |
| **`crm.follow_ups`** ⭐ | **قائمة عمل اليوم**: مهام متأخرة + فرص تجاوزت تاريخ الإغلاق + عملاء بلا تواصل ≥N يوم — مرتبة بالأولوية |
| **`crm.rep_performance`** ⭐ | لكل مندوب: المحول/Mكسوب/مفقود + **نسبة الفوز** + قيمة المكسوب + أنشطته |

> 💡 جرّب: «من أدنى مندوب أداءً هذا الشهر؟» أو «ما متابعاتي العاجلة؟»

## حالات استخدام

| الموقف | التقرير/الأداة |
|---|---|
| اجتماع فريق المبيعات الصباحي | `crm.follow_ups` — أجندة اليوم جاهزة |
| تقييم قنوات التسويق الفصلية | تقرير التحويل ← جدول المصادر |
| توقعات إيراد الشهر القادم | خط الفرص ← **الأنباق المرجحة** |
| مكافأة أفضل مندوب | `crm.rep_performance` |
| لماذا لا نغلق صفقات؟ | خط الفرص ← ركّز أين تتجمع القيمة |
