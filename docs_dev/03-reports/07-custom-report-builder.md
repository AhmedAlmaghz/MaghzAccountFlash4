# منشئ التقارير المخصص

> المسار: `/reports/custom-builder` — الصلاحيات: `reports.custom` (+ `reports.export` للتصدير)

---

## ما هو؟

معالج 4 خطوات لصناعة تقرير من نوعك — **بلا كتابة SQL**: اختر جدولاً، أعمدة، فلاتر، ثم عاين وصدّر.

---

## الخطوات الأربع

شريط تنقل علوي مع أزرار «السابق/التالي» (يتعطل حتى اكتمال الخطوة الحالية).

### الخطوة 1 — اختيار الجدول
**6 جداول مسموحة** (قائمة بيضاء أمنية — لا شيء غيرها):

| الجدول | مناسب لـ |
|---|---|
| فواتير المبيعات | تحليلات فواتيرك |
| فواتير المشتريات | تحليلات الشراء |
| المنتجات | جرد وقيم |
| العملاء | قوائم وأرصدة |
| الموردون | مستحقات وتصنيفات |
| الحسابات | أرصدة الشجرة |

كل بطاقة تعرض عدد الأعمدة المتاحة.

### الخطوة 2 — اختيار الأعمدة
- Checkboxes لكل عمود متاح
- **لكل عمود تكتيلة (aggregation) اختيارية**: `Sum` / `Avg` / `Count` / `بدون` (تفصيلي)
- مثال: جدول فواتير + عمود «الإجمالي» بـ Sum + تجميع حسب «العميل» = إجمالي بيع كل عميل

### الخطوة 3 — الفلاتر
أضف أي عدد من القواعد:
```
[عمود] + [معامل] + [قيمة]
```
| المعامل | الاستخدام |
|---|---|
| `=` | مطابقة تامة |
| **يحتوي** | بحث نصي جزئي |
| `>`, `<`, `>=`, `<=` | نطاقات رقمية وتواريخ |

أمثلة: «الحالة = مرحّلة» + «الإجمالي >= 100000» — زر حذف لكل قاعدة.

### الخطوة 4 — المعاينة والتصدير
- يجلب **حتى 500 صفاً** ثم يطبق فلاترك
- **حماية injection**: اسم الجدول يُعاد التحقق منه ضد القائمة البيضاء قبل أي SQL
- جدول النتائج: الأعمدة الرقمية تُنسق بالعملة تلقائياً
- **حقل اسم التقرير** — يظهر في ملف التصدير
- زرا **تصدير Excel** و**PDF**

---

## وصفة سريعة: «أفضل 10 عملاء هذا العام»

1. الجدول: **فواتير المبيعات**
2. الأعمدة: العميل + الإجمالي (Sum)
3. الفلاتر: التاريخ `>=` بداية السنة + الحالة `=` مرحّلة
4. معاينة ← رتب بالإجمالي ← صدّر Excel

> ملاحظة: الترتيب النهائي يتم في ملف Excel بعد التصدير (المعاينة تعرض 500 صف الأولى).

---

## القيود الأمنية (عن قصد)

- **قائمة بيضاء للجداول فقط** — لا استعلام حر على أي جدول آخر
- **لا أوامر SQL خام** — كل شيء عبر واجهة المعالج
- يخضع لصلاحيات RBAC مثل كل النظام (`reports.custom`)
