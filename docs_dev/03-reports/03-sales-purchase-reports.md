# تقارير المبيعات والمشتريات

> تحليل الإيراد والمصروف من طرفي العملية التجارية

---

## تحليل المبيعات

**المسار**: `/reports/sales-analysis`

### الفلاتر
| الفلتر | الوصف |
|---|---|
| **من/إلى تاريخ** | نطاق الفترة + أزرار جاهزة (30/90/السنة/الكل) |
| **اسم العميل** | تصفية نصية لعميل محدد |
| **اسم المنتج** | تصفية لمنتج محدد |
| **⭐ الجدول المحوري** | بدون / حسب العميل / حسب المنتج / حسب الشهر — يغير شكل التجميع بالكامل |

### بطاقات KPI (3)
إجمالي الإيرادات | عدد الفواتير | **متوسط قيمة الفاتورة**

### المخططات والجداول
- **مخطط أعمدة الإيراد** — يعيد تجميعه حسب المحور المختار (شهر/عميل/منتج)
- **مخطط دائري** — أعلى 6 جهات بيع
- **الجدول المحوري** — لكل بُعد: الإيراد + عدد الفواتير + المتوسط
- **الجدول التفصيلي** (بدون محور): التاريخ، العميل، المنتج، **شارة العملة**، الإيراد — حتى 200 سطر
- **تفصيل بالعملات** — جدول العملة/المبلغ/المعادل بالأساسية (عند التعدد)

### حالة استخدام: «من هم أفضل 5 عملاء؟»
اختر المحور «حسب العميل» ← رتب الجدول بالإيراد تنازلياً ← صدّر Excel.

## تقارير المشتريات

تقارير المشتريات تعمل من داخل الوحدة والوكيل الذكي (أدوات `purchases.*`):

| التقرير | أداة الوكيل | ماذا يعرض |
|---|---|---|
| تحليل المشتريات | `purchases.purchase_analysis` | إجماليات وفترة |
| سجل الفواتير | `purchases.purchase_register` | كل فواتير الشراء بتفاصيلها |
| **كشف حساب مورد** | `purchases.supplier_statement` | كشف تفصيلي بالمستحقات |
| **أعمار ذمم الموردين** | `purchases.ap_aging` | شرائح ما علينا |
| أعلى الموردين | `purchases.top_suppliers` | ترتيب حسب الحجم |
| تفصيلي | `purchases.invoices_detailed` | فواتير بأسطرها |
| نقدي مقابل آجل | `purchases.cash_vs_credit` | توزيع طرق الشراء |

### أعمار ذمم الموردين (AP)
نفس منهجية AR معكوسة: ما **نحن مدينون به** للموردين موزعاً على شرائح التأخر:
```
0-30 (أخضر) | 31-60 (كهرماني) | 61-90 (برتقالي) | +90 (أحمر)
```
**تشمل الأرصدة الافتتاحية** — ديون ما قبل استخدام النظام تظهر في مكانها الصحيح (+90 إن كانت غير مؤرخة).

### أين أجد شاشاتها؟
- **كشف مورد فردي**: من صفحة الموردين ← تفاصيل المورد
- **أعمار الموردين الكاملة**: أداة الوكيل + التقرير المرجعي داخل تقرير كشف حساب المورد
- **إجمالي AP**: بطاقة في لوحة التحكم + التدفق النقدي

## نقدي مقابل آجل (كلا الطرفين)

أداتا `sales.cash_vs_credit` و `purchases.cash_vs_credit` تجيبان سؤال السيولة المهم: **ما نسبة مبيعاتك/مشترياتك الفورية مقابل الآجلة؟** — نسبة آجلة مرتفعة = ضغط تحصيل قادم.

## تقارير ضريبة VAT

`sales.vat_summary` — إجمالي الضريبة المحصلة (مبيعات) مقابل المدفوعة (مشتريات) لفترة — أساس الإقرار الضريبي.
