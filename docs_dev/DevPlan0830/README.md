## ترتيب التنفيذ الموصى به

المراحل مرتبة **حسب الأولوية والمخاطرة وتبعيات العمل**. يجب تنفيذها بالتسلسل التالي:

```
 ١ ← ٢ ← ٣ ← ٤ ← ٥ ← ٦ ← ٧ ← ٨ ← ٩ ← ١٠ ← ١١ ← ١٢
(الأمان)                          (التقارير)
```

**قاعدة التبعية:** كل مرحلة تُبنى فوق سابقتها. لا ينصح بالقفز إلى مرحلة متأخرة قبل إتمام المراحل الحرجة (١–٥) لأنها تؤثر مباشرة على سلامة البيانات وأمانها.

## معايير التحقق العامة

كل مرحلة تخضع لنفس **بوابة الجودة** قبل اعتبارها مكتملة:

```bash
npm run lint            # 0 errors, 0 warnings
npx tsc -b              # 0 errors
npm test                # جميع اختبارات الوحدة ناجحة
npm run db:check        # لا drift
npm run build           # بناء ناجح
npx playwright test     # e2e حرجة ناجحة
```
