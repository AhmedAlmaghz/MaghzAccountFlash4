## بيانات الشركة

**المسار**: `/settings/company`

| الحقل | الأثر |
|---|---|
| **الاسم العربي/الإنجليزي** | رؤوس الفواتير والتقارير |
| **العملة الافتراضية** | عرض كل التقارير والتقسيم بالعملة |
| الرقم الضريبي | الفواتير الضريبية |
| **التقويم** (ميلادي/هجري) | عرض كل التواريخ (أم القرى للهجري) |
| **صيغة التاريخ** | `yyyy-MM-dd` / `dd/MM/yyyy` / إلخ — في كل الشاشات |
| **المنازل العشرية** (0-4) | تنسيق كل المبالغ |
| **بداية السنة المالية** | نقطة انطلاق تقارير الربحية |

## العملات

**المسار**: `/settings/currencies`

- القائمة الافتراضية: YER (أساسية) + SAR/USD/AED/KWD/QAR
- **القاعدة**: سعر الصرف = «كم وحدة من الأساسية = 1 من هذه العملة» — مثال: USD بسعر 1500 يعني 1 دولار = 1500 ريال
- العملة الأساسية (`isDefault`) سعرها دائماً 1
- عطّل عملة بدل حذفها إن استُخدمت بمستندات

> كل مستند يحمل: عملته + سعره + **المعادل بالأساسية** — والتقارير تفصل الإجماليات حسب العملة عند التعدد.

## الضريبة (VAT) وإعدادات العرض

**المسار**: `/settings/vat`

| الإعداد | الأثر |
|---|---|
| **نسبة الضريبة** | تحسب VAT لكل فاتورة (0 = بلا ضريبة) |
| الرقم الضريبي للشركة | يظهر بالفواتير |
| شامل/غير شامل | طريقة التسعير |
| **إظهار الخصم** | عمودي خصم السطر + حقل خصم الفاتورة في كل شاشات الفواتير |
| **إظهار الضريبة** | عمود ضريبة السطر + سطر ضريبة الفاتورة |

> ⭐ ضريبة الفاتورة تُحسب **على مستوى الفاتورة ككل** (صافي بعد الخصم × النسبة) — وليس سطراً بسطر.

## النقدية والخزائن ⭐

**المسار**: `/settings/cash-boxes`

**المفهوم الموحد**: بعد إلغاء «البنوك» ككيان مستقل، كل موقع دفع = **خزينة مربوطة بحساب دفتري**:

| الحقل | الوصف |
|---|---|
| الاسم + الكود | «الصندوق الرئيسي»، «محفظة موبايل موني»... |
| **الحساب الدفتري** ⭐ | **هدف القيود النقدية** — سند نقدي يقيّد على حساب هذه الخزنة تحديداً |
| الفرع + المسؤول | اختياري |
| الرصيد الحالي | متابعة |

- طرق الدفع في السندات (نقدي/حوالة/شيك) كلها تصل لهذه الخزينة — «حوالة» يعني تحويلاً أو محفظة
- **ممارسة أفضل**: خزنة لكل نقطة استلام (صندوق، محفظة، بنك كخزينة) — رصيد كل خزنة يعكس حقيقتها الدفترية

## مراكز التكلفة

**المسار**: `/settings/cost-centers` — شجرة مراكز (فرع/قسم/مشروع/خط منتج) مع موازنات — للتحليل بالتكلفة.

## وحدات القياس

**المسار**: `/settings/units` — وحدات بمعاملات تحويل (كرتونة = 12 قطعة) مع وحدة أساس لكل عائلة.

---

## أنواع المنتجات

**المسار**: `/settings/product-types` — **أقوى إعدادات المخازن**:

| العلم | يفعل ماذا |
|---|---|
| **يظهر في المبيعات/المشتريات/المخازن/التصنيع** | أين يظهر نوع المنتج في القوائم الذكية (ProductSelect يتولى الفلترة) |
| **تتبع مخزون** | هل منتجات هذا النوع تدخل عدّ المخزون |
| **يدعم BOM** | منتج تام قابل للإنتاج من خامات |
| **الاستخدام** (تام/خام/أخرى) | سلوك التصنيع: التام يُستلم عند الإكمال والخام يُصرف عند البدء |
| **حسابات محاسبية للنوع** | إيرادات/تكلفة/مخزون مخصصة تتقدم على الافتراضيات العامة |

## تصنيفات المنتجات

**المسار**: `/settings/product-categories` — شجرة تصنيفات هرمية؛ المنتج قد ينتمي لأكثر من تصنيف.

## الحسابات الافتراضية

**المسار**: `/settings/default-accounts` — **أهداف الترحيل لكل عملية آلية**:

| المفتاح | الوظيفة |
|---|---|
| `default_cash` | حساب السندات النقدية الاحتياطي |
| `default_inventory` / `default_wip` / `default_finished_goods` | مخزون خام / إنتاج تحت التشغيل / تام الصنع |
| `default_production_labor/energy/packaging/other/loss` | تكاليف الإنتاج وتصنيف عجوزه |
| `default_opening_balance` | مقابل الأرصدة الافتتاحية (31201) |
| `default_rent` / `default_shipping` / `default_misc_expense` | مصروفات السندات العامة |
| `default_salaries_payable` / `default_payroll_deductions` | مسير الرواتب |
| `default_eos_payable` / `default_eos_expense` | نهاية الخدمة |

- زر **«تطبيق قالب»**: `trading` / `manufacturing` / `services` — يملأ الأزواج القياسية
- حساب نوع المنتج (أعلاه) **يتقدم** على الافتراضي العام

## التسلسلات الرقمية

**المسار**: `/settings/document-sequences`

كل نوع مستند له تسلسل مستقل (atomic — آمن حتى مع مستخدمين متزامنين):

| النوع | البادئة | مثال |
|---|---|---|
| فاتورة مبيعات | `INV-` | INV-000001 |
| مردود مبيعات | `SRT-` | SRT-0001 |
| عرض سعر | `QOT-` | QOT-0001 |
| أمر شراء | `PO-` | PO-000001 |
| فاتورة مشتريات | `PINV-` | PINV-0001 |
| مردود مشتريات | `PRT-` | PRT-0001 |
| قيد يومية | `JV-` | JV-0000001 |
| سند قبض | `RV-` | RV-000001 |
| سند صرف | `PV-` | PV-000001 |
| أمر تشغيل | `WO-` | WO-0001 |
| قائمة مواد | `BOM-` | BOM-0001 |
| مسير رواتب | `PAY-` | PAY-000001 |
| موظف | `EMP-` | EMP-0001 |
| منتج | `PRD-` | PRD-0000001 |
| تسوية مخزون | `ADJ-` | ADJ-000001 |
| تحويل مخزون | `TRF-` | TRF-000001 |
| عميل / مورد | `CUS-` / `SUP-` | CUS-00001 / SUP-0001 |

**قابل للتعديل**: البادئة، الرقم التالي، خطوة الزيادة، **طول الحشو** (padding)، وإعادة الضبط السنوي (`yearReset`).

## قاعدة البيانات والنسخ الاحتياطي

- **`/settings/database`**: عرض وضع التخزين + بيانات اتصال PostgreSQL (تغيير الوضع)
- **`/settings/backup`**: إنشاء نسخة (SQL dump للجداول) واستعادة — **خذ نسخة قبل أي عملية خطرة** (إعادة تهيئة/مسح)

## إعادة التهيئة

**`/settings/reset`** (admin فقط): يعيد تشغيل معالج التهيئة الأول — انظر [دليل المعالج](../01-getting-started/03-onboarding.md).
