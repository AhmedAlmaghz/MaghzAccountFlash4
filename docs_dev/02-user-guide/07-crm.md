## العملاء المحتملون (Leads)

**المسار**: `/crm/leads`

### قائمة المحتملين
- **فلاتر**: الحالة + البحث (فوضي عربي)
- الأعمدة: الاسم، الشركة/المصدر، الهاتف، **التقييم** (🔥 ساخن / دافئ / بارد بشارات)، القيمة التقديرية، **آخر تواصل**، **المسؤول**، الحالة

### إنشاء Lead
| الحقل | ملاحظات |
|---|---|
| **الاسم** (إلزامي) | حوار التكرار (بالاسم بعد التطبيع أو الهاتف) |
| الهاتف/البريد/الشركة | |
| **المصدر** | إعلان / توصية / معرض / موقع... (يغذي تقرير التحويل) |
| **التقييم** | ساخن/دافئ/بارد |
| **القيمة التقديرية** | تنتقل كقيمة فرصة أولى عند التحويل |
| **المسؤول** | مندوب من مستخدمي النظام |

### دورة حياة المحتمل
```
new ──▶ contacted ──▶ qualified ──▶ converted (تحويل لعميل)
                └──────────▶ lost
```
- **آخر تواصل `last_contacted_at`** يُختم تلقائياً عند تسجيل أي نشاط مرتبط — أداة «المتابعات» تقرأها
- الحذف **مرفوض** إذا له فرص/مهام/أنشطة مرتبطة (رسالة تفصيلية) — القطع يفصل الرابط فقط

### تحويل لعميل ⭐
مودال التحويل: يعرض بيانات الـ Lead جاهزة للتحرير + **خيار إنشاء فرصة أولى**:
- في **عملية ذرّية واحدة**: يولّد كود العميل من التسلسل الموحد (`CUS-NNNNN`)، ينشئ العميل، يحدث حالة الـ Lead لـ converted، و(اختيارياً) ينشئ فرصة «فرصة [الاسم]» بقيمته التقديرية
- حارس idempotent: المحوّل مسبقاً لا يتحول ثانية

## الفرص (Opportunities)

**المسار**: `/crm/opportunities`

### عرضان
- **Kanban**: أعمدة المراحل الخمس المفتوحة + won/lost — بطاقات قابلة للسحب (السحب غير القانوني = toast يشرح)
- **قائمة**: جدول بفلاتر المرحلة والبحث

### آلة الحالات الصارمة (أهم قاعدة في الوحدة)
```
new ──▶ qualified ──▶ proposal ──▶ negotiation ──▶ won  (نهائية)
                                     └───────────▶ lost (نهائية)
```
- **للأمام فقط** — الرجوع مرفوض (بأخطاء عربية واضحة من الخادم وليس الـ UI فقط)
- **won/lost نهائية**: يُختم `close_date` بالتاريخ الفعلي + probability (won=100 / lost=0) في نفس اللحظة
- **won ≠ فاتورة**: كسبان الفرصة لا يولّد فاتورة — الوكيل والنظام يرشدانك لسؤال المستخدم أولاً

### إنشاء فرصة
الاسم، **القيمة**، المرحلة، **الاحتمالية %** (0-100)، **تاريخ الإغلاق المتوقع**، الربط (Lead / عميل قائم)، المسؤول، ملاحظات

### بطاقة الفرصة
تعرض القيمة + **القيمة المرجحة** (قيمة × احتمالية) + العد التنازلي لتاريخ الإغلاق المتوقع.

## المهام

**المسار**: `/crm/tasks`

### قائمة المهام
- **فلاتر**: الحالة (معلقة/منجزة/ملغاة) + الأولوية + البحث
- الأعمدة: العنوان، **تاريخ الاستحقاق** (مع شارة **متأخرة** حمراء للمهام الماضية غير المنجزة)، الأولوية (بشارات)، **الربط** (فرصة/محتمل/عميل)، المسؤول، الحالة

### إنشاء/تعديل مهمة
| الحقل | ملاحظات |
|---|---|
| **العنوان** (إلزامي) | |
| الاستحقاق | ⭐ مقارنة اليوم تُحسب بالتاريخ الكامل لا الوقت |
| الأولوية | منخفضة/متوسطة/عالية |
| **الربط الذكي** | ثلاثة قوائم منفصلة: فرصة أو Lead أو عميل (إصلاح الحقل المكسور القديم) |
| المسؤول | UserSelect |

- زر **إتمام** سريع من الجدول يقلب الحالة لـ completed
- متأخرة تُحسب فقط للمهام غير المنجزة/الملغاة

## الأنشطة

**المسار**: `/crm/activities`

سجل تواصل كامل: مكالمات، اجتماعات، رسائل، زيارات:

| الحقل | الوصف |
|---|---|
| **النوع** | call / meeting / email / visit |
| **الموضوع** (إلزامي) + الوصف | |
| **تاريخ النشاط** + المدة (دقائق) | |
| **الربط** | Lead / فرصة / عميل |
| **المسؤول** | |

> ⭐ تسجيل نشاط مرتبط بـ Lead **يختم `last_contacted_at` ذرّياً** في نفس العملية — أدوات المتابعة والتقارير تعتمد عليها.

- **فلاتر**: النوع + البحث
- **تقرير أداء المندوبين** بالأنشطة متاح للوكيل وتقرير خط الفرص

---

## أدوات المتابعة الذكية (عبر الوكيل)

أداتان جاهزتان في الوكيل الذكي تغنيانك عن التتبع اليدوي:

| الأداة | ماذا تعيد |
|---|---|
| **`crm.follow_ups`** | قائمة موحدة مرتبة بالأولوية: مهام متأخرة + مستحقة اليوم + **فرص تجاوزت تاريخ الإغلاق المتوقع** + **عملاء بلا تواصل ≥ N يوم** |
| **`crm.rep_performance`** | لكل مندوب: محتملون مسندون/محولون + won/lost + نسبة الفوز + قيمة المكسوب + عدد أنشطته |

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| جاء استفسار جديد | Leads ← جديد ← عيّن مسؤولاً وتقييماً |
| تواصلت هاتفياً | الأنشطة ← نوع call ← اربط بالـ Lead (يختم آخر تواصل) |
| المحتمل جاد | Leads ← «تحويل» + فعل «إنشاء فرصة» |
| تقدمت المفاوضات | اسحب البطاقة لـ negotiation (لا رجوع للخلف!) |
| كسبنا الصفقة | اسحب لـ won ← اسأل عن إنشاء الفاتورة ← أنشئها من المبيعات |
| ماذا أفعل اليوم؟ | اسأل الوكيل: «ما هي متابعاتي اليوم؟» |
