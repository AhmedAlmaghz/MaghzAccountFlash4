## المنتجات

**المسار**: `/inventory/products`

### قائمة المنتجات
- **فلاتر**: بحث نصي (الاسم/الكود/الباركود/SKU) + النوع + التصنيف + حالة (نشط/موقوف)
- **فلاتر من جانب الخادم**: الترقيم حقيقي (25/50/100 لكل صفحة)
- الأعمدة: الكود، الاسم، النوع، سعر التكلفة، سعر البيع، الوحدة، المخزون، الحالة
- كل صف قابل للنقر لبطاقة تفاصيل المنتج

### إنشاء منتج جديد
| الحقل | ملاحظات |
|---|---|
| **الكود** | `PRD-0000001` يولد تلقائياً (قابل للتحرير) |
| **الاسم العربي** (إلزامي) | يظهر في واجهة AR |
| الاسم الإنجليزي | يظهر في واجهة EN |
| **الباركود / SKU** | يظهران في شارات اختيار المنتج بالفواتير |
| **النوع** | من أنواع المنتجات المعرّفة (يحدد أين يظهر: مبيعات/مشتريات/تصنيع) |
| **التصنيف** | متعدد (many-to-many) — للتحليل بالتصنيفات |
| **سعر التكلفة / سعر البيع** | ⭐ مصدر التعبئة التلقائية في فواتير الشراء/البيع |
| **الوحدة** | وحدة القياس (كجم، قطعة، كرتونة...) — حقل نصي |
| **الحد الأدنى للمخزون** | يشغل تنبيه النواقص |
| **الرصيد الافتتاحي + المستودع** | يرحّل قيد افتتاحي للمخزون |

> 🔒 **حوار التكرار**: الاسم العربي+الإنجليزي+الكود يفحص ضد القائم — تطابق تام يمنع، تشابه ≥85% يستنزل تأكيدك.

### بطاقة تفاصيل المنتج
تعرض كل بيانات المنتج + رصيده في كل مستودع + آخر حركاته.

## أنواع المنتجات والتصنيفات

الأنواع تُدار من **الإعدادات** (`/settings/product-types`) وتتحكم في:
- **أين يظهر المنتج**: أعلام «يظهر في المبيعات / المشتريات / المخازن / التصنيع»
- **هل له BOM**: منتج تام (يُنتَج) أم مادة خام (يُستهلك)
- **حسابات محاسبية مخصصة** لنوع المنتج (إيرادات/تكلفة/مخزون) — تتقدم على الحسابات الافتراضية العامة

التصنيفات شجرة هرمية (`/settings/product-categories`) — للفلترة والتقارير.

## المستودعات

**المسار**: `/inventory/warehouses`

- إنشاء/تعديل مستودعات: الاسم، الكود، الفرع المرتبط، الحالة
- كل مستودع يظهر في: أرصدة المخزون (رصيد كل منتج فيه)، الحركات، التحويلات، أوامر التشغيل (مصدر الخامات ومستلم التام)
- حذف مستودع محروس إن كان له حركات

---

## أرصدة المخزون

**المسار**: `/inventory/stock`

مصفوفة **المنتج × المستودع**:
| العمود | الوصف |
|---|---|
| المنتج | الاسم + الكود + SKU |
| المستودع | موقع الرصيد |
| **الكمية** | الرصيد الفعلي الحالي |
| **الحد الأدنى للتنبيه** | لكل مستودع على حدة (يختلف عن حد المنتج العام) |
| الحالة | ✅ جيد / ⚠️ منخفض / ❌ نافد |

- فلترة بالمستودع والمنتج والحالة
- زر تصدير Excel

## حركات المخزون

**المسار**: `/inventory/transactions`

سجل زمني لكل ما دخل وخرج:

| النوع | المصدر |
|---|---|
| `in` وارد | فواتير المشتريات، مردودات البيع، إكمال أوامر التشغيل (استلام التام)، إرجاع فائض الخامات |
| `out` صادر | فواتير المبيعات، مردودات الشراء، بدء أوامر التشغيل (صرف الخامات) |
| `transfer` تحويل | التحويلات بين المستودعات |
| `adjustment` تسوية | تسويات الجرد المعتمدة |

**الأعمدة**: التاريخ (بصيغة الشركة)، المنتج، المستودع، النوع، الكمية، **المرجع** (رقم المستند البشري: INV-000001 أو WO-0002 — ليس UUID)، ملاحظات

**الفلاتر**: النوع + المنتج + نطاق ترقيم صفحات من الخادم

> 🔍 الحركات **سجل تدقيقي** — تُنشأ من العمليات تلقائياً ولا تُنشأ يدوياً هنا (لإنشاء حركة يدوية استخدم التسوية أو التحويل).

## تسويات الجرد

**المسار**: `/inventory/adjustments`

عند الجرد الفعلي واكتشاف فرق:

### إنشاء تسوية
| الحقل | الوصف |
|---|---|
| المنتج + المستودع | موقع الفرق |
| **الكمية النظامية** | تُجلب تلقائياً |
| **الكمية الفعلية** | أدخل ما وجدته فعلاً |
| **الفرق** | يحسب تلقائياً (+ أو −) |
| **تكلفة الوحدة** | لتقييم الأثر المالي |
| **السبب** | إلزامي — تالف/فاقد/خطأ قيد/جرد دوري... |

### دورة حياة التسوية
```
مسودة (draft) ──اعتماد──▶ معتمدة ──ترحيل──▶ مرحّلة (posted)
```
**الترحيل** يقوم بثلاثة أشياء دفعة واحدة:
1. حركة مخزون `adjustment` بالفرق
2. تحديث رصيد الخزين
3. قيد يومي (زيادة: مدين المخزون / نقص: مدين هالك أو مصروف الجرد)

---

## التحويلات بين المستودعات

من شاشة الحركات أو المستودعات — نقل كمية من مستودع لمستودع:
1. أنشئ التحويل: المنتج، الكمية، من مستودع، إلى مستودع، مرجع
2. الحالة: `pending` ← **إكمال** ينشئ حركتين متقابلتين (`out` من المصدر + `in` للهدف)
3. يمكن حذف التحويل المعلق فقط

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| أضفت صنفاً جديداً للمخزون | المنتجات ← جديد ← مع رصيد افتتاحي |
| وجدت نقصاً بالجرد | التسويات ← جديد ← فعلي أقل ← اعتماد ← ترحيل |
| انقل بضاعة بين فرعين | الحركات ← تحويل جديد ← إكمال |
| أعرف ماذا نفد | أرصدة المخزون ← فلتر «نافد» أو تقرير النواقص |
| اعرف قيمة مخزوني | تقرير تقييم المخزون (`/reports/stock-valuation`) |
