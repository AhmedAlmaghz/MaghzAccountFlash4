## الموظفون

**المسار**: `/hr/employees`

### قائمة الموظفين
- **بحث** بالاسم/الرقم الوظيفي + فلتر نشط + الترقيم من الخادم
- الأعمدة: **الرقم الوظيفي** (`EMP-NNNN`)، الاسم، القسم، الوظيفة، **الراتب الأساسي**، تاريخ التعيين، الحالة

### إنشاء/تعديل موظف
| الحقل | ملاحظات |
|---|---|
| **الاسم الكامل** (إلزامي) | حوار التكرار يفحص الاسم + الرقم الوظيفي |
| **الرقم الوظيفي** | توليد تلقائي قابل للتحرير |
| القسم + **المدير المباشر** | من قوائم الأقسام والمستخدمين |
| الوظيفة + الدرجة | |
| **تاريخ التعيين** | ⭐ أساس حساب نهاية الخدمة |
| **الراتب الأساسي** | أساس كل حسابات المسير |
| الهوية الوطنية/الهاتف/البريد/العنوان | |
| **صورة الموظف** | حتى 2MB |
| **الرصيد الافتتاحي + تاريخه** | سلف/مستحقات سابقة — تُرحَّل كقيد |

> 🔒 **حذف محروس**: موظف له مسيرات/إجازات/حضور/نهاية خدمة لا يُحذف — عطّله (فقدان تاريخي مقصود).

## الأقسام

**المسار**: `/hr/departments` — إدارة تشغيلية داخل HR (لا تحتاج صلاحية إعدادات).

- إنشاء/تعديل قسم + ربط **مدير** من مستخدمي النظام
- القائمة تعرض لكل قسم: **المدير + عدد الموظفين**
- حذف قسم به موظفون **مرفوض** برسالة تظهر العدد

## الحضور

**المسار**: `/hr/attendance`

### تسجيل اليوم
نموذج **جدولي موسّع** (Modal 4xl) بصف لكل موظف:
- **الحضور/الانصراف** (خُرم الوقت HH:mm) + الحالة (حاضر/غائب/متأخر/إجازة) + أوفر تايم يدوي + ملاحظات
- يوم الغياب/الإجازة: الحضور يبقى فارغاً (مسموح)
- **footer حي**: عدد الحاضرين/الغائبين/المتأخرين + إجمالي الساعات

### الاشتقاق الخدمي
عند الحفظ يشتق النظام **من سياسة الشركة** (انظر أدناه):
- **التأخير**: إذا الحضور > البداية الرسمية + سماحية التأخير
- **أوفر تايم**: إن لم يُدخل يدوياً، من الفارق (الانصراف − الحضور − ساعات العمل القياسية)
- **Upsert حقيقي**: نفس الموظف + نفس اليوم = تحديث لا تكرار

### تصفح السجلات
- **منتقي شهر/سنة** — تنقّل بين الشهور يعيد التحميل
- بطاقات إحصائية لكل شهر + تصدير Excel + **طباعة** (نموذج شهري RTL بخط Cairo)
- تاريخ السجل يعرض بصيغة الشركة

## الإجازات

**المسار**: `/hr/leaves`

### طلب إجازة
| الحقل | الوصف |
|---|---|
| الموظف + النوع | سنوية / مرضية / اضطرارية / **بدون راتب** |
| من − إلى | ⭐ **الأيام تُحسب خدمياً** (شاملة الطرفين) والمعكوس مرفوض |
| السبب | |

### آلة الحالة + الرصيد الصارم
```
pending ──▶ approved / rejected
   │            │
   └──cancelled─┘  (المعتمدة تُلغى فقط)
```
- **عند الاعتماد**: يفحص النظام **(المعتمد + المعلق − هذه الإجازة) ضد رصيد النوع** — تجاوز = **رفض برسالة عربية بالمتبقي**
- **بدون راتب غير محدود** — لا فحص رصيد
- الحذف: pending/rejected فقط

> 💡 عند اختيار الموظف في النموذج تظهر **بطاقة أرصدة** للأنواع الأربعة فوراً.

## مسير الرواتب

**المسار**: `/hr/payroll`

### إنشاء مسير — ثلاث خطوات محروسات

#### 1) المعاينة التلقائية
اختر **الشهر والسنة** ← زر «معاينة» يجلب الحساب الخدمي لكل موظف نشط:
- **الأساسي** من بطاقته
- **المكونات** من جدول مكونات الرواتب (بدلات/استقطاعات ثابتة أو نسبية) — مفعّلة لكل موظف؟ عبر نوعها
- **أوفر تايم**: من مجموع `attendance.overtime_hours` للشهر × معدل السياسة
- **netSalary** = أساسي + بدلات − استقطاعات + أوفر تايم

#### 2) التعديل الانتقائي
جدول المعاينة قابل للتحرير في **البدلات والاستقطاعات فقط** — الأساسي والأوفر تايم محسوبان خدمياً.

#### 3) الحفظ ثم الترحيل
- **الحفظ** ينشئ `PAY-NNNNNN` بحالة `draft` — **الخادم يعيد حساب كل سطر** (لا يثق بقيم الشاشة) ويرفض تكرار الفترة (مسير draft/posted موجود لنفس الشهر = خطأ)
- **الترحيل** = **قيد ذرّي واحد** مع تغيير الحالة:
```
مدين 52101 رواتب وأجور    بالإجمالي
دائن 21501 رواتب مستحقة   بالصافي
دائن 21502 استقطاعات      بالمستقطع (يُحذف السطر إن كان صفراً)
```
- الحذف: **draft فقط** (مسار التراجع عند فشل الترحيل)

> 🔒 المسير الملغى يحرر الفترة — يمكن إنشاء مسير جديد لنفس الشهر بعد الإلغاء.

## نهاية الخدمة

**المسار**: `/hr/end-of-service`

### إنشاء حساب
اختر **الموظف** + **تاريخ الانتهاء** + **السبب** (استقالة/إنهاء/انتهاء عقد/تقاعد):
- **المبلغ يحسبه الخادم وحده** (payrollEngine): نصف شهر لكل سنة للخمس الأولى ثم شهر كامل — حسب سياسة الشركة القابلة للضبط
- سطر معاينة فوري قبل الحفظ

### المرحلتان
```
draft ──اعتماد──▶ approved ──دفع──▶ paid
```
| المرحلة | القيد |
|---|---|
| **الاعتماد** | مدين 52501 مصروف نهاية الخدمة / دائن 21503 مستحقات نهاية الخدمة — التزام يظهر في الميزانية |
| **الدفع** | ⭐ اختر **الخزينة** ← مدين 21503 / دائن حساب الخزينة — تسوية الالتزام |

> الدفع المباشر من approved مرفوض — المرحلتان تضمنان ظهور الالتزام في التقارير قبل تسويته.

## سياسات HR (الإعدادات)

**المسار**: `/settings/hr-policies` — 9 سياسات لكل شركة (أزرار حفظ ON CONFLICT):

| السياسة | تتحكم في |
|---|---|
| أرصدة الإجازات (سنوية/مرضية/اضطرارية) | فحص الرصيد الصارم |
| معدل أوفر تايم + ساعات العمل القياسية | حساب أوفر تايم الحضور |
| سماحية التأخير (دقائق) | اشتقاق «متأخر» |
| سياسة نهاية الخدمة (معاملات النصف شهر/الشهر) | حساب EOS |
| طريقة ترحيل المسير (Gross-up) | قيد المسير |

ومن **`/settings/payroll-components`** تُدار **مكونات الرواتب**: بدلات/استقطاعات/تأمينات بنوع الحساب (ثابت/نسبة) وحسابها الدفتري — **تعطيل ناعم فقط** (المسيرات السابقة ترجع إليها).

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| أجهز رواتب الشهر | مسير الرواتب ← اختر الشهر ← **معاينة** ← عدّل البدلات ← حفظ ← ترحيل |
| سجلت حضوراً فيه خطأ | الحضور ← نفس الموظف/اليوم ← **Upsert** يحدث لا يكرر |
| موظف طلب إجازة | الإجازات ← جديد ← عند الاعتماد يفحص النظام رصيده تلقائياً |
| موظف استقال | نهاية الخدمة ← جديد (الخادم يحسب) ← اعتماد ← دفع بخزينة |
| أعرف تأخير من يتأخر | الحضور شهرياً — عمود الحالة يشتق خدمياً |
