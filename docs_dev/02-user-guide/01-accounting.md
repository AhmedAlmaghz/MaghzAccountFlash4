## شجرة الحسابات

**المسار**: `/accounting/chart`

### بنية الشجرة
شجرة IFRS كاملة تأتي جاهزة مع البيانات الافتراضية، مقسمة لخمسة أنواع:

| النوع | الطبيعة | أمثلة (كود 5 خانات) |
|---|---|---|
| **الأصول** (Asset) | مدين | 11101 الصندوق، 11201 البنك، 11301 المخزون، 11302 إنتاج تحت التشغيل، 11303 بضاعة تامة |
| **الالتزامات** (Liability) | دائن | 21101 الموردون، 21501 رواتب مستحقة، 21502 استقطاعات مستحقة |
| **حقوق الملكية** (Equity) | دائن | 31101 رأس المال، 31201 الأرصدة الافتتاحية والتسويات |
| **الإيرادات** (Revenue) | دائن | 41101 المبيعات |
| **المصروفات** (Expense) | مدين | 51101 تكلفة المبيعات، 52101 رواتب وأجور، 53101 أجور إنتاج |

### عرض الأرصدة
- كل حساب يعرض **الرصيد الجاري** = مجموع قيوده (افتتاحي + حركة)
- يمكن طي/فتح المجموعات — الحسابات المجمّعية (isGroup) لا تقبل قيوداً مباشرة

### إنشاء حساب جديد
زر «حساب جديد»:
| الحقل | ملاحظة |
|---|---|
| **الكود** | إلزامي، موحد 5 خانات، فريد لكل شركة |
| **الاسم العربي / الإنجليزي** | يظهر حسب لغة الواجهة |
| **الأب** | حدد المجموعة الأب أو «بدون» لحساب رئيسي |
| **النوع** | أحد الأنواع الخمسة — يحدد طبيعته |
| **الرصيد الافتتاحي + تاريخه** | يُرحَّل كقيد افتتاحي عبر حساب الأرصدة الافتتاحية (31201) |

> 🔒 **الحذف محروس**: حساب له قيود يومية لا يُحذف (خطأ واضح). عطّله بدلاً من ذلك.

### الحسابات الافتراضية
أهداف الترحيل قابلة للتكوين لكل شركة من **الإعدادات ← الحسابات الافتراضية** — انظر [دليل الإعدادات](10-settings.md).

## قيود اليومية

**المسار**: `/accounting/journal`

### قائمة القيود
جدول مركزي بفلاتر: حالة (مسودة/مرحّل/ملغي) + بحث. كل قيد يعرض رقمه (`JV-NNNNNNN`)، تاريخه، مرجعه، وصفه، إجماليه، وحالته.

### إنشاء قيد يدوي
«قيد جديد» — نموذج برأس (تاريخ، مرجع، وصف) وسطور لا نهائية:

| العمود | الوصف |
|---|---|
| **الحساب** | حقل ذكي يعرض الكود + الاسم |
| **مدين** | مبلغ المدين (اترك الدائن فارغاً) |
| **دائن** | مبلغ الدائن (اترك المدين فارغاً) |
| **البيان** | ملاحظة السطر (memo) |

**قاعدة القيد المزدوج**: المجموع المدين **يجب يساوي** المجموع الدائن قبل الحفظ — شريط توازن حي يعرض الفرق.

### دورة حياة القيد
```
مسودة (draft) ──ترحيل──▶ مرحّل (posted) ──إلغاء──▶ ملغي (cancelled)
```
- **الترحيل** يجمّد القيد: يظهر في كل التقارير ولا يقبل تعديلاً
- **القيد المرحّل محمي**: لا تعديل ولا حذف — التصحيح بقيد عكسي

> 💡 **القيود التلقائية**: الفواتير والسندات والرواتب والتصنيع كلها تولّد قيوداً بنفسها بافتراض سطورها — القيد اليدوي للاستثناءات والتسويات.

## دفتر الأستاذ

**المسار**: `/accounting/ledger`

كشف حركة حساب واحد عبر الزمن:

1. **اختر الحساب** + نطاق تاريخ (اختياري)
2. الجدول يعرض كل القيود مصنفة، وسطر **«الرصيد الافتتاحي»** أولاً:
   - **مع فلترة تاريخ**: الافتتاحي = رصيد ما قبل الفترة (لا يضيع منك شيء أبداً)
   - **بلا فلترة**: كل القيود من الصفر مباشرة
3. عمود الرصيد التراكمي حيّ لكل سطر — رصيد آخر سطر = الرصيد الكامل

## ميزان المراجعة

**المسار**: `/accounting/trial`

أرصدة كل الحسابات في نطاق تاريخي:
- الأعمدة: كود الحساب، الاسم، النوع، **مدين**، **دائن**، **الرصيد** (بطبيعة الحساب)
- الخلاصة السفلية: مجموع المدين مقابل مجموع الدائن — **متساويان دائماً** (اختبار التوازن الأعظم)
- يخدم كفحص سلامة قبل إعداد القوائم المالية

---

## الميزانية العمومية

**المسار**: `/accounting/balance`

قائمة المركز المالي في تاريخ مرجعي:
- **الأصول** (متداولة ثم ثابتة) مقابل **الالتزامات + حقوق الملكية**
- المعادلة: الأصول = الالتزامات + حقوق الملكية (شريط توازن)
- مرتبة هرمياً من الشجرة

## الأرباح والخسائر

**المسار**: `/accounting/profit`

قائمة الدخل لفترة:
- البنية: الإيرادات − تكلفة المبيعات = **الربح الإجمالي** − المصروفات التشغيلية = **صافي الربح**
- التواريخ الافتراضية تحترم **بداية السنة المالية** للشركة
- اختبرها بعد كل عملية بيع لترى الأثر الفوري

## التدفق النقدي

**المسار**: `/accounting/cashflow`

عرض نقدي حركي: الفعليات التشغيلية (تحصيلات ومدفوعات من السندات والفواتير النقدية) مع إجمالي مستحقات الموردين — يكشف الفجوة بين الربحية المحاسبية والسيولة.

## سندات القبض (استلام نقدية)

**المسار**: `/accounting/receipt-vouchers`

### إنشاء سند قبض
| الحقل | ملاحظات |
|---|---|
| **رقم السند** | `RV-NNNNNN` يولد تلقائياً |
| **العميل** | إلزامي |
| **التطبيق على فاتورة** | ⭐ قائمة ذكية تعرض فواتير العميل غير المسددة (المرحّلة + مدفوعة جزئياً) مع «المستحق» لكل واحدة |
| **المبلغ** | إذا اخترت فاتورة يتعبأ بالمستحق تلقائياً — عدّله لدفعة جزئية |
| **طريقة الدفع** | نقدية / حوالة-محفظة / شيك (مع رقم وتاريخ الشيك) |
| **الخزينة** | ⭐ إلزامية — حساب هذه الخزينة هو طرف القيد |
| **العملة + سعر الصرف** | للعملات الأجنبية مع المعادل بالأساسية |
| **المرفقات** | يمكن إرفاق صور/ملفات (PDF) بالسند |

### سلوك التطبيق على فاتورة
عند الترحيل، **ذرّياً في استعلام واحد**:
1. قيد: مدين حساب الخزينة / دائن العميل
2. `paid_amount` للفاتورة يزيد
3. حالة الفاتورة تتحدث تلقائياً: **مدفوعة** (اكتمل) أو **مدفوعة جزئياً**
4. رصيد العميل ينقص

> 💡 **«دفعة على الحساب»** (بلا ربط بفاتورة): اختر الخيار الأول في القائمة — السند يقيّد على العميل دون تخصيص، ويُطبق لاحقاً.

### الحمايات
- **منع الدفع الزائد**: المبلغ المطبق لا قد يتجاوز مبلغ السند ولا مستحق الفاتورة
- **السند المرحّل**: لا يمكن حذفه أو تعديل ربطه بفاتورة (اتساق مالي)
- حوار تكرار يمنع تسجيل نفس السند مرتين

## سندات الصرف (دفع نقدية)

**المسار**: `/accounting/payment-vouchers`

نفس منطق القبض معكوساً، مع اختلافين مهمين:

### سند دفع لمورد
- **المورد** + تطبيق على فاتورة مشتريات مستحقة (نفس السلوك الذري: قيد + خصم الفاتورة + رصيد المورد)

### سند مصروف عام (بلا مورد)
- اختر **حساب المصروف** بدلاً من المورد (مثلاً 52201 مصروف الإيجار)
- القيد: مدين حساب المصروف / دائن الخزينة
- مناسب للمصروفات النثرية: كهرباء، إنترنت، صيانة — لا يحتاج مورداً مسجلاً

> 💡 طرق الدفع: «نقدي» و«حوالة/محفظة» و«شيك» — الكل يقيّد على **حساب الخزينة المختارة** (المفهوم الموحد للنقدية).

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| سجل عميلاً دفع فاتورة قديمة | سند قبض ← اختر العميل ← طبق على الفاتورة ← ترحيل |
| ادفع إيجار المكتب | سند صرف ← حساب المصروف = إيجار ← الخزينة ← ترحيل |
| صحح قيداً مرحّلاً | قيد عكسي جديد (يعكس السطور) ثم القيد الصحيح |
| افحص سلامة الدفاتر | ميزان المراجعة — المجموعان متساويان؟ |
| ارى مبيعات شهر بعينه | دفتر الأستاذ ← حساب 41101 + فلتر التاريخ |
