# المستخدمون والأدوار والصلاحيات (RBAC)

> المسارات: `/settings/users` و `/roles` و `/audit-logs` — الصلاحية: `settings.users` / `settings.roles` / `settings.audit_log`

---

## نموذج الصلاحيات

نظام RBAC كامل على **مستويين** (دفاع في عمق):
1. **الواجهة**: قوائم مخفية + أزرار مقفلة + حرس مسارات
2. **المحرك** (Electron): كل استعلام SQL يفحص ضد قواعد جدول-بصلاحية قبل التنفيذ — حتى لو اخترقت الواجهة، البيانات محروسة

### بنية الصلاحية
```
<module>.<action>
```

### الأفعال الستة لكل وحدة
| الفعل | معناه |
|---|---|
| `.view` | رؤية كل السجلات |
| `.own` | رؤية سجلاتي فقط (للمندوبين) |
| `.create` | إنشاء |
| `.edit` | تعديل |
| `.delete` | حذف |
| `.post` | ترحيل (المستندات) |

### صلاحيات خاصة
| الصلاحية | تفتح |
|---|---|
| `reports.view` / `reports.export` / `reports.custom` | التقارير / التصدير / المنشئ المخصص |
| `settings.view/edit/users/roles/audit_log` | الإعدادات |
| `ai.use` / `ai.settings` | استخدام الوكيل / إعداداته |
| `core.view` / `core.edit` | لوحة التحكم / تعديل بيانات الشركة النادرة |
| `*` | كل شيء (wildcard) |

## الأدوار الجاهزة

| الدور | الفلسفة | أهم الصلاحيات |
|---|---|---|
| **super_admin** | كل شيء بلا استثناء | `*` (تجاوز كامل) |
| **admin** | كل شيء إلا تعديل نادر | كل الصلاحيات ما عدا `core.edit` |
| **manager** | تشغيل كامل دون إدارة مستخدمين | محاسبة كاملة + مبيعات + مشتريات + تصنيع + مخازن إنشاء/تعديل + تقارير + AI |
| **accountant** | المحاسبة والأزمة المالية | محاسبة كاملة + عرض مخازن + مبيعات/مشتريات إنشاء وتعديل + تقارير + AI |
| **sales_rep** | **مندوب ميداني** | `sales.own` + `crm.own/create/edit` + تقارير عرض + AI |
| **viewer** | قراءة فقط | عرض: محاسبة، مخازن، مبيعات، مشتريات، تصنيع، تقارير |

> المصفوفة الكاملة قابلة للتنزيل من [ملاحق التوثيق](../06-appendix/02-permissions-matrix.md).

## إدارة المستخدمين

**المسار**: `/settings/users`

### إنشاء مستخدم
| الحقل | ملاحظات |
|---|---|
| **اسم المستخدم** (إلزامي، فريد) | المستخدم يسجل به |
| **الاسم الكامل** | يظهر في الواجهة والتقارير |
| **كلمة المرور** | تُخزن PBKDF2 (100k تكرار SHA-256 + salt فريد) |
| **الدور** | من الأدوار الستة أو دور مخصص |
| **الفرع** | ربط اختياري |
| نشط/موقوف | تعطيل يمنع الدخول فوراً ويبطل كل جلساته |

### عمليات الصف
- **تعديل** (بما فيها تغيير الدور — يسري على الجلسة التالية)
- **إعادة تعيين كلمة المرور** — يبطل كل جلسات المستخدم فوراً
- **حذف** — المستخدم المحذوف: بياناته التاريخية تبقى (أعمدة التدقيق تُصفّر reference لا تُحذف)

## إدارة الأدوار المخصصة

**المسار**: `/roles`

### إنشاء دور مخصص
1. «دور جديد» — الاسم والوصف
2. **شبكة الصلاحيات**: 11 مجموعة وحدات — فعّل/عطّل كل فعل بضغطة (checkboxes مصفوفة)
3. حفظ — الدور يصبح متاحاً للمستخدمين

### الأدوار النظامية (isSystem)
- معروضة بقفل 🔒 وشارة «نظامي»
- **للقراءة فقط** — لا يمكن تعديل صلاحياتها (تضمن سلامة النموذج)
- **«نسخ»** (Clone) ⭐: انسخ دوراً نظامياً بدور جديد بنفس الصلاحيات — ثم عدّل النسخة كما تشاء

## حرس الصلاحيات في الواجهة

| الطبقة | مثال |
|---|---|
| **القوائم** | عنصر بلا صلاحية وصول (`view` أو `own` أو `create`) لا يظهر في الشريط الجانبي |
| **الأزرار** | زر «فاتورة جديدة» مغلّف بـ `<Can action="create" module="sales">` — يختفي بلا صلاحية |
| **المسارات** | `PermissionRoute` يفحص صلاحية الوحدة لكل URL — كتابة رابط يدوي لمحظور = إعادة توجيه للوحة |
| **الوكيل الذكي** | لا تُعرض أداة إلا بصلاحيتها — وكذلك أدوات الوكيل ترفض عند التنفيذ |

> ⭐ **ملاحظة مهمة**: إخفاء الزر ليس الأمان — الأمان الحقيقي أن الوصول المباشر بالرابط محروس أيضاً (وهو كذلك).

## سجل العمليات (Audit Log)

**المسار**: `/audit-logs`

كل كتابة في النظام تدخل السجل تلقائياً:

| العمود | المحتوى |
|---|---|
| **المستخدم** | من فعل |
| **الفعل** | create / update / delete / post / cancel / login / logout / reset_password / toggle_active |
| **الجدول** | على أي كيان |
| **معرف السجل** | UUID الكيان (أو اسم أداة الوكيل) |
| **القيم** | قبل ← بعد (jsonb) |
| **الوقت** | متى |

**فلاتر**: المستخدم + الجدول + الفعل + نطاق تاريخ.

> 🔍 السجل يوثق أيضاً كل عمليات الوكيل الذكي (اسم الأداة في record_id) — مراجعة كاملة لما فعله المساعد.

## سياسات الجلسة المرتبطة

| السياسة | القيمة |
|---|---|
| انتهاء الخمول | 30 دقيقة |
| الحد المطلق (سطح المكتب) | 8 ساعات |
| قفل محاولات الدخول | 5 محاولات / 60 ثانية ← قفل 5 دقائق |
| بطلان الجلسات | عند تغيير كلمة المرور / تعطيل / حذف |

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| أضيف محاسباً | المستخدمون ← جديد ← الدور: accountant |
| أضيف مندوب مبيعات | المستخدمون ← جديد ← الدور: sales_rep (يرى فواتيره فقط) |
| أصنع دور «مخازن فقط» | الأدوار ← جديد ← فعّل مجموعة المخازن + viewer للباقي |
| أعدل صلاحيات دور نظامي | استنسخه ثم عدّل النسخة (الأصل مقفل) |
| أعرف من حذف فاتورة | سجل العمليات ← فلتر: الجدول=sales_invoices، الفعل=delete |
| أوقف مستحقاً فوراً | المستخدمون ← عطّل — يبطل جلساته فوراً |
