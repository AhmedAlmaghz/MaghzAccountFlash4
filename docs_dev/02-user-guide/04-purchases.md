## فواتير المشتريات

**المسار**: `/purchases/invoices`

مرآة وحدة المبيعات على جانب الشراء — نفس النموذج ثلاثي الأقسام والمنطق المحاسبي معكوس:

### نموذج الفاتورة
| القسم | الحقول |
|---|---|
| **الرأس** | **المورد** (إلزامي)، التاريخ والاستحقاق، **نوع الدفع** (نقدي/آجل)، العملة وسعر الصرف، **الخزينة** (للنقدي) |
| **السلع** | سطور بمنتج ذكي — **سعر الوحدة يتعبأ من سعر التكلفة** تلقائياً + خصم السطر |
| **الملخص** | خصم الفاتورة (نسبة/مبلغ) → **الضريبة** بشارة النسبة → الإجمالي |

### ترحيل الفاتورة — نقدي مقابل آجل

| | **نقدي** | **آجل** |
|---|---|---|
| **القيد** | مدين المخزون + VAT / **دائن حساب الخزينة** | مدين المخزون + VAT / **دائن الموردون** |
| **الحالة** | `paid` فوراً | `posted` |
| **رصيد المورد** | لا يتأثر | يزيد (مستحق علينا) |
| **المخزون** | حركة `in` لكل صنف | نفس الشيء |

### دورة الحياة والحمايات
```
مسودة ──ترحيل──▶ مرحّلة ──سند صرف──▶ مدفوعة جزئياً/مدفوعة
```
نفس حمايات المبيعات: منع حذف المرحّل، منع حذف مسودة عليها مدفوعات، منع تعديل سطور المرحّلة، حوار بصمة المستند ضد التكرار.

## الموردون

**المسار**: `/purchases/suppliers`

مطابق لإدارة العملاء:
- الكود `SUP-0001` تلقائي، الاسم إلزامي (بفحص التكرار)
- **الرصيد الصافي** (المستحق علينا) + تفصيل مدين/دائن + **رصيد افتتاحي بتاريخه**
- بيانات الاتصال تظهر في أوامر الشراء
- حذف مورد له فواتير **ممنوع** — عطّله

> 💡 **رصيد افتتاحي للمورد** = ديونك له عند بدء استخدام النظام — يظهر كأول سطر في كشف حسابه ويقع في أعمار الديون.

## أوامر الشراء

**المسار**: `/purchases/orders`

### سير العمل
```
أمر شراء (PO-NNNNNN) ──استلام البضاعة──▶ تحويل لفاتورة ──▶ دورة الفاتورة
```

1. **إنشاء أمر**: المورد + الأصناف والكميات والأسعار المتوقعة + **تاريخ التسليم المتوقع**
2. الحالات: `draft` → `confirmed` → `invoiced` (بعد التحويل) / `cancelled`
3. عمود **الكمية المستلمة** يتتبع ما وصل فعلاً من كل سطر
4. **«تحويل لفاتورة»**: يفتح فاتورة مشتريات جديدة بنسخ السطور — وتربط الفاتورة بأمر الشراء

### الفرق بين أمر الشراء والفاتورة
| | أمر الشراء | الفاتورة |
|---|---|---|
| **أثر محاسبي** | لا قيد — التزام معلن فقط | قيد مخزون/موردين كامل |
| **أثر مخزون** | لا شيء | حركة `in` |
| **الاستخدام** | التعاقد والمتابعة مع المورد | الاعتراف المالي بالشراء |

## مردودات المشتريات

**المسار**: `/purchases/returns`

إرجاع بضاعة اشتريتها لمورد:

1. اختر **المورد** ثم **الفاتورة الأصلية** (فواتيره المرحّلة بسطورها)
2. حدد الأصناف والكميات المرتجعة + **السبب** (إلزامي)
3. الرقم `PRT-NNNN` تلقائي

### الترحيل — أثر ثلاثي معكوس
```
مدين الموردون / دائن المخزون
+ حركة مخزون out (الخروج للمورد)
+ رصيد المورد ينقص
```

---

## السداد (تكامل مع السندات)

السداد من **الحسابات ← سندات الصرف**:
1. سند صرف ← اختر المورد
2. **«تطبيق على فاتورة»** يعرض فواتيره المستحقة
3. الترحيل: خصم الفاتورة + تحديث حالتها + قيد الخزينة — ذرّي

---

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| اشتريت نقداً من السوق | فاتورة **نقدي** + خزينة ← ترحيل (سُددت فوراً) |
| اشتريت ب أجل من مورد | فاتورة **آجل** ← ترحيل ← السداد لاحقاً بسند صرف |
| أريد التعاقد أولاً ثم الاستلام | أمر شراء ← عند الوصول «تحويل لفاتورة» |
| أرجعت بضاعة تالفة للمورد | مردودات ← اختر الفاتورة ← الأصناف ← ترحيل |
| ماذا يجب للموردين؟ | تقرير كشف حساب المورد + أعمار ذمم الموردين |
| خطط مشتريات نواقص | تقرير تنبيه النواقص ← زر «أمر شراء» |
