## قوائم المواد (BOM)

**المسار**: `/manufacturing/bom`

### ما هو BOM؟
وصفة إنتاج: **ماذا نحتاج لصنع دفعة من منتج تام** — الخامات والكميات وتكلفة كل وحدة.

### إنشاء BOM
| الحقل | الوصف |
|---|---|
| **المنتج التام** | منتج نوعه «تام» (يدعم التصنيع) |
| **كمية الناتج للدفعة** | ⭐ مثال: 10 — كل دفعة تنتج 10 وحدات (افتراضي 1) |
| **سطور الخامات** | منتج (مادة خام) + **الكمية اللازمة لكل دفعة** + تكلفة الوحدة (تعبأ تلقائياً من سعر التكلفة — قابلة للتعديل) |
| الإصدار (version) | لتتبع تطورات الوصفة |
| **التكلفة الإجمالية** | ⭐ **تُحسب تلقائياً** = Σ(كمية × تكلفة) |

> 🔒 حوار التكرار وحماية الحذف عند وجود أوامر مرتبطة.

### حاسبة توفر الخامات (شاشة BOM الذكية)
على بطاقة كل BOM:
- أدخل **كمية مخططة** (عدد دفعات)
- الجدول يعرض لكل مادة: **المطلوب / المتاح / يكفي؟** (✓ أخضر أو ✗ أحمر)
- **أقصى كمية قابلة للإنتاج** من المخزون الحالي (عبر **كل** المستودعات)
- زر **«إنشاء أمر تشغيل»** مباشرة — يستخدم الحساب ويحذرك إن كانت الخامات ناقصة

## أوامر التشغيل

**المسار**: `/manufacturing/work-orders` — قلب الوحدة.

### إنشاء أمر تشغيل
| الحقل | الوصف |
|---|---|
| **رقم الأمر** | `WO-NNNN` تلقائي |
| **المنتج التام + BOM** | ⭐ الاختيار يشتق **سطور الاستهلاك تلقائياً** من الشجرة (كمية الدفعات × كمية المادة) |
| **عدد الدفعات** | quantity — الإنتاج المتوقع = الدفعات × كمية ناتج BOM |
| **التواريخ المخططة** | بداية/نهاية — افتراضياً اليوم + تحقق (النهاية قبل البداية مرفوضة) |
| **تكلفة الوحدة للخامات** | تعبئة تلقائية من BOM — قابلة للتعديل |
| **تكاليف الإنتاج** | jsonb: عمالة / طاقة / تغليف / أخرى — مبالغ بأوصاف تُجمّل في تكلفة المنتج |
| رقم التشغيلة + المشرف | اختياريان |

> ⭐ **التكلفة الإجمالية آلية دائماً** = Σ(مواد) + Σ(تكاليف الإنتاج) — تُحسب في الـ API ولا تقبل قيمة يدوية. بطاقة حية في الفورم تُحدثها لحظياً.

### دورة حياة أمر التشغيل
```
planned ──بدء──▶ in_progress ──إكمال──▶ completed
   ▲                  │                      │
   └── إعادة فتح ─────┴── إلغاء (مع إرجاع اختياري) ──▶ cancelled
```

#### 1) البدء (Start) — الصرف الفعلي
- **بوابة توفر**: يفحص رصيد كل مادة في **كل المستودعات** — نقص أي مادة = **فشل بتقرير تفصيلي** (ماذا ينقص وكم)
- النجاح ينشئ حركات `out` ذرّية لكل مادة **بمرجع رقم الأمر** (WO-0002)
- قيد محاسبي: **مدين WIP (إنتاج تحت التشغيل 11302)** / دائن المخزون — بمبلغ مواد صافٍ (`wip_materials_cost`)

#### 2) الإكمال (Complete) — الاستلام والتسوية
مودال مُعبّأ مسبقاً بالخطة (**الفعلي = المخطط افتراضياً** — عدّل فقط ما انحرف):
- **الكمية المنتجة**: افتراضياً الدفعات × ناتج BOM
- **سطور الاستهلاك الفعلي**: لكل مادة `actualQuantity = planned` و `actualUnitCost = unitCost` — **مؤشر انحراف حي** لكل سطر (كمية + نسبة٪: أخضر فائض / أحمر زيادة / ±0 مطابقة)
- **مستودع استلام المنتج التام**: ⭐ اختر الوجهة — حركة `in` للمنتج التام بمرجع الأمر

التنفيذ ذرّي:
1. تسوية الاستهلاك بالفرق (actual > issued ← صرف إضافي / actual < issued ← إرجاع فائض `in`)
2. استلام التام في المستودع المختار
3. **قيد إجمالي التكلفة**: مدين المخزون-تام (أو حساب النوع المخصص) / دائن WIP — وكل فائض/عجز مادة بحساب مخزونها الخاص (فروقات دقيقة)
4. تثبيت القيم الفعّالة في DB (تقارير الانحراف تقرأ حقيقة لا أصفاراً)

#### 3) الإلغاء
- من `planned`: مباشر
- من `in_progress`: **مع خيار إرجاع الخامات المصروفة** (حركات `in` عكسية)
- **إعادة الفتح** (cancelled → planned): يصفّر المسار التشغيلي كاملاً (تواريخ فعلية، WIP، actuals)

### جدول الأوامر
أعمدة: الرقم، المنتج، الكمية، **التواريخ المخططة (رمادي) + الفعلية (teal)**، التكلفة، الحالة
فلاتر: الحالة + البحث. بطاقة التفاصيل: جدول زمني مخطط/فعلي + **بطاقة تفصيل التكلفة** (مواد + كل تكلفة إنتاج + الإجمالي).

## التقارير

### تقرير تكلفة الإنتاج
`/manufacturing/cost-report` — تكاليف الأوامر المكتملة مفصلة (مواد/عمالة/طاقة/أخرى) مع الإجماليات.

### تحليل الانحرافات
`/manufacturing/variance-report` — لكل أمر: **المخطط مقابل الفعلي** لكل مادة (كمية وتكلفة) وفروقات الإنتاج — القيم من القيم الفعّالة المثبتة عند الإكمال.

### فحص التوفر (أداة الوكيل)
`manufacturing.check_bom_availability` — نفس حاسبة شاشة BOM متاحة للوكيل الذكي قبل بدء أي أمر.

## المحاسبة (ملخص القيود)

| الحدث | القيد |
|---|---|
| **بدء أمر** | مدين WIP (11302) / دائن المخزون (بمبلغ الخامات المصروفة) |
| **صرف إضافي عند الإكمال** | مدين WIP / دائن مخزون المادة |
| **إرجاع فائض** | عكسه |
| **إكمال** | مدين مخزون التام (حساب النوع أو 11303 أو 11301) / دائن WIP |
| **عجز (خسارة مواد)** | حساب خسائر الإنتاج (53501 القابل للتكوين) |

كل حسابات التصنيع قابلة للتكوين من **الإعدادات ← الحسابات الافتراضية**: WIP، تام الصنع، عمالة/طاقة/تغليف/أخرى/خسائر إنتاج.

## تدفقات سريعة

| أفعل | الخطوات |
|---|---|
| أصنع منتجاً من خامات أول مرة | 1) أنشئ منتجين: خام + تام (بنوع يدعم BOM) 2) BOM جديد بالوصفة 3) أمر تشغيل |
| أختبر توفر الخامات قبل الإنتاج | شاشة BOM ← أدخل الكمية ← اقرأ ✓/✗ وأقصى قابل للإنتاج |
| أنفذ أمر إنتاج قياسياً | أمر ← **بدء** (يصرف الخامات) ← **إكمال** (نقرة واحدة — الفعلي معبأ بالمخطط) |
| المواد المستهلكة زادت عن الخطة | عند الإكمال عدّل actualQuantity للمادة — الفرق يُصرف إضافياً ويثبت |
| فحص تكلفة إنتاج شهر | تقرير التكلفة + تقرير الانحرافات |
