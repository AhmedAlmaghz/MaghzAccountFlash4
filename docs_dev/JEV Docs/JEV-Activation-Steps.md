# تفعيل JEV في خطوة واحدة (بعد التحديث)

> **القاعدة الذهبية:** مفتاح `.env` وحده لا يكفي — التطبيق يقرأ العلم والمفتاح من قاعدة البيانات.

## الخطوات (دقيقتان)

1. افتح **الإعدادات ← الذكاء الاصطناعي ← بطاقة "تسريع JEV"**.
2. الصق مفتاح TypeSafe (من https://console.typesafe.ai/keys — يبدأ بـ `ts_`) في حقل المفتاح.
3. فعّل **"تفعيل JEV"** (و"توجيه النية عبر JEV" — مفعّل افتراضياً).
4. اضغط **حفظ** ثم **"اختبار JEV"** — يجب أن ترى `JEV يستجيب — jev-1.13.0 ~90ms`.
5. اضغط **"فحص حالة JEV"** — يجب أن ترى `✓ التفعيل: يعمل` + `✓ المفتاح: محفوظ`.
6. أرسل أي رسالة في الدردشة، ثم أعد فتح الإعدادات: سطر التشخيص يعرض `⚡JEV <النية> · ثقة X% · Yms` — هذا هو الدليل القاطع أن JEV يقود.

## استكشاف الأخطاء

| العرض | المعنى | الحل |
|---|---|---|
| `✗ التفعيل: مطفأ` | العلم غير محفوظ | فعّل المفتاح واحفظ |
| `✗ المفتاح: غير موجود` | لا مفتاح في DB | الصق المفتاح واحفظ (`.env` لا يكفي) |
| `○ لم يوجَّه أي طلب` بعد الدردشة | JEV لا يُستدعى | تحقق من المفتاح + راقب كونسول DevTools لسطر `[ai][jev]` |
| بطء إضافي ~2s لكل رسالة | مفتاح خاطئ + مهلة | صحح المفتاح بزر الاختبار أولاً |
| `Failed to fetch` | الـ renderer محجوب عن api.typesafe.ai (CORS/شبكة) | سطح المكتب: أُصلح في 0.25.7 عبر العملية الرئيسية (`ai:jev-systemone`) — حدّث وأعد الفحص. المتصفح: أُصلح عبر مُرحّل نفس المصدر (`POST /api/jev-systemone` — دالة Vercel في الإنتاج، ملحق vite في التطوير) — حدّث وأعد الفحص |

## ما الذي يستخدم JEV فعلياً (عند التفعيل)؟

- **الموجه الاحتمالي**: تصنيف النية (13 نية) بدل مطابقة الكلمات.
- **البحث الموحد** (`jev.search_all`): قرار واحد يغطي 20 عائلة كيانات + 1–3 قراءات DB بدل 19 جدولاً.
- **المسار السريع**: حقن معرفات الكيانات عالية الثقة قبل الاستدلال القديم.
- **الحراسة**: فحص الحقن/البيانات الحساسة على المدخل والمخرجات.
- **التقييم**: زر التقييم في العملاء المحتملين + شارة حارس الترحيل على البطاقات.

## ملاحظة عن PoC

`scripts/jev-poc.ts` يعمل بمفتاح البيئة فقط (`TYPESAFE_API_KEY=... npx tsx scripts/jev-poc.ts`) — ممتاز للقياس، لكنه **لا يغني عن خطوات التفعيل أعلاه** للتطبيق نفسه.
