# الخطة المدمجة الموحدة: إحياء JEV + البحث الموحد — بذكاء وأداء أعلى

> **التاريخ:** 2026-09-23 — **الحالة:** قيد التنفيذ — **المبدأ:** JEV يقرر، والكود ينفذ

## 1. الفلسفة المدمجة (التحسين الجوهري)

الخطتان السابقتان (إحياء JEV + البحث الموحد) تشتركان في نفس الجذر. والتحسين الذي يدمجهما حقاً:

**طلب فهم واحد (One Understanding Call) بدل 3 طلبات** — النية + أنواع الكيانات + الحراسة أسئلة متوازية في طلب JEV واحد في المقدمة (~15 سؤالاً، ~150ms)، ثم تُستهلك نتائجه في الموجه والحارس والبحث معاً بدل 3 استدعاءات منفصلة (موجه 1.8s + حارس 2s + بحث). هذا وحده يخفض زمن JEV لكل رسالة من ~4s إلى ~0.3s.

```
رسالة المستخدم
  ▼  طلب JEV واحد "الفهم" (guard Nouls + intent Choice + type Nouls) ~150ms
  ├─ verdict=block → رسالة حظر صادقة (نهاية)
  ├─ intent+confidence → الموجه يستخدمها مباشرة (بلا طلب ثانٍ في الدورة الأولى)
  └─ type probs → البحث الموحد: الأنواع فوق 0.50 فقط
                    → قراءات DB متوازية (1–3 بدل 19 جدولاً)
                    → Choice ترتيب على مختصر ≤30 → id + confidence
  ▼  Gemini للسرد فقط + شارة ⚡JEV المرئية + مقاييس حية
```

## 2. حزم العمل

### الحزمة P0 — التشخيص المرئي أولاً (حتى ترى بعينك قبل أي توسع)
- زر **"فحص حالة JEV"** في بطاقة الإعدادات يعرض: المفتاح موجود؟ الموجّه مفعّل؟ آخر `intent/confidence/latency` من الذاكرة — ينهي التخمين نهائياً.
- إصلاح بطاقة المقاييس: تحديث حي بعد كل رسالة (اشتراك في `recordJevMetric` بدل `jevMetricsTick` عند الحفظ فقط).
- ملفات: `AiSettingsPage.tsx` + `jevMetrics.ts` (مشترك بسيط `subscribeJevMetrics`).

### الحزمة P1 — إعلان `jev.*` (يسد فجوة "الأدوات الميتة" + يؤسس للبحث)
- إضافة بادئة `jev.` في **كلا** الموجهين: `ALWAYS_ON` تستقبل `jev.search_all` دائماً، و`INTENT_TO_PREFIXES` تستقبل `jev.score_lead ← crm/reports` و`jev.score_stock ← inventory/reports` و`jev.rank_customers_churn ← sales/reports`.
- اختبار: كل أداة `jev.*` تظهر في `routeToolsForCycle` و`jevRouteToolsForCycle` عند النية المطابقة، وتُحجب عند غياب الصلاحية (RBAC عبر `getVisibleTools()` — `registry.ts:31` يضمنها تلقائياً).

### الحزمة P2 — البحث الموحد `jev.search_all` (قلب الخطة)
- ملف جديد `jev/jevSearch.ts`:
  - `jevRouteSearch(query)` — Nouls الأنواع الـ 15 (عميل/مورد/منتج/وحدة/حساب/فاتورة/سند/قيد/موظف/تصنيع/مخزن/فرصة/مهمة/…) في طلب واحد.
  - `jevSearchAll(companyId, query)` — المنسق: يقرأ الاحتمالات، يستدعي `execute` أدوات `search.*` الحالية **مباشرة** (نفس الدوال في `searchTools.ts` — بلا إعادة كتابة، فلتر RBAC أولاً)، يدمج ويرتب.
  - `jevRankCandidates()` — Choice على مختصر ≤30 اسماً (نمط `jevEntityLinker` يُدمج هنا بدل ملف منفصل ميت).
- أداة `jev.search_all` (read) في `jevTools.ts` — تُعلن دائماً.
- **دقة أعلى**: إجماع مرحلتين — `fuzzySearch` الحالي يبني المختصر، وJEV يختار منه (يمنع هلوسة id) + عند تقارب الأول والثاني (<0.1) يُرجع `ambiguous` فيسأل المستخدم بدل التخمين.
- **أداء أعلى**: توزيع الأنواع يُخزَّن 60s للنص المطبَّع نفسه — "تابع/استمر" لا تدفع أي طلب جديد.

### الحزمة P3 — المسارات السريعة ودمج الطلبات (الأداء)
- في `send()` قبل `resolveEntitiesInText` (`chatEngine.ts:476`): طلب "الفهم" الموحد، وحقن المعرفات عالية الثقة (>0.85) في السياق، وتخطي fan-out الـ 19 جدولاً.
- الدورة الأولى من `runLoop` تستهلك توزيع المقدمة المخزَّن (بلا طلب موجه ثانٍ)؛ الدورات اللاحقة على الاستمرارية C1 القديمة.
- سقف صارم: أي طلب JEV خلف `deadlineOr ≤2s` + fallback للقديم.

### الحزمة P4 — العداد المرئي (الثقة)
- شارة `⚡JEV intent·conf` صغيرة على بطاقة الأداة/الرسالة عند استخدام JEV + لون حسب الثقة — أول دليل مرئي للمستخدم.
- مودال `LeadsPage` موجود يُعمَّم نمطه (يعرض "تقدير محلي" بصراحة عند غياب JEV — يُبقى).

### الحزمة P5 — بوابة التحقق الحية (قبل أي تعميم)
- تشغيل `scripts/jev-poc.ts` + 20 استعلام بحث حقيقي بمفتاح فعلي، وتثبيت: زمن/تكلفة/دقة عربية/عتبات (ابدأ 0.50، إسقاط للكلاسيكي تحت 0.55).
- 10–12 اختباراً جديداً: توجيه الأنواع، العتبة، RBAC، fallback، لهجات، طلب-واحد-لا-ثلاثة (يُحسب عدد استدعاءات `jevSystemOne`).
- توثيق التفعيل بخطوة واحدة (يسد فخ env مقابل DB flag).

## 3. معايير القبول
- `tsc` صفر، بناء أخضر، كل اختبارات jev خضراء فرادى.
- طلب بحث متعدد الكيانات = **طلب JEV واحد + ≤3 قراءات DB** (يُثبت بعدّاد في الاختبار).
- زر الفحص يعرض الحالة الحقيقية، والمقاييس تتحدث حياً، والشارة تظهر في الدردشة.
- أي فشل JEV = سلوك اليوم حرفياً (لا تراجع).

## 4. المخاطر
- العربية ثانوية في JEV → عتبات مضبوطة على بياناتك + fallback تلقائي.
- سقف الحالة 32k → مختصرات ≤30/نوع فقط تصل JEV.
- زمن إضافي عند تفعيل JEV بمفتاح خاطئ (حتى 2s مهلة) → زر الفحص يكشفه فوراً + المهلة تُبقي الدردشة حية.
