# خطة الفحص الشامل للتطبيق (للقراءة فقط) + تقرير مفصل

## ما أُنجز بالفعل (الاستطلاع الأولي)
جُمعت الحقائق الثابتة عن المشروع: الإصدار v0.26.3، 14 وحدة، 174,896 سطر / 683 ملف، 246 ملف اختبار، 43 migrations، 68 جدول، ترجمة متوازنة 4011=4011، نظافة كود عالية (صفر TODO/FIXME، 4 `as any` فقط)، ونقاط ساخنة (chatEngine.ts بـ 2,341 سطر، وحدة AI = 29% من الكود).

## المرحلة 1: تشغيل الفحوصات الحية (كلها للقراءة فقط)
1. **ESLint** — `npm run lint` → عدد الأخطاء/التحذيرات
2. **TypeScript** — `npx tsc -b` → سلامة الأنواع عبر كل المشاريع
3. **الاختبارات** — `npm test` (vitest run) → عدد الناجح/الفاشل من 246 ملفاً + تفاصيل أي فشل
4. **بناء الإنتاج** — `npm run build` → نجاح البناء + أحجام الـ chunks (قسم الأداء)
5. **فحص Drift** — `npm run db:check` → تطابق Drizzle schema مع الـ migrations
6. **أمن الاعتماديات** — `npm audit` (+ `npm outdated` إن تطلب الشبكة وقتاً معقولاً)
7. **قاعدة البيانات الحية (قراءة فقط)** — `node check-db-state.cjs` الموجود في الجذر → عدد الجداول/الشركات/المستخدمين/السجلات. إن كان PostgreSQL متوقفاً يُوثَّق ذلك في التقرير فقط.

**ضمانات:** لا `db:reset`، لا `migrate`، لا أي كتابة في قاعدة البيانات. الملف الوحيد الذي سيُنشأ هو التقرير (وتحفظ أدوات البناء artifactsها المؤقتة المعتادة dist/ وذاكرة vitest).

## المرحلة 2: كتابة التقرير — `AUDIT_REPORT.md` في جذر المشروع
أقسام التقرير (بالعربية):
1. **الملخص التنفيذي** — حكم عام على صحة التطبيق + أهم الأرقام + أهم المخاطر
2. **بطاقة المشروع** — الإصدار، التقنيات، الوحدات، حجم الكود، المسارات، الاعتماديات
3. **نتائج الفحوصات الحية** — نتيجة كل فحص من المرحلة 1 مع الأرقام الدقيقة
4. **قاعدة البيانات** — الـ migrations، الجداول، نتيجة drift check، الحالة الحية
5. **جودة الكود** — مؤشرات النظافة، النقاط الساخنة (الملفات الضخمة، توزيع console/eslint-disable)
6. **الاختبارات** — التوزيع، فجوات التغطية (reports/settings/inventory بلا اختبارات تقريباً)، اختبارات البنية (27 gate tests)
7. **الترجمة (i18n)** — التوازن والاتساق
8. **الأمان** — ثغرات الاعتماديات، عزل multi-tenancy، RBAC
9. **الأداء** — أحجام الحزم من ناتج البناء، lazy loading
10. **المخاطر والملاحظات** — أهمها: الإصدار 0.26.3 بلا قيود في CHANGELOG (آخر قيد v0.25.12)، تضارب AGENTS.md مع الواقع (يقول v0.25.6 و38 migrations و3959 keys)، ملفات سجل متناثرة في الجذر
11. **التوصيات** — قائمة مرتبة بالأولوية (عالية/متوسطة/منخفضة) دون تنفيذ أي إصلاح

## المرحلة 3: الملخص التنفيذي في المحادثة
عرض أهم النتائج والأرقام + رابط ملف التقرير الكامل.

## نطاق صريح
تقرير فقط — **لا إصلاحات، لا تعديل كود، لا E2E، لا حذف بيانات**. أي إصلاح مقترح يُذكر كتوصية فقط ويُنفَّذ بطلب لاحق منك.
